Документы

Замены документов инструкторов: водительские удостоверения (ВУ) и СТС автомобилей. До решения действует предыдущая версия — документ «не мигает». Подтверждение делает новую версию действующей; при отклонении обязательна причина отказа — её увидит инструктор, действующей останется предыдущая версия.

История решений. Подтверждение: новая версия verified, предыдущая — архив. Отклонение: версия rejected с причиной, у инструктора действует предыдущая версия.
