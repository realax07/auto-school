Мой график на неделю
Клик по слоту — попап: «Разово» (только эта дата) или «Повторяющееся» (еженедельно) · шаг 2 часа · клик по запросу/брони — решение
Есть несохранённые изменения
Рабочий интервалНе работаюПодтверждённая броньНовый запрос ученика
Тип выбирается в попапе для каждой ячейки: «Разово» — слот только на эту дату, «Повторяющееся» — еженедельно. Изменения применяются по «Сохранить график» (одна замена всего графика), «Отменить» возвращает сохранённый график. Прошедшие ячейки и недели — только просмотр. Запрос ученика показан ровно на выбранном им слоте — подтверждение или отказ (с обязательным комментарием) применяются сразу, без «Сохранить».

Без файла СТС автомобиль не создаётся — вернётся ошибка «загрузите фото СТС». Тип и размер файла проверяются по содержимому (magic bytes), лимит 5 МБ. Заменить документ?

—
Замена не вступает в силу сразу. Замена вступит в силу только после проверки администратором: до подтверждения действует предыдущая версия — документ «не мигает». Повторная загрузка до решения заменит ожидающую версию.

Если администратор отклонит замену, вы увидите причину отказа, а действующей останется текущая версия — документ не будет утерян.
