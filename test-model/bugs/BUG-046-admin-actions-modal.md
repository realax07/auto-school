# BUG-046: админка — кнопки «Одобрить/Отклонить» наслаивались на соседние колонки

> Автор: PM (main) · Дата: 2026-10-16 · Статус: ИСПРАВЛЕНО

## Симптом

Колонка «Действия» таблицы заявок: кнопки «Одобрить/Отклонить»
наезжали на соседние колонки (скрин Заказчика 2026-10-16).

## Решение Заказчика (дословно)

«Отклонение и одобрение только в модалке, которая при нажатии на строку
открывается. На рассмотрении статус сделай желтым».

## Исправление

- frontend/admin-dashboard.html: колонка «Действия» удалена; клик по
  строке pending открывает модальную карточку (по согласованному мокапу
  instructor-card-admin) с «Одобрить»/«Отклонить» (deny — обязательный
  комментарий, кнопка блокируется до ввода); waiting-бейдж желтый
  (#ffc76e на темном фоне), approved/rejected — зеленый/красный.
- design/mocks/admin-dashboard.html синхронизирован.
- e2e: модерация через модалку + тест блокировки deny + бейдж-цвета
  (TC-UI-012…014, change add-instructor-student-loop).
