# BUG-054: просмотр фото авто — нет навигационных стрелок

> Автор: PM (main) · Дата: 2026-11-04 · Статус: ИСПРАВЛЕНО

## Симптом (Заказчик, дословно)

«На экране просмотра фото авто, отсутствует стрелка с правой стороны (с левой есть)».

## Корень

Просмотр в полном размере (m-view, mcOpenView) показывал ОДНО фото без
навигации: стрелки ‹ › были только в галерее модалки авто и плитках, в
m-view их не было вовсе.

## Исправление

- m-view: стрелки ‹ › (классы .navarrow prev/.next — обе стороны) НАД
  фотографией; листание по доступному набору фото (авто: ракурсы + СТС;
  документ: одиночный — стрелки скрыты), циклически; заголовок обновляется
  названием текущего фото; Esc закрывает.

## Проверка

- e2e пилота/документов в составе UI-сьюта: 61 passed (full: см. PR).
- Прогон мока: стрелки рендерятся обе, листание циклическое.
