# BUG-067: test_pdd_generator мутирует РЕАЛЬНЫЙ корпус content/pdd (грязное дерево после гейта)

- **Обнаружено:** Спринт 18, волна sidebar-module (2026-11-16, гейт
  `pytest tests/unit -q` в рамках приемки единого сайдбара).
  После прогона unit-тестов `git status` показывал измененным
  `content/pdd/pravila/r17_Dvizhenie-v-zhilikh-zonakh.md` (файл
  отсутствовал в стартовом статусе).
- **Причина:** `tests/unit/test_pdd_generator.py::test_generator_strips_reinjected_site_chrome`
  строит symlink-«копию» корпуса: `os.symlink(CORPUS/"pravila", corpus/"pravila")`
  — «копия» указывает на РЕАЛЬНЫЙ каталог репо. Далее тест делает
  `victim.unlink()` + `victim.write_text(dirty)` на файле через симлинк
  (r17) и НЕ восстанавливает оригинал — в рабочем дереве остается версия
  с подмешанными хвостами сайта-источника (дубль блоков «Поделиться/
  Печатать/комментарии/футер»). Любой последующий `git add -A`
  закоммитил бы мусор в корпус (прецедент d9e7353).
- **Что сделано:** мутация заключена в try/finally с восстановлением
  оригинального текста (`victim.write_text(text)`); проверено: прогон
  теста оставляет `git status` чистым по content/.
- **Статус:** FIXED (fix/sidebar-module; носитель — unit-тест, на
  прод-поведение генератора не влияет).
