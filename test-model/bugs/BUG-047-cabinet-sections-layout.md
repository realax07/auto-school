# BUG-047: разделы «Мои автомобили»/«Мои заявки» открывались вне сайдбара кабинетов

> Автор: PM (main) · Дата: 2026-10-20 · Статус: ИСПРАВЛЕНО

## Симптом

«Мои автомобили» (инструктор) и «Мои заявки» (ученик) были отдельными
standalone-страницами: без сайдбара, шапка съезжала/центрировалась,
back-ссылки слипались с крошками (скрины Заказчика 2026-10-17).

## Решение Заказчика (дословно)

«Должно быть во всех разделах: активный раздел в сайдбаре, остальная
страница справа от него».

## Исправление

- instructor-dashboard.html: раздел «Мои автомобили» встроен табом
  (сайдбар + активный пункт), frontend/my-cars.html удален.
- cabinet.html: ученический сайдбар (Главная / Мои заявки / Выбрать
  инструктора), «Мои заявки» разделом; frontend/my-requests.html удален.
- backend/app.py: 301-редиректы старых маршрутов; /review → /cabinet#/my-requests.
- review-form.html: шапка space-between, крошка сверху.
