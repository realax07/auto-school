# PLAN-BUG-047: вторичные страницы без сайдбара/съехавшие шапки (скрины Заказчика 2026-10-17)

> Флоу: 2 · Автор: dev · Дата: 2026-10-20 · Ветка: fix/bug-047-sections-in-cabinets

## Решение Заказчика (дословно)

«Должно быть во всех разделах: активный раздел в сайдбаре, остальная
страница справа от него».

## Шаги

1. `frontend/instructor-dashboard.html`: раздел «Мои автомобили» — верстка
   и JS из frontend/my-cars.html перенесены ВНУТРЬ дашборда как таб
   (секция #sec-cars по образцу «Календарь»/«Запросы учеников»); пункт
   сайдбара «Мои автомобили» уже был — активный пункт подсвечивается,
   контент в main справа, шапка дашборда без изменений. Хеш #/my-cars
   открывает раздел напрямую (reload не сбрасывает).
2. `frontend/cabinet.html`: единый лейаут ученика — примитивный сайдбар
   («Главная», «Мои заявки», «Выбрать инструктора»), контент справа, шапка
   сверху. Раздел «Мои заявки» — верстка/JS из frontend/my-requests.html
   (бейджи желтый/зеленый/красный, комментарии отказов, «Повторить заявку»,
   переход на /review). Строки стилей мокапа не изменялись (design-guard
   test_cabinet_page.py) — новые правила только добавлены.
3. Страницы frontend/my-cars.html и frontend/my-requests.html удалены;
   в backend/app.py их статик-маршруты заменены 301-редиректами на
   /instructor/dashboard#/my-cars и /cabinet#/my-requests. review-form.html
   остается целевой страницей: шапка — крошка слева (без центрирования),
   back-ссылки из тела убраны, навигация кнопкой «Назад к заявкам» в форме.
4. `frontend/instructor-choice.html` остается отдельной страницей (крошка
   слева, «В кабинет» и user разнесены — flex space-between, как в
   review-form после фикса).
5. `tests/test_ui_playwright.py`: TC-UI-015…018 переведены на разделы внутри
   кабинетов (переход через сайдбар/хеш, проверка активного пункта);
   TC-UI-019 — навигация после встраивания; новый тест 301-редиректов
   старых маршрутов; design-guard баланса тегов — на новые носители
   (dashboard/cabinet/review-form/instructor-choice). tests/test_s3_backend.py:
   статика /review → 200, /my-cars//my-requests → 301; шейпы API — по новым
   файлам-носителям.
