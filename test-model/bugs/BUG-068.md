# BUG-068: клики по таб-бару MobileTabBar падали TypeError — openTab не возвращен из setup

- **Обнаружено:** Спринт 18, волна 18.4 (2026-11-17, новый e2e-носитель
  мобильного вьюпорта TC-UI-077 `test_s18_mobile_login_bottomsheet_tabbar_cabinet`
  на 390×844). Первый же клик по табу «Записи» не переключал раздел:
  `#sec-bookings` оставался скрыт, в консоли —
  `TypeError: e.openTab is not a function` (shared-чанк).
- **Причина:** `src/components/MobileTabBar.vue` — функция `openTab(name)`
  объявлена в `setup()`, но НЕ включена в возвращаемый объект bindings
  (возврат содержал только `visible/active/EDU/sheet/closeSheet/pickEdu/
  uname/initials/openProfile/logout`). Шаблон вызывает
  `@click="openTab('…')"` на 4 из 5 табов — в рантайме клик падал
  TypeError, навигация с таб-бара была мертва. Пропущено на волне 18.1:
  прогон «targeted 27» не включал кликовых сценариев по таб-бару (носители
  были статическими + e2e desktop), сборка TypeError не ловит.
- **Что сделано:** `openTab: openTab` добавлен в возвращаемый объект
  (комментарий BUG-068 на месте); носители закрепляют регресс:
  `tests/web/test_mobile_tabbar.py::test_mtabs_setup_bindings_exposed`
  (wiring-фрагмент: имя в возвращаемом объекте) + e2e TC-UI-077 (клик
  «Записи» → `#sec-bookings` + хеш `#/my-bookings`). Пересобран dist,
  прогон s18-сценариев green.
- **Статус:** FIXED (fix волны 18.4; Desktop-версии не касался — таб-бар
  на desktop не рендерится).
