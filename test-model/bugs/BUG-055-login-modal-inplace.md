# BUG-055: логин — отдельная страница вместо модалки поверх текущей

> Автор: PM (main) · Дата: 2026-11-04 · Статус: ИСПРАВЛЕНО

## Симптом (Заказчик, дословно)

«Сделай логин в модальном окне, поверх замутненной страницы, откуда его открыли».

## Корень

«Войти» на лендинге инструкторов (data-open-login) делал редирект на /
(sessionStorage-флаги), логин-модалка открывалась только на лендинге
ученика.

## Исправление

- instructors.html: модалка логина (поля/ошибка/сабмит — те же id
  login-email/login-password/login-error) на самой странице; data-open-login
  открывает локально, БЕЗ редиректа и sessionStorage-флагов.
- Бэкдроп оверлея: backdrop-filter: blur(8px) + затемнение — страница под
  модалкой замутнена (в обоих контурах логина).

## Проверка

- e2e: «Войти» открывает модалку на текущей странице; логин по роли
  (instructor → /instructor/dashboard, student → /cabinet).
- UI-сьют: 61 passed.
