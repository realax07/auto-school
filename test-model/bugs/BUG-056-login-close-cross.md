# BUG-056: окно логина — крестик вне модалки, без закрытия по фону

> Автор: PM (main) · Дата: 2026-11-04 · Статус: ИСПРАВЛЕНО

## Симптом (Заказчик, дословно)

«В окне логина, закрытие окна сделай через крестик в полупрозрачном
замутненном круге вне модального окна с отступом справа верзху. Закрытие
кликом вне зоны окна отключи. При нажатии на крестик, возвращаемся на
страницу откуда его открыли (если с инструктора то на инструктора, если с
ученика то на ученика)».

## Исправление

- Кнопка-крестик ВНЕ карточки модалки: absolute top:18px/right:22px,
  круг 44px, rgba(0,0,0,.35) + backdrop-filter blur (полупрозрачный
  замутненный круг), крестик белый.
- Закрытие кликом по фону — ОТКЛЮЧЕНО (в обоих контурах логина).
- Крестик/Esc → закрытие модалки: страница не менялась (модалка
  на месте), флаги sessionStorage (open_login*) удаляются; после
  УСПЕШНОГО логина роутинг по роли (инструктор → /instructor/dashboard,
  ученик → /cabinet) — не менять.

## Проверка

- e2e: клик по бэкдропу не закрывает; крестик закрывает; Esc закрывает.
- UI-сьют: 61 passed.
