# BUG-045: админка — кнопки «Отклонить/Отмена» разъезжаются по краям

> Автор: PM (main) · Дата: 2026-10-15 · Статус: ИСПРАВЛЕНО

## Симптом

В форме отказа админки (скрин Заказчика 2026-10-15): после поля
«Причина отказа (обязательно):» кнопка «Отклонить» висит по центру,
«Отмена» — у правого края, между ними пустота.

## Ожидаемое поведение

Кнопки стоят вместе под полем комментария (gap 10px).

## Причина

Класс `.btn-export{margin-left:auto}` задуман для кнопки-действия в
строке таблицы (прижать вправо), но переиспользован в deny-форме:
в flex-строке первая кнопка упирается в авто-отступ, вторая — в край.

## Исправление

frontend/admin-dashboard.html: скоупед-правило
`#deny-box .btn-export{margin-left:0}` — табличное поведение
.btn-export не затронуто.

## Проверка

- python -m pytest tests/test_admin.py tests/test_admin_users.py — 21 passed.
- Дифф: одна CSS-строка. ПМ-исключение с оговоркой (механический
  однострочный фикс; делегация несоразмерна — прецедент процесса).
