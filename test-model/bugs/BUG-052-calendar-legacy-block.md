# BUG-052: Календарь инструктора — несесcный унаследованный блок «Запросы на занятия» без стилей и без модалки

> Автор: PM (main) · Дата: 2026-11-02 · Статус: ИСПРАВЛЕНО

## Симптом

Под слотовым календарем («Мой график на неделю») отображается задвоенный
блок «Запросы на занятия» + сетка «Календарь на неделю» с полностью
несесcной версткой: сырые кнопки-ячейки без сетки, дни сжаты в узкий
столбец, подписи слипаются (скрин Заказчика 2026-11-02). Решения по
брони/запросу в этом блоке выполняются инлайн-панелями — модального окна
отклонения в нем нет («модальное окно отклонения недоступно, даже при
заполнении причины»).

## Корень

Мерж Спринт 8 × BUG-051: bk-block и его JS-контур (openBookings/
bkRenderList/bkBindList/bkRenderGrid) реанимированы из origin/main, а CSS
блока (.dh/.tlabel/.corner/.slot/.bk-cal/.bk-hint/.bk-none — 0 стилей в
итоговом HTML) и часть проводки потеряны. Тесты старого контура
(TC-UI-019/025/026) при сносе «Бронирований» были переписаны на слотовый —
унаследованный блок остался без покрытия.

## Исправление

- instructor-dashboard.html: bk-block удален целиком (фильтры, bk-list,
  внутренняя сетка bk-grid, hint); осиротевшие CSS-правила bk-* сняты.
  Секция «Календарь» — ровно одна сетка .cal-grid с решениями на слотах
  (модалка #m-bk: подтвердить / отклонить с причиной / отменить бронь).
- js/dashboard-instructor.js: resurrect-контур BUG-051 (bkState, openBookings,
  bkRenderList, bkBindList, bkRenderGrid) и вызов openBookings() в
  openCalendar удалены; слотовый контур (calLoadBookings/calMarkBookings,
  модалка #m-bk) не тронут.

## Проверка

- grep: 0 упоминаний bkState/bkRender*/bkBindList/openBookings в JS и
  bk-block/bk-list/bk-grid в HTML.
- Новые e2e: TC-UI-041 (модалка #m-bk: отклонение с причиной, слот
  освобождается; в секции ровно одна сетка, bk-артефакты отсутствуют).
- Прогоны: UI-сьют 52 passed (вкл. TC-UI-041/042); полный — см. PR.
