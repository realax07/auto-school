# BUG-064: docker build приемки 17.7.4 невыполним в среде агента С17 (нет доступа к docker.sock)

- **Обнаружено:** Спринт 17, волна 17.7 (приемка 2026-11-15, worktree
  wt-s17-pdd, ветка feat/s17-pdd-learning). Прогон 17.7.4:
  `docker info` → «permission denied … /var/run/docker.sock»;
  `sudo -n docker` → пароль недоступен (single-query-сессия).
- **Природа:** НЕ дефект кода/образа. Учетная запись агента не в группе
  `docker` (сокет root:docker 660), пароля sudo нет. Контрактные тесты
  контейнера tests/test_container_contract.py — статические (БЕЗ Docker)
  и от этого не зависят; runtime-сборка — job `docker-build` в CI
  (.github/workflows/flow.yml), который выполняется на пуше ветки и
  остается машинным гейтом 17.7.4.
- **Что сделано вместо локальной сборки:** pytest
  tests/test_container_contract.py (compose/Dockerfile/pins/CI — green)
  + проверка состава сборки фронтенда локально (npm run build →
  pdd-чанки, check:budgets (а)–(д) green) + Dockerfile `COPY content/`
  из 17.2.2 уже закрыт волной 17.2.
- **Статус:** OPEN (требуется стенд/CI с docker для локальной реплики
  сборки; CI `docker-build` — действующий гейт на пуше).
