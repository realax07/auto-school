# BUG-051: сайдбар и разделы кабинета инструктора — чистка по Постановке 2026-10-23 (п.6/9/10)

> Автор: PM (main) · Дата: 2026-11-01 · Статус: ИСПРАВЛЕНО

## Симптом (Постановка Заказчика 2026-10-23, пункты 6, 9, 10 + Спринт 7)

1. В сайдбаре кабинета инструктора лишние пункты: «Бронирования»,
   «Мой автомобиль» (старая ДЕМО-заглушка), «Запросы учеников»
   (должен быть подразделом «Моих учеников»).
2. Раздел «Мои документы» должен называться «Профиль и документы»;
   старая ДЕМО-секция «Профиль и документы» (заглушка) — удалиться.
3. Раздел «Бронирования» убрать, функционал слить с «Календарем»
   (п.9: бронь и запросы показывать на выбранных слотах).

## Причина

Сайдбар разрастался спринтами (Спринт 3/5 добавляли кнопки новых разделов,
не убирая демо-заглушки макета add-instructor-cabinet); переименование
«Мои документы» → «Профиль и документы» не делалось при Спринте 7.

## Исправление

- frontend/instructor-dashboard.html:
  - сайдбар: удалены кнопки «Бронирования», «Мой автомобиль»,
    «Запросы учеников»; итоговый перечень: Мой день / Расписание(демо) /
    Календарь / Мои ученики / Мои автомобили / Доходы и выплаты(демо) /
    Материалы и обучение(демо) / Профиль и документы / Выход;
  - «Мои документы» → «Профиль и документы» (data-tab кнопки; заголовок
    шапки раздела переключается по data-tab); ДЕМО-секции «Профиль и
    документы» в разметке не было (демо-таб был toast-заглушкой) — её место
    занял переименованный реальный раздел (#sec-docs, ВУ + СТС по авто);
  - новый раздел «Мои ученики» (#sec-students): вкладки-подразделы
    «Ученики» (карточки привязанных, шейп GET /api/instructor/summary) и
    «Запросы учеников» (переехала секция #sec-requests без изменения
    текстов); виджеты главной и остальные разделы — без виджетов;
  - секция «Бронирования» (#sec-bookings) удалена; её содержимое (список
    запросов/броней + сетка недели с бронями на слотах) перенесено
    БЕЗ изменения текстов в раздел «Календарь» (блок .bk-block под
    сеткой графика) — п.9 Постановки;
  - CSS: добавлены .subtabs/.stu-card/.bk-block (мокап my-students.html,
    ветка feat/s8-package); существующие CSS-строки мокапа не тронуты
    (design-guard тест зеленый).
- frontend/js/dashboard-instructor.js (вне путей ТЗ, но необходимо —
  wiring data-tab живет в модуле; отмечено ПМ):
  - navTo: реальные разделы Календарь/Мои ученики/Мои автомобили/
    «Профиль и документы»; stuSwitch() — переключение подразделов
    «Мои ученики»; openStudents() — карточки привязанных;
  - «Календарь» открывает и брони (openBookings из openCalendar);
    бейджи nav-req-badge/nav-bk-badge удалены вместе с кнопками;
  - старые хеши сохранены: #/my-cars → «Мои автомобили», #/my-docs →
    «Профиль и документы», #/bookings → «Календарь».
- e2e (tests/test_ui_playwright.py): клики по удаленным сайдбар-кнопкам
  переведены (ТC-UI-009/025/026 — через «Мои ученики»→подраздел и
  «Календарь»); test_back_links_lead_to_role_home ассертив новые имена
  и отсутствие удаленных; НОВЫЙ TC-UI-028: сайдбар содержит РОВНО
  ожидаемый перечень, вкладки «Ученики»/«Запросы учеников» переключаются,
  «Профиль и документы» открывает раздел документов, «Календарь» содержит
  подраздел броней. tests/test_instructor_dashboard.py: FR-19-перечень
  обновлен (без удаленных кнопок, с ассертами удаления).

## Хвосты / примечания

- ТЕКСТЫ интерфейса не менялись (design-guard): перенесены дословно;
  новые строки — только подразделы «Ученики»/«Запросы учеников» и
  пустое состояние карточек (фразы виджета «Привязанные ученики»).
- До ответа API разделы показывают честные пустые состояния.
- Подраздел броней в «Календаре» — перенос текущего UI (список + сетка
  слотов); редизайн «брони прямо в сетке графика» — пакет
  add-s8-cars-docs-booking (мокап calendar-booking-s8.html, ветка
  feat/s8-package, в main не смержен).
