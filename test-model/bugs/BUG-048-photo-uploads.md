# BUG-048: загрузка фото не работала (анкета, админ-карточка, автомобили)

> Автор: PM (main) · Дата: 2026-10-21 · Статус: ИСПРАВЛЕНО

## Симптом (Заказчик)

«Не работает загрузка фото: 1) в документах при регистрации водителя;
2) отображение при аппруве заявки; 3) в автомобилях». Требование: после
загрузки — миниатюра вместо области загрузки; в админке просто
отображаться; при ошибке — понятное сообщение.

## Причина

Фронт был «макетом без реальной загрузки»: input #license-file никуда
не был подключен, сабмит шёл JSON без файла; фото авто/ВУ в UI не
отображались, хотя бэкенд (multipart, фото-эндпоинты) был готов.

## Исправление

- instructor-apply.html: реальный multipart-сабмит, миниатюра вместо
  области загрузки, клиентская валидация JPEG/PNG ≤5МБ, файловые ошибки
  сервера — у поля, остальные 422 — в общий notice (MED-1), accept
  приведен к JPEG/PNG (PDF-путь удален — MAJ-1 review-001).
- admin-dashboard.html: фото ВУ в карточке (токен, плейсхолдеры через
  phText/createTextNode — без innerHTML).
- instructor-dashboard.html (авто): миниатюра до отправки, тосты ошибок
  413/415/422, фото в карточке авто.

## Проверка

- Ревью-цикл: review-001 RETURN (MAJ-1 PDF-путь, MED-1) → итерации 2-3 →
  review-002 **APPROVE** (e2e 31/31, новые не внесены).
- Прогоны: dev 31+278; ПМ 31 (дважды) + 43 backend.
