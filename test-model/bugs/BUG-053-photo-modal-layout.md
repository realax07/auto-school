## Повтор (2026-11-04): горизонтальный скролл остался — корень в gal-big

- Повторное обращение Заказчика: полоса горизонтальной прокрутки в модалке
  (изображение шире окна, элементы отъезжают при прокрутке).
- Корень (воспроизведен probe: modal scrollWidth 630 > clientWidth 518;
  mc-big 604×340): CSS `.gal-big{aspect-ratio:16/9;min-height:340px}` —
  min-height через aspect-ratio задает боксу МИНИМАЛЬНУЮ ШИРИНУ
  340×16/9 ≈ 604px > контейнера 468px → overflow:auto модалки скроллит.
  Первая волна фикса (компоновка) это не убрала.
- Фикс: aspect-ratio и min-height сняты; высота задана напрямую
  `height:min(340px,56vw)` — ширина = контейнеру, переполнение исключено
  по построению. Probe после фикса: mc-big 466×340, H-SCROLL no
  (вьюпорты 1206/900).
