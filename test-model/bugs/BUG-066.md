# BUG-066: frontend/vue/node_modules — самоссыльный симлинк в git (сборка NFR-26 невыполнима)

- **Обнаружено:** Спринт 18, волна sidebar-module (2026-11-16, worktree
  auto-school, ветка fix/sidebar-module от fix/noreq-button-layout).
  Гейт `npm run build` падал: vite не находится; `ls -la` →
  `node_modules -> /home/hermes-bot/auto-school/frontend/vue/node_modules`
  (симлинк указывает сам на себя — цикл).
- **Причина:** коммит 377e9aa «[s17-fix] сайдбар (замечание №1)…» от
  2026-11-16 09:48 закоммитил `frontend/vue/node_modules` КАК СИМЛИНК
  (объект git mode 120000, содержимое = абсолютный путь самого себя).
  В .gitignore строка `frontend/vue/node_modules/` уже была — файл попал
  в индекс до нее (вероятно, blanket add в среде, где node_modules был
  симлинком на другой чекаут; здесь путь совпал с самим файлом — цикл).
- **Что сделано:** `git rm --cached frontend/vue/node_modules` (симлинк
  разuntracked, в дереве удален) + `npm install` в frontend/vue (реальный
  каталог, package-lock без изменений). Проверка: `npm run build` → OK
  (14 page-чанков + shared + lazy ПДД), `npm run check:budgets` → OK
  (а)–(д), страницы: 14.
- **Статус:** FIXED (fix/sidebar-module; git-объект симлинка удален —
  cat-file HEAD:frontend/vue/node_modules больше не существует).
