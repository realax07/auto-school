# BUG-061: блок пользователя «Выбора инструктора» уехал влево

- **Источник:** Заказчик, telegram:144324141, 2026-11-07 + скриншот
  (дословно: «В выборе инструктора вот это уехало влево, а должно быть
  справа как у всех»)
- **Симптом:** после BUG-059 (удаление дубля логотипа и крошки из шапки)
  блок ФИО/аватар/«Выйти» остался единственным ребенком шапки с
  `justify-content:space-between` → прижат к ЛЕВОМУ краю; во всех прочих
  кабинетах он справа.
- **Причина:** фикс BUG-059 изменил только media-правило choice-страницы,
  базовое `header{...space-between}` не тронул (cabinet.html был переведен
  на flex-end, instructor-choice — нет).
- **Фикс:** базовое правило → `justify-content:flex-end` в
  frontend/instructor-choice.html и мокапах choice-instructor-a/b.
- **Покрытие:** TC-UI-059 дополнен проверкой позиции (зазор от правого
  края < 40px).
- **Статус:** CLOSED (фикс-волна Спринта 11, follow-up).
