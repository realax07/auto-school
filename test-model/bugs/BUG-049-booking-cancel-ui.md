# BUG-049: отмена брони не работала; UI-дефекты бейджа комплектности и пустого состояния

> Автор: PM (main) · Дата: 2026-10-23 · Статус: ИСПРАВЛЕНО

## Симптом (Заказчик, скрины 2026-10-23)

1. У инструктора не работает отмена брони.
2. В добавлении авто верстка в сообщении о нехватке фото — бейдж
   «Не хватает: …» наезжает на название.
3. У ученика в «Моих бронях» пустое состояние — всё в одну строку.

## Причина

1. Cancel-эндпоинта для подтвержденных броней не существовало (только
   reject по pending).
2/3. Отсутствие flex-wrap в шапке карточки авто; пустое состояние
   сведено в одну строку без блочной верстки.

## Исправление

- backend/booking.py: POST /api/instructor/bookings/{id}/cancel —
  guard status='confirmed', доступ только инструктора пары; статус
  'rejected' (CHECK-ограничение схемы; отдельный статус «Отменена» —
  кандидат на миграцию, замечено ПМ).
- instructor-dashboard.html: flex-wrap бейджа комплектности.
- cabinet.html: вертикальное пустое состояние (заголовок/описание/кнопка).
- e2e: сквозной cancel-флоу (повторная отмена → guard), структурные
  проверки wrap и вертикали (TC-UI-0NN, change add-booking-docs).
