# BUG-044: кабинет инструктора — вёрстка «уезжает» в сайдбар

> Автор: PM (main) · Дата: 2026-10-14 · Статус: ИСПРАВЛЕНО

## Симптом

На /cabinet-instructor весь контент страницы рендерился внутри сайдбара:
одна узкая колонка, боковая рамка по всей высоте, плитки статистики
сжаты. Скриншот Заказчика от 2026-10-14 (мобильный и десктоп вид).

Дополнительно: приветствие «Добрый день, Михаил» захардкожено (имя
не из БД — правка Заказчика п.7), кнопки «Выйти» возле иконки
инструктора не было (п.5).

## Ожидаемое поведение

- Сайдбар слева (236px), main справа — как в макете
  design/mocks/dashboard-instructor.html.
- Кнопка «Выйти» рядом с иконкой инструктора в topbar.
- ФИО в шапке и имя в приветствии — из /api/auth/me.

## Причина

При правке сайдбара (пр#41) регэксп-замена `<aside class="sidebar">…</aside>`
выполнилась по усечённому мокапу: закрывающий `</aside>` был поглощён
заменой — `<main>` остался вложенным в `<aside>`. Flex-контейнер сайдбара
сжал всё содержимое в одну колонку. Юнит-тесты (строковые фрагменты)
этот структурный дефект не ловили.

## Исправление

- frontend/instructor-dashboard.html: восстановлен `</aside>` перед
  `<main>`; кнопка «Выйти» (icon-btn, onclick=logout) возле блока user;
  id=avatar/user-fio/hello-name — заполнение из /api/auth/me (дефолт —
  демо-данные до ответа API).
- design/mocks/dashboard-instructor.html: синхронизирован (Инструктор
  вместо «Инструктор · Категория B», id=hello-name).
