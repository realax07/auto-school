## 4. Шейпы ошибок (FR-19.3/NFR) и «+»/«Скоро» (FR-19.7) — по коду

- Оба шейпа: App.vue:543–546 aiHumanError — контрактному `{ok:false, error:"…"}` доверяет текст (`String(res.data.error)`), машинному/сетевому (422 `{detail:[…]}`, data:null) — общий человеческий текст «Не получилось отправить сообщение. Попробуйте еще раз чуть позже.». Прогон логики на трех входах: contract → «Сообщение: поле пустое» (если придет от сервера), machine {detail} → generic, network null → generic — коды/стеки в UI не проходят. Бэкенд-основание: backend/ai/routes.py — 422 и 503 отдают контрактный `{ok:false, error}`; глобального exception_handler/RequestValidationError в backend нет (grep — 0), т.е. машинный 422 {detail} достижим и фронтоном закрыт. Носители: TC-S19-007/008 (unit), CHK-11, e2e-нога ошибок TC-S19-WEB-004.
- «+» (FR-19.7): App.vue:87–92 / cabinet.html — `#ai-plus` c атрибутом **disabled**, aria-label «Вложения — скоро», рядом `<span class="ai-soon">Скоро</span>`; CSS .ai-plus cursor:not-allowed (styles.css:660). Кнопка отправки `#ai-send` рабочая (без disabled в разметке; на время ответа :disabled="aiBusy"). **(б) «+»/«Скоро» против FR-19.7.**
