## Проверенные Scenario (спека)

- registration: успешная регистрация; пароль только хэшем; незаполненное поле
  (в т.ч. отсутствующий ключ JSON); неверный email; пароль < 8; несовпадение
  подтверждения; дубликат email (422, запись не создается); отклонение не
  уводит с формы (фронт показывает `error`, редирект только при ok);
  переход на /registered при успехе.
- admin: вход (успех/неверный пароль/неизвестный логин → 401 без токена);
  список (fio-склейка, свежий сверху, count); тай-брейк id в одну секунду;
  CSV: BOM+«;»+заголовок, строка на пользователя, «Ученик», санитизация,
  локальная дата, пустой CSV, 401 без/с плохим токеном; токен: валидный /
  отсутствует / поддельный / истекший.
- интеграция: GET /, /registered, /admin-login, /admin-dashboard → 200;
  /api/health → `{"ok": true}`; init_db через lifespan; fetch-контракты
  фронта (register → 200/422; login → token в sessionStorage; дашборд →
  X-Admin-Token, 401 → редирект на /admin-login; CSV через blob) соответствуют
  sdd §3; выборочная сверка текстовок с design/mocks — дословно.
