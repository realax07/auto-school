## Отличия от мокапа (полный список — подтверждено diff'ом, других нет)

Допустимые (wiring, FR-9; sdd §10.2–10.4):

1. HTML-комментарий-шапка дополнен описанием wiring (комментарий, на рендер не влияет).
2. Wiring-блок `<script>` вместо заглушки мокапа:
   - чтение `sessionStorage.session_token` (try/catch);
   - нет токена → `toLogin()`: очистка ключа + `location.href = '/'` (FR-7);
   - `GET /api/auth/me` с заголовком `X-Session-Token`; 401/`!ok` → `toLogin()` (FR-7);
   - 200 → подстановка ФИО: `.uname` = «surname name patronymic», `.greet b` = «Добро пожаловать, {name}!» (FR-5; пример мокапа заменяется данными учетной записи — разрешено сценарием спеки);
   - сетевая ошибка → остаться на странице без подстановки;
   - «Выйти» → `POST /api/auth/logout` → очистка sessionStorage → редирект на главную после любого ответа (FR-8, поток 3);
   - заглушки плиток/чата сохранены, но `.logout` выведен из селектора заглушек (иначе alert перебил бы logout — корректное следствие wiring, поведение клика по плиткам не изменилось).

Недопустимых отличий (тексты, стили, структура, порядок секций) не обнаружено.
