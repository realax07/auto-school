# TC-S12UI-003 — Вход с Vue-лендинга: маршрут-маппинг route/reason не меняется — approved → /instructor/dashboard, waiting → /instructors/pending, rejected → причина в sessionStorage ДО редиректа, ученик → /cabinet

- Автоматизация: `tests/web/test_ui_playwright.py::test_s9_pilot_rejected_redirects_with_reason` (TC-S9UI-003 — прогон без правок: waiting → /instructors/pending, обмен → rejected с причиной через sessionStorage «instructor_rejected_reason», экран /instructors/rejected без входа и перелогина); `tests/web/test_ui_playwright.py::test_instructor_login_approved_dashboard_layout` (TC-UI-005 — вход инструктора approved → /instructor/dashboard через модалку лендинга, без правок); `tests/web/test_login_modal.py::test_login_route_mapping_wiring` (весь route-маппинг §15.5 — дословно в носителе App.vue); API-контракт route/reason — `tests/api/test_auth_route.py` (test_login_instructor_approved_route_cabinet, test_login_waiting_application_pending_no_session, test_login_denied_application_rejected_with_reason, test_login_student_route_student_cabinet — без правок); браузерный заход учеником → /cabinet — ручной шаг кейса
- Приоритет: Must
- Статус: автоматизирован существующими e2e (TC-S9UI-003/TC-UI-005 — дословно, NFR-27); кейс фиксирует трассировку сценария на партию (носитель wiring — App.vue лендинга), новый автотест не пишется
- Трассировка:
  - Requirement: Лендинг ученика на Vue (/) (openspec/changes/add-vue-s12-landing-apply/specs/Frontend/spec.md)
  - Scenario: Вход — route/reason контракт не меняется, включая rejected

## GIVEN / WHEN / THEN
- GIVEN Vue-wiring модалки m-login лендинга (App.vue через src/shared/api.js — postJSON/setToken дословно); заведены: заявка инструктора approved, заявка waiting с токенами опроса, заявка deny с комментарием C, аккаунт ученика
- WHEN из модалки входа на Vue-лендинге выполняется вход каждым пользователем; для rejected — ответ логина route='rejected', reason=C получен
- THEN маршрут-маппинг не изменился: route='cabinet' → /instructor/dashboard (сессия инструктора, кабинет открывается); route='pending' → /instructors/pending (Vue-статусник пилота); route='rejected' → sessionStorage «instructor_rejected_reason» = C записан ДО редиректа на /instructors/rejected (причину читает экран С11 — TC-S9UI-003 проходит без правок селекторов/логики); default 'student-cabinet' → /cabinet (ручной шаг: wait_for_url **/cabinet, ФИО ученика в шапке); ошибка входа (401/403/сеть) — текст сервера в #login-error (res.data.error — дословно); порядок `res.status===200&&res.data.ok` до route-разбора сохранен (test_login_route_mapping_wiring — фрагменты дословны)
