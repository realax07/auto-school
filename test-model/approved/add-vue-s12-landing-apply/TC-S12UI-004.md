# TC-S12UI-004 — Регистрация с Vue-лендинга: согласие обязательно (FR-78) — #reg-submit недоступен до #reg-consent; 200 → сессия и /cabinet; 422 без consent → текст сервера в #reg-error; ссылка /policy в блоке согласия

- Автоматизация: `tests/web/test_ui_playwright.py::test_student_register_redirects_to_cabinet` (TC-UI-002 — 200 → сессия и редирект /cabinet, прогон без правок); `tests/web/test_ui_playwright.py::test_register_modal_consent_gates_submit_and_links_policy` (TC-UI-043 — #reg-submit недоступен до #reg-consent, ссылка /policy видна, прогон без правок); `tests/api/test_register.py::test_s9_register_consent_missing_or_false_422_in_regression` (422 без consent/consent=false — контракт сервера); `tests/api/test_register.py::test_tc_reg_008_no_record_created_on_any_rejection` (отклоненная регистрация запись не создает); `tests/api/test_policy.py::test_s9_policy_link_visible_in_both_consent_blocks` (TC-PD-005 — ссылка /policy в обоих согласиях, носитель перенесен на вход + App.vue)
- Приоритет: Must
- Статус: автоматизирован существующими e2e + API (TC-UI-002/043 — дословно, NFR-27); кейс фиксирует трассировку сценария на партию, новый автотест не пишется
- Трассировка:
  - Requirement: Лендинг ученика на Vue (/) (openspec/changes/add-vue-s12-landing-apply/specs/Frontend/spec.md)
  - Scenario: Регистрация — согласие обязательно (FR-78)

## GIVEN / WHEN / THEN
- GIVEN модалка m-register на Vue-лендинге (#reg-surname/#reg-name/#reg-patronymic/#reg-email/#reg-phone/#reg-password/#reg-password-confirm/#reg-consent/#reg-submit/#reg-error; `.reg-check a[href='/policy']`); кнопка #reg-submit связана `:disabled` с состоянием чекбокса (эквивалент Vue для `regSubmit.disabled=!regConsent.checked` — семантика FR-78)
- WHEN чекбокс согласия снят / установлен и форма отправлена (POST /api/register с consent)
- THEN #reg-submit недоступен до установки #reg-consent и становится доступен после; с consent=true: 200 → {ok, token} → setToken → location.href='/cabinet' — сессия ученика открыта (TC-UI-002 — дословно); без consent (снятие чекбокса либо прямой POST с consent=false/без ключа): 422 {ok:false, error} → текст сервера в #reg-error, запись не создана (API — дословно); ссылка на /policy видна в блоке согласия и открывает страницу политики (TC-UI-043/TC-PD-005 — без правок)
