# TC-S12UI-006 — Анкета на Vue: согласие обязательно — 422 позиция 1a (FR-77); ошибки файла ВУ (не JPEG/PNG, >5 МБ, 413/415) — текст «Файл: …» у #license-error, прочие — notice

- Автоматизация: `tests/web/test_ui_playwright.py::test_instructor_apply_consent_gates_submit_and_links_policy` (TC-UI-045 — кнопка сабмита недоступна до чекбокса согласия, ссылка /policy, прогон без правок); `tests/api/test_instructors_apply.py::test_apply_order_consent_checked_before_email_format` (422 позиция 1a — согласие проверяется раньше email-формата); `tests/api/test_instructors_apply.py::test_apply_validation_contract_422` (контрактные 422-тексты сервера по полям — без правок; файловых «Файл: …» сервер в этой партии НЕ выдает — серверная валидация файла ВУ вне объема партии, instructors.py:12-14); `tests/api/test_instructors_apply.py::test_apply_fio_three_required_fields` (обязательные поля); клиентская валидация ВУ в браузере (выбор файла >5 МБ / не-JPEG-PNG → #license-error до отправки; миниатюра/ошибка BUG-048; позиционирование ошибки у поля загрузки; notice под формой) — ручные шаги кейса
- Приоритет: Must
- Статус: ручной; consent-гейт и серверный контракт 422 — автотесты без правок (NFR-27)
- Трассировка:
  - Requirement: Анкета инструктора на Vue (/instructors/apply) (openspec/changes/add-vue-s12-landing-apply/specs/Frontend/spec.md)
  - Scenario: Согласие обязательно — 422 позиция 1a (FR-77)
  - Scenario: Ошибки файла ВУ — видимое сообщение у поля загрузки

## GIVEN / WHEN / THEN
- GIVEN анкета на Vue (/instructors/apply): `.checkline input` связан `:disabled` кнопки сабмита (FR-77); upload-блок с #license-file/#license-thumb/#license-error/#file-name; клиентская валидация JPEG/PNG ≤ 5 МБ (`5*1024*1024` — дословно, validateLicenseFile)
- WHEN (а) анкета заполнена, чекбокс согласия НЕ установлен — попытка сабмита и прямой POST без согласия; (б) выбран файл ВУ >5 МБ / не-JPEG-PNG; (в) сервер отвечает 413/415; (г) прочие ошибки полей / ошибка сети
- THEN (а) кнопка сабмита недоступна на клиенте; прямой POST без согласия отвечает 422 {ok:false, error:"Согласие: поле обязательно"} — позиция 1a, заявка НЕ создана (API — дословно, test_apply_order_consent_checked_before_email_format); (б) клиентская валидация показывает текст у #license-error ДО отправки — тексты дословно legacy-клиентские («Файл: изображение больше 5 МБ» / «Файл: допустимы только изображения JPEG или PNG» — validateLicenseFile 1:1 apply.js; серверных файловых текстов в этой партии нет — instructors.py:12-14), отправка блокирована; (в) 413/415 — файловые тексты у поля загрузки #license-error + notice под формой (защитный клиентский маппинг 1:1 legacy — сервер 413/415 не возвращает); (г) прочие 422 (включая согласие при прямом POST) и ошибка сети («Ошибка сети») — notice под формой; тексты 1:1 с legacy; сессия по заявке не выдается — sessionStorage на странице не используется (ручная проверка)
