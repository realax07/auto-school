# TC-S12UI-002 — Модалки входа/регистрации на Vue-лендинге: открыть/закрыть (крестик, «Отмена», Esc; фон НЕ закрывает), снятие open_login-флагов, заглушки чат-бара

- Автоматизация: `tests/web/test_ui_playwright.py::test_bug056_landing_login_modal_close_semantics` (TC-UI-053 — прогон без правок: «Войти» открывает #m-login, фон НЕ закрывает, Esc и крестик #login-close закрывают); `tests/web/test_login_modal.py::test_tc_auth_login_modal_texts_verbatim` и `test_tc_auth_login_modal_no_stub_submit` (разметка модалок между комментариями «Модалка: Вход/Регистрация» — дословно, носитель переносится на вход frontend/vue/index.html); «Отмена», снятие sessionStorage open_login/open_login_from при закрытии (BUG-056), alert-заглушки #ai-open/.quick/#to-teachers — ручные шаги кейса
- Приоритет: Must
- Статус: ручной; семантика закрытия и тексты модалок — автотесты без правок (NFR-27); модалки вынесены в shared-компоненты каркаса (`src/shared/LoginModal.vue`, `src/shared/RegisterModal.vue`) — разметка 1:1
- Трассировка:
  - Requirement: Лендинг ученика на Vue (/) (openspec/changes/add-vue-s12-landing-apply/specs/Frontend/spec.md)
  - Scenario: Семантика модалок и заглушки сохранены

## GIVEN / WHEN / THEN
- GIVEN гость на Vue-лендинге (/); модалки m-login/m-register смонтированы в статической разметке входа (паттерн «статическая разметка + гидрация» пилота), wiring — в App.vue (data-open/data-close/Esc)
- WHEN открыты и закрыты модалки всеми способами; нажаты элементы-заглушки; модалка закрыта после глубокого захода (sessionStorage open_login/open_login_from установлен — сценарий «вернуться к входу»)
- THEN «Войти» (.auth [data-open="login"]) и «Регистрация» ([data-open="register"]) открывают #m-login / #m-register (.overlay.open); крестик #login-close, кнопка «Отмена» и Esc закрывают модалку с остатком на лендинге; клик по фону НЕ закрывает #m-login (BUG-055/056); при закрытии sessionStorage open_login/open_login_from снимаются; чат-бар «Гига ГАИшник» (#ai-open), кнопки .quick (5) и #to-teachers ведут себя как в legacy — визуальные заглушки с теми же alert-текстами, реальных запросов к /api/* нет; в сабмите модалок нет заглушечных onSubmit (test_tc_auth_login_modal_no_stub_submit — без правок)
