# TC-S14-006 — «Мои документы» /instructor/documents — новая страница на Vue: вход из dist без легаси-монолита (BUG-047), список ВУ/СТС с версиями и статусами ОВ-1/ОВ-7, просмотр действующей, доступ только владельцу

- Автоматизация: `tests/api/test_auth_route.py::test_new_static_routes_served` (GET /instructor/documents — 200 text/html, НОВЫЙ маршрут без правок теста); `tests/api/test_s8_backend.py` — test_s8_license_version_lifecycle_and_reject_reason (версии ВУ, отклонение с причиной ОВ-7), test_s8_sts_primary_replacement_and_admin_flow (СТС по авто, статусы ОВ-1/ОВ-7), test_s8_sts_replacement_keeps_validated_ov6, test_s8_empty_sts_rule_seed_branch_agree (авто без СТС), test_s8_my_documents_versions_and_empty_state (список/пустое состояние), test_s8_access_matrix (401 без сессии, 403 ученику/чужому инструктору, чужой doc_id — 404, file только владельцу); тот же контракт в e2e раздела кабинета — TC-UI-033/034 (`tests/web/test_ui_playwright.py::test_s8_my_documents_statuses_versions_and_license_replace`, `::test_s8_admin_documents_verify_reject_preview_history`); негативный список standalone design-guard (documents.html запрещен) — в test_ui_playwright БЕЗ ПРАВОК; html-вход со ссылками /vue/assets, прямой URL, ручной smoke на dist задачи 3.3 (список/просмотр/замена-диалог/гвард/logout) — ручные шаги кейса
- Приоритет: Must
- Статус: ручной (approved-кейс партии change add-vue-s14-instructor-loop, Спринт 14); контракт API списка/файла/доступа и маршрут 200 — автотесты; отдача входом каркаса и экран новой страницы — ручные шаги (smoke 3.3 на приемке)
- Трассировка:
  - Requirement: Мои документы на Vue (/instructor/documents) (openspec/changes/add-vue-s14-instructor-loop/specs/Frontend/spec.md)
  - Scenario: Новая страница обслуживается каркасом Vue
  - Scenario: Список и версии — контракт не меняется
  - Scenario: Доступ только владельцу

## GIVEN / WHEN / THEN
- GIVEN сборка каркаса выполнена; маршрут /instructor/documents добавлен в `_PAGE_ROUTES` как `vue:documents.html`; легаси-монолит frontend/documents.html НЕ создан (design-guard BUG-047 «standalone-страницы запрещены» сохраняется); инструктор А с ВУ и автомобилями, включая авто без СТС; документы принадлежат только инструктору А
- WHEN инструктор А открывает /instructor/documents (прямой URL — ссылок из сайдбара нет по design); гость без сессии открывает тот же URL; ученик и другой инструктор запрашивают список/файл; затем — чтение списка GET /api/instructor/documents (+ /api/instructor/cars для дозагрузки)
- THEN страница отдается входом каркаса Vue (html со ссылками на /vue/assets/documents-*), маршрут новый, другие маршруты не затронуты; ВУ и СТС по каждому авто показаны с типом/привязкой/датой действующей версии и статусами «Действует»/«Ожидает проверки замены»/«Отклонено» с причиной (ОВ-1/ОВ-7); авто без СТС — карточка «нет СТС» с кнопкой загрузки; просмотр — действующая версия через GET /api/instructor/documents/{doc_id}/file; гость без сессии возвращается на вход (гвард /api/auth/me → «/»), чужие сессии получают отказ API 401/403 (чужой doc_id — 404), страница редиректится на «/»

## Примечание
- Автоматизация поведенческой части — контракты API (test_s8_backend.py, без правок) и e2e того же функционала в разделе кабинета (TC-UI-033/034, прогон 6.1 без правок, NFR-27); НОВОГО носителя-страницы поведенческие e2e не получают по плану партии — её экран покрыт ручным smoke задачи 3.3 (список/просмотр/замена-диалог/гвард/logout — green).
- Достижимость прямым URL при отсутствии ссылок из сайдбара — сознательное состояние (proposal, «Out of scope»); инвариант BUG-047 для documents.html закреплен параметризацией design-guard без правок.
- Замена/загрузка с предупреждением FR-71 — отдельный кейс TC-S14-007.
