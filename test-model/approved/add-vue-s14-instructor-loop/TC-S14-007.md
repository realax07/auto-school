## GIVEN / WHEN / THEN
- GIVEN инструктор с действующим ВУ и СТС по авто; на новой странице /instructor/documents (носитель mcValidatePhoto/m-replace — перенос 1:1 раздела С8); собран dist всех восьми входов каркаса
- WHEN инструктор нажимает «Заменить» у документа, открывается диалог; проверяются отмена и подтверждение; подается недопустимый файл (не JPEG/PNG, >5 МБ); для авто без СТС выполняется дозагрузка; затем — `npm run check:budgets` на артефактах сборки
- THEN диалог показывает предупреждение «замена вступит в силу только после проверки администратором…»; отмена — файл НЕ отправлен; подтверждение явной кнопкой «Заменить» — POST на контрактный эндпоинт (multipart), после успеха список перезагружен, версия в статусе «Ожидает проверки замены» (до верификации админом — ветка ОВ-1); недопустимый файл отклонен клиентской валидацией с текстами сервера; тосты — тексты legacy дословно; дозагрузка СТС создает версию по контракту POST /api/instructor/cars/{id}/photo/sts (автотест без правок); бюджеты: каждый vendor-чанк ≤150 КБ gzip, JS первого захода КАЖДОЙ из 8 страниц (page-чанк + static-import graph) ≤200 КБ gzip, в бандле страницы нет чужих page-чанков (multi-entry MPA — SPA/router/pinia запрещены)
