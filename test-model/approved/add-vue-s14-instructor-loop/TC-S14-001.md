- Приоритет: Must
- Статус: ручной (approved-кейс партии change add-vue-s14-instructor-loop, Спринт 14); тексты/CTA/маршрут 200 — автотесты без правок сценариев (NFR-27)
- Трассировка:
  - Requirement: Лендинг инструкторов на Vue (/instructors) (openspec/changes/add-vue-s14-instructor-loop/specs/Frontend/spec.md)
  - Scenario: Лендинг обслуживается каркасом Vue
  - Scenario: Визуальная эквивалентность и CTA анкеты

## GIVEN / WHEN / THEN
- GIVEN сборка каркаса выполнена (`npm ci && npm run build` в frontend/vue, dist существует); маршрут /instructors переключен на `vue:instructors.html` в `_PAGE_ROUTES` (backend/app.py); легаси `frontend/instructors.html` и `frontend/js/instructors.js` удалены; контент входа = дословный перенос legacy-разметки + модуль `src/pages/instructors/`
- WHEN гость (чистый контекст браузера, без сессии) открывает /instructors; затем — поблочное сопоставление содержимого с допартийным лендингом инструкторов; отдельная проверка того же маршрута при отсутствующем dist (чистая рабочая копия без сборки)
- THEN страница отдается входом каркаса Vue — HTML со ссылками на ассеты префикса /vue/ (`/vue/assets/instructors-*.<hash>.js`), а не legacy-HTML-монолитом; маршрут /instructors не изменился; эквивалентность без редизайна: бренд (.brand em «Сбер»), hero «Учи водить. Меняй подход.», форматы own/sber, блок возможностей, нижний CTA, футер без входа для учеников — тексты дословно (носитель test_instructors_landing_texts_verbatim); CTA шапки/hero/карточек/кнопка #open-form ведут на /instructors/apply (носитель test_instructors_cta_wiring_to_apply + TC-UI-003); без dist маршрут отвечает 404 (паттерн `vue:`-маркера С11), после пересборки — снова 200

- Механика отдачи `vue:`-маркера — design.md «Роуты и статика»; перенос носителя §4.1 — прецедент 2.3 пилота, 3.1 С11, 4.1 С12 (design.md «Границы правок тестов»).
- 404 без dist — задокументированное поведение локального регресса без сборки; в CI/образе dist собирается всегда.
- Автоматизация поведенческой части уже существует (принцип Н5): кейс фиксирует трассировку и ручной остаток, автотесты не дублируются.
