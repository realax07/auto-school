# TC-ADD-009 — Повторный старт без побочных эффектов

- ID кейса: TC-ADD-009
- Источник: Requirement: Идемпотентная инициализация БД при старте
- Сценарий спеки: Scenario: Повторный старт без побочных эффектов
- Спека: openspec/changes/add-containerization/specs/containerization/spec.md (FR-53)
- Тип: позитивный
- Приоритет: Must

## Сценарий (GIVEN/WHEN/THEN)

- **GIVEN** тот же том с уже актуализированной схемой
- **WHEN** контейнер перезапускается
- **THEN** старт проходит без ошибок повторного применения миграций, данные не дублируются и не портятся

## Ожидаемый результат

старт проходит без ошибок повторного применения миграций, данные не дублируются и не портятся. Отклонение от THEN (иная формулировка статуса/содержимого) — дефект контейнера TC-ADD-009.
