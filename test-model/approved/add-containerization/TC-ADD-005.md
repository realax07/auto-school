# TC-ADD-005 — Секреты не зашиты в образ

- ID кейса: TC-ADD-005
- Источник: Requirement: Секреты вне образа и сегментация сетей
- Сценарий спеки: Scenario: Секреты не зашиты в образ
- Спека: openspec/changes/add-containerization/specs/containerization/spec.md (NFR-14, NFR-16)
- Тип: позитивный
- Приоритет: Must

## Сценарий (GIVEN/WHEN/THEN)

- **GIVEN** образ приложения собран
- **WHEN** образ и контекст сборки инспектируются
- **THEN** ни один секрет (админ-креды, ключи MinIO, TLS-ключи) не присутствует в слоях образа и в контексте сборки — секреты приходят только через env_file и монтирования

## Ожидаемый результат

ни один секрет (админ-креды, ключи MinIO, TLS-ключи) не присутствует в слоях образа и в контексте сборки — секреты приходят только через env_file и монтирования. Отклонение от THEN (иная формулировка статуса/содержимого) — дефект контейнера TC-ADD-005.
