# TC-ADD-001 — Сборка образа на чистой машине

- ID кейса: TC-ADD-001
- Источник: Requirement: Образ приложения
- Сценарий спеки: Scenario: Сборка образа на чистой машине
- Спека: openspec/changes/add-containerization/specs/containerization/spec.md (FR-51, NFR-11, NFR-12)
- Тип: позитивный
- Приоритет: Must

## Сценарий (GIVEN/WHEN/THEN)

- **GIVEN** чистая машина с установленным Docker и копия репозитория
- **WHEN** выполняется сборка образа из репозитория
- **THEN** сборка проходит без ручных шагов, запуск образа поднимает uvicorn, а процесс в контейнере работает не от root

## Ожидаемый результат

сборка проходит без ручных шагов, запуск образа поднимает uvicorn, а процесс в контейнере работает не от root. Отклонение от THEN (иная формулировка статуса/содержимого) — дефект контейнера TC-ADD-001.
