# TC-ADD-012 — Прогон тестов внутри поставляемого образа

- ID кейса: TC-ADD-012
- Источник: Requirement: Тесты внутри контейнера на том же образе
- Сценарий спеки: Scenario: Прогон тестов внутри поставляемого образа
- Спека: openspec/changes/add-containerization/specs/containerization/spec.md (FR-55, NFR-17)
- Тип: позитивный
- Приоритет: Must

## Сценарий (GIVEN/WHEN/THEN)

- **GIVEN** собранный образ приложения
- **WHEN** внутри контейнера из этого образа выполняется pytest с временной БД
- **THEN** тесты проходят, и в постоянных томах не остается артефактов прогона

## Ожидаемый результат

тесты проходят, и в постоянных томах не остается артефактов прогона. Отклонение от THEN (иная формулировка статуса/содержимого) — дефект контейнера TC-ADD-012.

## Примечания

- Кейс утвержден на основе спек-дельты add-containerization; code-review пакета —
  code-reviews/add-containerization/review-001.md (вердикт по находкам F-1..F-7).
- Runtime-прогон (docker build / compose up) выполняется на Docker-стенде (задача 5.1);
  статический контракт проверяет tests/test_container_contract.py (TC-ADD-трассировка).
