# TC-ADD-007 — MinIO готов принимать данные, файлы пока на volume

- ID кейса: TC-ADD-007
- Источник: Requirement: Секреты вне образа и сегментация сетей
- Сценарий спеки: Scenario: MinIO готов принимать данные, файлы пока на volume
- Спека: openspec/changes/add-containerization/specs/containerization/spec.md (NFR-14, NFR-16)
- Тип: позитивный
- Приоритет: Must

## Сценарий (GIVEN/WHEN/THEN)

- **GIVEN** стек поднят
- **WHEN** проверяется сервис MinIO
- **THEN** MinIO доступен из внутренней сети стека и хранит данные на своем томе, при этом загрузки приложения продолжают работать через локальный volume (S3-адаптер — отдельный объем)

## Ожидаемый результат

MinIO доступен из внутренней сети стека и хранит данные на своем томе, при этом загрузки приложения продолжают работать через локальный volume (S3-адаптер — отдельный объем). Отклонение от THEN (иная формулировка статуса/содержимого) — дефект контейнера TC-ADD-007.
