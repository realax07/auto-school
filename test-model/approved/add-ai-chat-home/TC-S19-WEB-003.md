# TC-S19-WEB-003 — Композер: «+» видима и неактивна с подписью «Скоро» (ничего не открывает), отправка рабочая; hit-targets ≥44px; композер не перекрыт таб-баром (390×844)

- Автоматизация: носителя НЕТ (19.3.4 открыт) — пишет qa_automation в этой волне: e2e `tests/web/test_ui_playwright.py` на 390×844 (мобильная нога) + 1440×900 (десктопная): #ai-plus disabled + подпись .ai-soon «Скоро» + клик ничего не открывает (нет модалок/шитов); bounding box .ai-plus ≥44×44 и .ai-send ≥44×44 на ≤760px (факт реализации: 44/48; десктоп 48/54); клик по «+» и по отправке доходит (низ #ai-composer выше верха .mtabs 54px, зазор композера по измерению 19.3.3); рабочая отправка — нога кейса TC-S19-WEB-002.
- Приоритет: Must (FR-19.7; 19.3.3 — лейаут по измерениям 390×844/1280×800)
- Статус: не автоматизирован — кейс партии change add-ai-chat-home (новый, 19.4); автоматизация — qa_automation (волна 19.3.4/19.4)
- Трассировка:
  - Requirement: Композер отправляет сообщение и показывает ответ ассистента (openspec/changes/add-ai-chat-home/specs/ai-chat/spec.md)
  - Scenario: Кнопка «+» и отправка (FR-19.7)
  - Scenario: Ожидание и ошибка — нога «UI не висит молча» (NFR)
  - Носитель: e2e 390×844 (план прогонов №3); статические хит-таргеты — против стилей ai-* в styles.css (@media ≤760px)

## GIVEN / WHEN / THEN
- GIVEN ученик вошел в кабинет, «Главная» открыта на вьюпорте 390×844 (затем 1440×900); композер видим над таб-баром
- WHEN проверены кнопка «+» (#ai-plus), подпись «Скоро» (.ai-soon), кнопка отправки (#ai-send), их размеры и доступность кликов; выполнен клик по «+»; выполнен клик по отправке с непустым текстом; композер измерен против таб-бара
- THEN «+» видима и неактивна (disabled, aria-label «Вложения — скоро», подпись «Скоро») — клик ничего не открывает (вложений/модалок/шитов нет); кнопка отправки рабочая — сообщение уходит (FR-19.3); размеры целей на 390px: «+» = 44×44, отправка = 48×48 (≥44px); на десктопе 48/54; композер не перекрыт таб-баром (54px): клики по «+»/отправке доходят без перехвата, страница 390×844 без скролла (высота #sec-home по константе компоновки)

## Примечание
- ВАЖНО: «+»/«Скоро» в утвержденных макетах ОТСУТСТВУЮТ — сверка не с макетом, а с FR-19.7 (требование Заказчика, зафиксировано в задаче 19.4.2); вербатим-гарды макетов «+» не содержат — не считать расхождением.
- disabled на время ответа (aiBusy) у поля и отправки — поведение TC-S19-WEB-002/005; здесь проверяется только «+» (постоянно disabled) и геометрия.
- Тексты/структура композера по макетам (плейсхолдер и т.д.) — кейс TC-S19-WEB-001; этот кейс — про семантику кнопок и геометрию.
