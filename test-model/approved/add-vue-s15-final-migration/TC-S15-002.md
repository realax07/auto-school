- GIVEN админ с валидным admin_token в /admin-dashboard (вход через _seed_session — паттерн e2e); сборка dist выполнена; разделы «Пользователи», «Заявки инструкторов», «Автомобили», «Документы» — внутри одной страницы
- WHEN открыты все четыре раздела; выгружен CSV; выполнены модерация заявки (карточка, предпросмотр ВУ, approve с confirm, deny с комментарием), валидация комплекта автомобиля, верификация/отказ документа
- THEN GET /api/admin/users рендерится как в legacy (textContent-эквиваленты, «Записей: N», #users-table/#rows/#count/#empty); «↓ Выгрузить CSV» скачивает users.csv через blob — серверные контракты 1:1 (TC-ADM-008…010 без правок); таблица заявок без колонки «Действия» (BUG-046: желтый wait-бейдж, rowhint), deny-кнопка #ic-deny-confirm disabled до комментария, confirm('Одобрить заявку?…') при одобрении (dialog-handler e2e без правок); комплектность/validate #ac-*, верификация ВУ/СТС #dc-* — якоря и контракты 1:1 (TC-UI-006/011/013/014 и admin-сценарии без правок); password_hash в UI отсутствует (TC-MOD-002, носитель вход+App.vue)
