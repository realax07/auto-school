# TC-S20-002 — «Ещё» bottom-sheet: разделы и Выход

- **Требование:** instructor-mobile / «Таб-бар инструктора ≤760px» (позиция «Ещё»)
- **Носитель:** tests/web/test_instructor_tabbar.py::test_s20_instructor_tabbar_and_more_sheet
- **Приоритет:** Must

## Шаги (вручную, 390×844)
1. Нажать таб «Ещё» → открывается bottom-sheet (grab-хендл, затемнение).
2. В шите: Календарь / Мои ученики / Мои автомобили / Материалы и обучение / Выход (5 строк).
3. Нажать «Календарь» — шит закрывается, открывается раздел.

## Ожидаемо
- Шит показывает 5 строк; клик по разделу закрывает шит и переключает раздел; «Выход» завершает сессию.
