# TC-S17-007 — Целостность контента проверяется на сборке: гейты генератора (80×20/один ✅/картинки/321 знак/join-биекция/допуски desc/fine/26 глав/3 поля штрафов) — провал сборки при нарушении (R7: 3 сценария)

- Автоматизация: unit `tests/unit/test_pdd_generator.py` (14 тестов; прогон генератора как subprocess на РЕАЛЬНОМ корпусе — фикстура generated): позитив `test_pravila_26_chapters_with_title_and_html` + `test_pravila_chapter10_title_from_corpus_h1` (26 файлов, ровно один H1, заголовок = H1 корпуса), `test_znaki_8_groups_and_321_signs` (8 групп, 321 знак), `test_znaki_join_by_title_number_bijective` (номер из title details биективен номерам group-md в ОБЕ стороны; группа — только из group-md), `test_znaki_desc_empty_only_allowed_numbers` (desc пуст ТОЛЬКО у 5.33.1/5.34.1 — гейт-допуск), `test_znaki_fine_optional_166` (fine опционален, непуст у 166/321), `test_znaki_images_exist_whitelist` (у каждого знака существует <номер>small.png; t8-формат обработан), `test_bilety_80_tickets_20_questions_one_correct` (80 билетов × 20 вопросов, ровно один ✅, 2–5 вариантов), `test_bilety_image_links_exist_whitelist` (каждая ссылка ../images/bilety/* из JSON существует на диске — факт 1094/1094; whitelist: unreferenced файлы не попадают в выдачу), `test_bilety_abm_01_question_texts_from_corpus`, `test_shtrafi_rows_three_fields` (58 строк × 3 tab-поля), `test_manifest_counts_match_outputs`; НЕГАТИВ `test_build_fails_on_missing_ticket_image` (symlink-копия корпуса с удалённым изображением вопроса → генератор завершается ошибкой, process.exit≠0, с указанием файла/вопроса — dist не собирается)
- Приоритет: Must
- Статус: автоматизированный прогон на приемке/регрессе (approved-кейс партии change add-pdd-learning, Спринт 17); файлы корпуса content/pdd/** руками не правятся — только перегенерация (правки корпуса = падение/починка гейтов на сборке)
- Трассировка:
  - Requirement: Целостность контента проверяется на сборке (openspec/changes/add-pdd-learning/specs/learning/spec.md)
  - Scenario: Сборка падает на недостающем изображении
  - Scenario: Сборка падает на неожиданной пустоте desc или номере вне group-md
  - Scenario: Позитивный прогон на текущем корпусе

## GIVEN / WHEN / THEN
- GIVEN корпус content/pdd/ (80×20 вопросов с 1094 ссылками на изображения, 321 знак, znaki-details.json 321 записи: desc 319/321 — пусты ровно 5.33.1/5.34.1, fine 166/321, 26 глав, 58 строк штрафов); гейты реализованы в generate-pdd-json.mjs (fail-выходы: пустой desc вне допуска — «znaki-details: пустой desc у <номер>… допуск только 5.33.1/5.34.1», номер вне group-md — биекция в обе стороны, и др.)
- WHEN выполняется генератор (npm run build): позитивно на текущем корпусе и негативно — на symlink-копии корпуса с недостающим изображением вопроса (unit) либо с искусственно испорченной znaki-details.json (ручной негатив на приемке через PDD_CONTENT_DIR)
- THEN позитив: все проверки проходят (включая допуски desc/fine и whitelist изображений), JSON созданы без потерянных данных, манифест сходится, повторный прогон идемпотентен; негатив (авто): генератор завершается ошибкой с указанием файла/вопроса, dist не собирается; негатив (ручной): пустой desc у номера вне {5.33.1, 5.34.1} или номер записи, не найденный среди номеров group-md, → ошибка с указанием slug/номера записи, сборка падает

## Примечание
- Ручной остаток: негатив «пустой desc у чужого номера / номер вне group-md» НЕ имеет собственного автотеста (автоматизирован один негатив — недостающее изображение, прецедент «минимального негатива» tasks 17.7.2a); сами fail-гейты есть в коде генератора (строки fail() на desc-допуск и join-биекцию) — ручная проба на приемке: копия корпуса через env PDD_CONTENT_DIR с испорченной записью → генератор падает с указанием slug.
- Группа знака берётся ТОЛЬКО из group-md (long записи — мусор источника «Предупреждающие у всех 321» — игнорируется; наивное использование свалило бы все знаки в одну группу) — закреплено гардой join-теста.
