## GIVEN / WHEN / THEN
- GIVEN чистая выкачка репозитория (pdd-data/ отсутствует, .gitignore) и корпус content/pdd/; Route /pdd-assets/{group}/{file} в backend/app.py по паттерну /vue/assets (ADR-001: один сервис отдает API и статику; nginx отклонён), группы ровно znaki|bilety
- WHEN выполняется npm ci && npm run build (дважды), запрашиваются /pdd-assets/znaki/1.1small.png и /pdd-assets/bilety/6942508s.jpg, чужие пути (/pdd-assets/other/x.png, /pdd-assets/znaki/../secret, неизвестный суффикс, скрытый файл), открывается /cabinet и после загрузки кликается «Знаки»
- THEN генератор создает JSON из content/pdd/ (pdd-data/*.json), vite собирает dist с lazy-чанками секций pdd-* и чанками билетов; повторный прогон байт-идентичен (рассинхрон корпуса невозможен по построению — генератор перезаписывает всё, в git не коммитится); изображения отдаются статикой с корректным media-type по ЯВНОЙ карте (.png/.gif/.jpg/.jpeg — не зависеть от системных mimetypes), любой другой путь — 404 (угадывание не вводится), traversal («..», «/», скрытые) — 404; файлов изображений в dist/assets нет (48 МБ не в бандле — роут читает content/pdd/images вне vite); при первом заходе /cabinet pdd-чанки не входят в статическое замыкание (правило (д)), чанк секции и его данные грузятся при первом клике (visited-паттерн)

## Примечание
- Ручные остатки: `docker build` невыполним в среде агента (BUG-064, OPEN) — действующий гейт сборки образа с corpus: CI job `docker-build` на PR (контрактные тесты контейнера — статические, зеленые; состав COPY не проверяется контрактом — осознанно, прецедент С16); сетевой факт «до первого клика браузер не запрашивал pdd-* чанки» — проба Network на приемке (машинно закрыто правилом (д) гейта бюджетов: в статическом замыкании lazy-чанков нет, visited-паттерн ставит загрузку за первым кликом).
- Запрос /pdd-assets маршрута публичный без auth — как /vue/assets (материалы — публичные учебные; design «Решение 1»).
