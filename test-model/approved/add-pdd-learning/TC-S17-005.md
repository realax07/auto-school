## GIVEN / WHEN / THEN
- GIVEN раздел «Штрафы» открыт (#/pdd-fines); данные — pdd-shtrafi.json генератора (все tab-строки таблицы корпуса «shtrafi-gibdd.md»; сейчас 58; блок «Популярные штрафы» источника — навигационный, НЕ данные, не рендерится)

- THEN показаны ВСЕ строки корпуса (58 на момент спринта) с колонками «Пункт КоАП»/«Нарушение»/«Наказание»; при вводе остаются только строки, содержащие подстроку в любой из трёх колонок БЕЗ учёта регистра (число строк сверено с независимым пересчётом по корпусу), фильтрация — клиентская, без перезагрузки; очистка возвращает все строки; при отсутствии совпадений таблица пуста и показано сообщение об отсутствии результатов («Ничего не найдено по запросу…»)
