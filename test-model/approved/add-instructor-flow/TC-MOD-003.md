# TC-MOD-003 — Клик по строке заявки открывает действия «Одобрить» и «Отклонить»

- ID кейса: TC-MOD-003
- ID чеклиста: CHK-24
- Источник: CHK-24 → Requirement «Раздел заявок инструкторов в админке» (домен admin-moderation) → FR-14; Scenario «Клик по строке открывает действия»
- Тип: позитивный
- Приоритет: Must
- Статус: manual/toBeAutomated (браузерный клик по строке — вне TestClient; API-часть действий — automated: TC-MOD-004/005/007/008)

## GIVEN / WHEN / THEN
- GIVEN администратор вошел в админку; в таблице «Заявки инструкторов» есть хотя бы одна заявка
- WHEN администратор нажимает на строку заявки
- THEN становятся доступны действия «Одобрить» и «Отклонить»

## Предусловия
- Браузер/Playwright; админ авторизован (admin / admin-pass-2026); одна waiting-заявка создана публичным apply.
- Сервис запущен, /api/health → 200.

## Шаги
1. Открыть админку, раздел «Заявки инструкторов».
2. Найти строку заявки в таблице.
3. Кликнуть по строке.
4. Зафиксировать появление действий.

## Ожидаемый результат
3. Строка раскрывается/открывает панель действий.
4. Доступны обе кнопки: «Одобрить» и «Отклонить».

## Тестовые данные
Заявка — базовый валидный набор (TC-APP-005): instructor@example.com. Админ: admin / admin-pass-2026.
