# TC-APP-007 — Негатив: поочередно пустое каждое обязательное поле → 422

- ID кейса: TC-APP-007
- ID чеклиста: CHK-7
- Источник: CHK-7 → Requirement «Сохранение заявки со статусом waiting» (домен instructor-application) → FR-11; Scenario «Отклонение некорректно заполненной анкеты»
- Тип: негативный
- Приоритет: Must
- Статус: automated — tests/test_instructors_apply.py::test_apply_validation_contract_422 (параметризовано все обязательные поля: ФИО, Телефон, Email, Адрес, Формат работы, Номер ВУ, Категория прав, Пароль, Подтверждение пароля) + ::test_apply_sber_format_allows_empty_plate (plate не обязателен при sber). Плановые ID в docstring действуют до утверждения (rule 6)

## GIVEN / WHEN / THEN
- GIVEN анкета заполнена базовым валидным набором
- WHEN поочередно каждое обязательное поле (по звездочкам макета + пароль + подтверждение: fio, phone, email, address, work_format, license_number, license_category, password, password_confirm) опустошается и анкета отправляется
- THEN на каждый вариант 422 {"ok": false, "error": "<поле-ру>: поле обязательно"}; заявка НЕ создана (в instructor_applications 0 записей)

## Предусловия
- Сервис собран через create_app() с роутером instructors; TestClient без сети; чистая БД в tmp, init_db.

## Шаги
1. Для каждого из 9 обязательных полей выполнить POST /api/instructors/apply с базовым набором, где поле = "" (отдельный запрос на поле).
2. Зафиксировать статус и тело каждого ответа.
3. После каждого запроса SELECT COUNT(*) FROM instructor_applications.

## Ожидаемый результат
1–2. Каждый ответ 422 с сообщением: «ФИО: поле обязательно», «Телефон: поле обязательно», «Email: поле обязательно», «Адрес: поле обязательно», «Формат работы: поле обязательно», «Номер ВУ: поле обязательно», «Категория прав: поле обязательно», «Пароль: поле обязательно», «Подтверждение пароля: поле обязательно».
3. После каждого запроса COUNT = 0 — заявка НЕ создана.

## Тестовые данные
Базовый валидный набор (TC-APP-005); вариации — пустая строка в одном из 9 полей за прогон. Поле plate НЕ входит (обязателен только при work_format='own', CHK-13).
