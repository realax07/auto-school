# TC-APP-004 — Граница: формат «автомобиль Сбера» блокирует госномер

- ID кейса: TC-APP-004
- ID чеклиста: CHK-4
- Источник: CHK-4 → Requirement «Анкета заявки инструктора» (домен instructor-application) → FR-11; Scenario «Переключение формата работы меняет доступность госномера»
- Тип: граничный
- Приоритет: Must
- Статус: manual/toBeAutomated (браузерное переключение radio — вне TestClient; косвенный автоконтроль wiring — tests/test_instructor_pages.py::test_apply_work_format_toggles_plate: plate.disabled=!own, очистка значения при !own)

## GIVEN / WHEN / THEN
- GIVEN открыта анкета /instructors/apply, выбран формат «свой автомобиль», поле госномера доступно
- WHEN пользователь выбирает «автомобиль Сбера», затем возвращается на «свой автомобиль»
- THEN при «автомобиль Сбера» поле госномера становится недоступным для ввода (disabled, значение очищается); при возврате на «свой автомобиль» поле снова доступно

## Предусловия
- Браузер/Playwright; /instructors/apply открыта.

## Шаги
1. Открыть /instructors/apply; убедиться, что выбран «свой автомобиль» и поле госномера активно.
2. Ввести в госномер значение «А123АА 777».
3. Выбрать «Хочу работать на автомобиле Сбера» → зафиксировать состояние поля (disabled? значение?).
4. Выбрать обратно «У меня есть свой автомобиль» → зафиксировать состояние поля.

## Ожидаемый результат
1. Поле госномера доступно для ввода.
3. Поле недоступно (disabled), введенное значение очищено (поведение мокапа).
4. Поле снова доступно для ввода.

## Тестовые данные
Значение госномера: «А123АА 777».
