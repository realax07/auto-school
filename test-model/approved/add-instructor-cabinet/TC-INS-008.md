# TC-INS-008 — Демо-изоляция: содержимое кабинета не раскрывает данные БД

- ID кейса: TC-INS-008
- ID чеклиста: CHK-8
- Источник: CHK-8 → Requirement «Соответствие утвержденному макету кабинета» → FR-19; Scenario «Данные кабинета — демо»
- Тип: негативный (демо-изоляция)
- Приоритет: Must
- Статус: automated — tests/test_instructor_dashboard.py::test_dashboard_contains_demo_payload (плановый ID TC-FR19D-006: демо-ключи ответа, 4 stats, 4 appointments, next_lesson) + test_dashboard_200_for_instructor_with_fio (demo: true); UI-проверка метки «Все данные вымышлены» — manual/toBeAutomated

## GIVEN / WHEN / THEN
- GIVEN инструктор открыл кабинет; в БД есть реальные записи (заявки, пользователи)
- WHEN он просматривает содержимое блоков (статистика, расписание, занятия, операции) и тело ответа GET /api/instructor/dashboard
- THEN содержимое блоков — демо-данные макета; метка «Все данные вымышлены» присутствует; реальные данные БД (заявки, пользователи, кроме ФИО/email учетки) не выводятся; в ответе demo: true, эндпоинт отдает только ФИО/email учетки + демо-константы

## Предусловия
- Инструктор создан флоу apply → approve → login; в БД заведомо есть реальные записи (минимум — сама учетка инструктора и админ).
- Для UI-части: браузер/Playwright.

## Шаги
1. Войти инструктором; GET /api/instructor/dashboard с токеном.
2. Проверить тело ответа: ok=true, demo=true; ключи stats (4 элемента), schedule, appointments (4), next_lesson, vehicle, operations — демо-константы (sdd §20.1: _DEMO_*).
3. Проверить состав данных об учетке: только instructor.{surname, name, patronymic, email}; поля id и прочие данные БД в ответе отсутствуют.
4. (UI) Открыть кабинет; проверить, что блоки показывают демо-значения макета (84 600, Александр Иванов, Škoda Rapid и т.д.) и футер «Демонстрационный интерфейс · Все данные вымышлены»; email инструктора и его ФИО — единственные реальные значения.

## Ожидаемый результат
1–3. 200; demo=true; демо-ключи присутствуют; реальных данных БД (список заявок, другие пользователи, id) в ответе нет.
4. В UI демо-данные макета + метка вымышленности; реальные записи БД не отображаются.

## Тестовые данные
Инструктор: instr@example.com; демо-константы сверять с _DEMO_STATS/_DEMO_APPOINTMENTS/_DEMO_NEXT_LESSON backend/dashboard.py.
