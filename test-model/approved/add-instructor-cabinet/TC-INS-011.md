# TC-INS-011 — Выбор раздела «Расписание» меняет заголовок, контент демо

- ID кейса: TC-INS-011
- ID чеклиста: CHK-11
- Источник: CHK-11 → Requirement «Разделы сайдбара — визуальное переключение на демо-данных» → FR-21; Scenario «Выбор раздела меняет заголовок, контент остается демо»
- Тип: позитивный
- Приоритет: Must
- Статус: automated — частично (tests/test_instructor_dashboard.py::test_dashboard_page_nav_sections_fr19, плановый ID TC-FR21D-008: nav-кнопки, navTo, пометка «демо», активен «Мой день»); браузерная часть (клик, смена заголовка/крошки, контент остается демо) — manual/toBeAutomated (Playwright; сигнал риска review-001-3.1 — требует исполнения JS)

## GIVEN / WHEN / THEN
- GIVEN инструктор открыл кабинет (активен раздел «Мой день»), валидная сессия
- WHEN он выбирает раздел «Расписание» в сайдбаре
- THEN заголовок страницы (h1) и хлебная крошка меняются на «Расписание», содержимое остается демо-данными, раздел помечен как демо

## Предусловия
- Инструктор вошел, кабинет открыт ( navTo-механика мокапа на месте, nav-кнопки достроены).
- Для UI-части: браузер/Playwright.

## Шаги
1. (UI) Войти инструктором, открыть /instructor/dashboard; зафиксировать: заголовок «Мой день», крошка «Мой день».
2. Кликнуть nav-кнопку data-tab="Расписание".
3. Зафиксировать текст h1 (#page-title) и крошки (#crumb), содержимое блоков, наличие пометки «демо» у раздела.

## Ожидаемый результат
2. Кнопка становится активной (класс active переносится).
3. h1 = «Расписание», крошка «Рабочее пространство / Расписание»; содержимое блоков — те же демо-данные; у раздела видна пометка «демо»; реальных запросов данных раздела не выполнено.

## Тестовые данные
Инструктор: instr@example.com / Instr1234; раздел: data-tab="Расписание".
