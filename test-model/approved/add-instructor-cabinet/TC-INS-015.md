# TC-INS-015 — Повторный доступ после выхода → 401, редирект

- ID кейса: TC-INS-015
- ID чеклиста: CHK-15
- Источник: CHK-15 → Requirement «Выход из кабинета» → FR-22; Scenario «После выхода повторный доступ к кабинету отклоняется»
- Тип: негативный
- Приоритет: Must
- Статус: automated — API-часть (tests/test_instructor_dashboard.py::test_dashboard_401_after_logout, плановый ID TC-FR18D-003: logout → повторный вызов 401 {"ok":false}); браузерная часть (страница не открывается, редирект на главную) — manual/toBeAutomated (Playwright)

## GIVEN / WHEN / THEN
- GIVEN инструктор выполнил выход (токен аннулирован на сервере)
- WHEN он открывает /instructor/dashboard повторно без входа (старый токен в sessionStorage или отсутствует)
- THEN GET /api/instructor/dashboard → 401 {"ok": false}; страница не открывается — редирект на главную (к модалке входа)

## Предусловия
- Инструктор вошел и выполнил выход (любым из двух путей TC-INS-013/TC-INS-014); сервис собран (create_app(), чистая БД).
- Для UI-части: браузер/Playwright.

## Шаги
1. Войти инструктором, зафиксировать токен.
2. POST /api/auth/logout с токеном → 200.
3. GET /api/instructor/dashboard с тем же токеном.
4. (UI) После выхода попытаться вернуться на /instructor/dashboard (кнопка «назад» браузера / прямой URL) без повторного входа.

## Ожидаемый результат
2. 200 — выход выполнен.
3. 401, тело точно {"ok": false} — токен аннулирован (не «истек», а именно аннулирован logout'ом).
4. Контент кабинета не отрисован; редирект на `/` (к модалке входа).
