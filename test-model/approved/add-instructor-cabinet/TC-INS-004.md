- Тип: негативный
- Приоритет: Must
- Статус: automated — API-часть (tests/test_instructor_dashboard.py::test_dashboard_403_for_student_session, плановый ID TC-FR18D-004); браузерная часть (страница не показывается, редирект на главную) — manual/toBeAutomated (Playwright)

## GIVEN / WHEN / THEN
- GIVEN пользователь с ролью 'student' с валидной сессией (вход выполнен успешно)
- WHEN он открывает /instructor/dashboard (GET /api/instructor/dashboard с его X-Session-Token)
- THEN бэкенд отвечает 403 {"ok": false}; код 403 отличим от 401; страница не показывается, редирект на главную

## Предусловия
- Сервис собран (create_app(), чистая БД); зарегистрирован ученик базового набора; вход ученика выполнен, токен валиден (проверка порядка: sdd §20.1 — сессия валидна, role != 'instructor').
- Для UI-части: браузер/Playwright.

## Шаги
1. Зарегистрировать ученика, выполнить POST /api/auth/login, зафиксировать токен.
2. GET /api/instructor/dashboard с X-Session-Token: <токен ученика>.
3. (UI) Войти учеником, открыть /instructor/dashboard, наблюдать поведение.

## Ожидаемый результат
2. 403 (не 401 — сессия валидна; distinct-семантика), тело точно {"ok": false}.
3. Кабинет не отрисован; редирект на `/` (к модалке входа).
