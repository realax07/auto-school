# TC-VUD-001 — Анкета с изображением ВУ сохраняет файл на сервере

- ID кейса: TC-VUD-001
- ID чеклиста: CHK-1
- Источник: CHK-1 → Requirement «Сохранение файла ВУ при подаче анкеты» (домен instructor-documents) → FR-23; Scenario «Заявка с изображением ВУ сохраняет файл»
- Тип: позитивный
- Приоритет: Must
- Статус: ручной (не исполнялся; автоматизация — после утверждения кейсов, контракт 6; плановые TC-ID в docstring автотестов действуют до утверждения, rule 6)

## GIVEN / WHEN / THEN
- GIVEN анкета инструктора заполнена корректно (все поля как в Спринте 2) и выбран файл изображения ВУ (JPEG, 2 МБ)
- WHEN выполняется POST /api/instructors/apply (multipart, поле license_photo)
- THEN заявка создана; файл сохранен на сервере в data/uploads/license/; запись заявки хранит license_photo_path, указывающий на сохраненный файл

## Предусловия
- Сервис собран через create_app() (uvicorn, single-worker); допускается TestClient без сети (паттерн tests/conftest.py). Чистая БД (AUTOSCHOOL_DB_PATH в tmp), init_db при старте. Контроль живости: GET /api/health → 200 {"ok": true}.
- Сессии/данные фикстур: одобренные инструкторы А и Б (approved-заявка, Спринт 2; users.role='instructor'), ученик с валидной сессией (role='student'), X-Admin-Token администратора (Спринт 0). Сессии получены через /api/auth/login.
- Все запросы к API передают токены в заголовках X-Session-Token / X-Admin-Token (механика Спринтов 0–2).

## Шаги
1. Подготовить валидные поля анкеты и файл license.jpg (JPEG, 2 МБ).
2. POST /api/instructors/apply multipart с полями анкеты и license_photo=license.jpg.
3. Зафиксировать статус-код и id заявки из ответа.
4. Проверить наличие файла в data/uploads/license/ и поле license_photo_path записи заявки (БД).

## Ожидаемый результат
2. 200/201 {ok:true}, заявка создана.
3–4. Файл существует на диске; license_photo_path в заявке не NULL и указывает на сохраненный файл.
