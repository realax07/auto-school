# TC-VUD-006 — Карточка инструктора в админке: с ВУ и без ВУ

- ID кейса: TC-VUD-006
- ID чеклиста: CHK-11, CHK-12
- Источник: CHK-11/12 → Requirement «Карточка инструктора в админке с изображением ВУ» (instructor-documents) → FR-25; Scenarios «Клик по строке открывает карточку с данными и ВУ», «Карточка заявки без ВУ»
- Тип: позитивный + граничный
- Приоритет: Must
- Статус: ручной (не исполнялся; автоматизация — после утверждения кейсов, контракт 6; плановые TC-ID в docstring автотестов действуют до утверждения, rule 6)

## GIVEN / WHEN / THEN
- GIVEN в таблице админки есть заявка с загруженным ВУ (id1) и заявка без ВУ (id2); админ авторизован токеном
- WHEN админ кликает по строке заявки (открывается детальная карточка, GET /api/admin/instructor-applications/{id})
- THEN для id1 карточка показывает полные данные анкеты и изображение ВУ; для id2 — данные анкеты показаны, место изображения — корректное пустое состояние (не ошибка, не «битая» картинка)

## Предусловия
- Сервис собран через create_app() (uvicorn, single-worker); допускается TestClient без сети (паттерн tests/conftest.py). Чистая БД (AUTOSCHOOL_DB_PATH в tmp), init_db при старте. Контроль живости: GET /api/health → 200 {"ok": true}.
- Сессии/данные фикстур: одобренные инструкторы А и Б (approved-заявка, Спринт 2; users.role='instructor'), ученик с валидной сессией (role='student'), X-Admin-Token администратора (Спринт 0). Сессии получены через /api/auth/login.
- Все запросы к API передают токены в заголовках X-Session-Token / X-Admin-Token (механика Спринтов 0–2).

## Шаги
1. GET /api/admin/instructor-applications (таблица), найти id1 и id2.
2. Открыть карточку id1: проверить полноту данных анкеты и наличие/отрисовку изображения ВУ (license-image отдался с токеном).
3. Открыть карточку id2: проверить данные анкеты и отображение пустого состояния на месте изображения (UI).

## Ожидаемый результат
2. Данные анкеты дословно из заявки; изображение ВУ отрисовано.
3. Данные показаны; на месте изображения — заглушка/подпись «нет файла» без JS-ошибок и битых <img>.

## Тестовые данные
Проверка UI-части — браузер (Playwright), не строковым тестом (паттерн чеклиста add-instructor-cabinet).
