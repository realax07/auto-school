# TC-S11UI-003 — Без ключа/с пустой причиной: блок причины скрыт, статусных запросов при загрузке НОЛЬ; sessionStorage недоступен — тихо

- Автоматизация: нет — ручной кейс (Playwright route-capture: регистрация счетчика на `**/api/**` + чтение sessionStorage/computed-стиля блока)
- Приоритет: Must
- Статус: ручной (approved-кейс партии change add-vue-s11-status-forms, Спринт 11)
- Трассировка:
  - Requirement: Статусный экран отказа заявки на Vue (/instructors/rejected) (openspec/changes/add-vue-s11-status-forms/specs/Frontend/spec.md)
  - Scenario: Без причины — блок скрыт, запросов нет

## GIVEN / WHEN / THEN
- GIVEN чистый контекст браузера — ключ «instructor_rejected_reason» отсутствует; отдельная ветка того же кейса — ключ есть, но значение пустая строка; на страницу зарегистрирован capture-счетчик всех запросов к /api/*
- WHEN /instructors/rejected открыт по прямой ссылке (гость, без входа); третья ветка — sessionStorage программно недоступен (стаб-объект, бросающий исключение при обращении)
- THEN блок причины #reason-block скрыт, #reason-text не виден — персональная причина не раскрывается (чужую не показываем, design); сетевых запросов к API — 0 (capture стабилен: статус при загрузке не проверяется — наследование FR-17, причина приходит только из ответа логина); ветка «sessionStorage недоступен» — тихо, без ошибки в консоли и без причины на экране (try/catch, design.md таблица обработки ошибок)

## Примечание
- Партия change add-vue-s11-status-forms (Спринт 11, задача 2.1 — поведение
  js/instructor-rejected.js воспроизведено в App.vue onMounted).
- Счетчик запросов — обязательный элемент кейса: «0 обращений к API» —
  прямое требование сценария спеки, глазом по вкладке Network не
  верифицируется.
