- Автоматизация: `tests/web/test_ui_playwright.py::test_s4_my_requests_badges_deny_comment_retry_and_review_link` (TC-UI-018 — переход из «Моих заявок» у принятой заявки → /review?instructor=<id>, #i-name с реальным ФИО — дословно); агрегат API — TC-UI-017 (rating.count/average)
- Приоритет: Must
- Статус: ручной — поля #i-ava/#i-sub/#i-rating (оба варианта агрегата); переход и #i-name покрыты TC-UI-018 без правок (NFR-27)
- Трассировка:
  - Requirement: Форма отзыва на Vue (/review) (openspec/changes/add-vue-s11-status-forms/specs/Frontend/spec.md)
  - Scenario: Контекст инструктора и переход из «Моих заявок»

## GIVEN / WHEN / THEN
- GIVEN ученик с принятой заявкой; сессия ученика на входе Vue /review?instructor=<id>: GET /api/auth/me заполнил #uname и инициалы #avatar (FR-5); сервер отвечает на GET /api/student/instructors/{id} карточкой с агрегатом FR-35
- WHEN карточка инструктора отрисована; затем — переход из кабинета («Мои заявки», кнопка отзыва у принятой заявки)
- THEN #i-name — ФИО инструктора (якорь TC-UI-018 без правок); #i-ava — инициалы; #i-sub — «Стаж N <expWord>» + автомобили через «·» (агрегат слова expWord — перенос из shared/utils.js); #i-rating — оба варианта 1:1 legacy: с отзывами «X.X ★» + «N отзывов учеников», без отзывов «☆» + «отзывов пока нет»; переход из «Моих заявок» открывает /review?instructor=<id> с заполненной карточкой (TC-UI-018)
