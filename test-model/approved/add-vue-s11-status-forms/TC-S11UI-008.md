# TC-S11UI-008 — Ошибки формы отзыва — реакции 1:1 legacy: 401 → вход, 403 → тост без редиректа, 422/прочие → тост, GET контекста not ok → «Инструктор не найден»

- Автоматизация: нет — ручной кейс (Playwright route-моки ответов POST/GET; server-гварды 403/422/409 покрыты на API — backend/reviews.py без изменений, NFR-2/NFR-5)
- Приоритет: Must
- Статус: ручной (approved-кейс партии change add-vue-s11-status-forms, Спринт 11)
- Трассировка:
  - Requirement: Форма отзыва на Vue (/review) (openspec/changes/add-vue-s11-status-forms/specs/Frontend/spec.md)
  - Scenario: Ошибки формы — тосты как в legacy

## GIVEN / WHEN / THEN
- GIVEN ученик на входе Vue /review?instructor=<id>; route-моки управляют ответами GET /api/student/instructors/{id} и POST …/reviews; заполнены rating и текст
- WHEN сервер возвращает ошибки — по ветке на каждую
- THEN реакции 1:1 legacy (design.md таблица): GET-и 401/403 и отсутствие токена → toLogin() — редирект на главную, к модалке входа (единый паттерн кабинетов через src/shared/api.js handleAuthFail); POST 401 → toLogin() (только 401 — сессионный маркер); POST 403 → тост с error сервера (бизнес-ошибка NFR-2) БЕЗ редиректа, кнопка #send снова активна; POST 422/прочие → тост (error сервера || «Не удалось отправить отзыв»), кнопка активна; GET контекста not ok → тост «Инструктор не найден»; network (status 0) → ветка «прочие» — тост «Не удалось отправить отзыв»; длительность тостов 3200 мс, тексты и один таймер на страницу — как в legacy (#toast, перенос в src/shared/utils.js)

## Примечание
- Партия change add-vue-s11-status-forms (Спринт 11, задача 2.2); серверные
  проверки POST не трогаются — клиент воспроизводит только реакции
  (design.md «Решения по НФТ», NFR-2/NFR-5).
- Ключевое различие веток: 401 — редирект; 403 — остаемся на форме с тостом
  (NFR-2); проверяется отсутствием смены URL при 403.
