# TC-S11UI-001 — Экран отказа /instructors/rejected обслуживается входом каркаса Vue: гость по прямой ссылке, ассеты /vue/, без dist → 404

- Автоматизация: `tests/api/test_auth_route.py::test_new_static_routes_served` (маршрут /instructors/rejected → 200 text/html — частично); проверка /vue/-входа и 404 без dist — ручные шаги кейса
- Приоритет: Must
- Статус: ручной (approved-кейс партии change add-vue-s11-status-forms, Спринт 11); маршрутный 200 — автотест без правок (NFR-27)
- Трассировка:
  - Requirement: Статусный экран отказа заявки на Vue (/instructors/rejected) (openspec/changes/add-vue-s11-status-forms/specs/Frontend/spec.md)
  - Scenario: Экран обслуживается каркасом Vue

## GIVEN / WHEN / THEN
- GIVEN сборка каркаса выполнена (`npm ci && npm run build`, dist существует); легаси `frontend/instructor-rejected.html` и `frontend/js/instructor-rejected.js` удалены из репозитория; маршрут /instructors/rejected зарегистрирован в `_PAGE_ROUTES` с маркером каркаса `vue:instructors-rejected.html` (отдача из `VUE_DIST_DIR`)
- WHEN гость (чистый контекст браузера, без сессии) открывает /instructors/rejected по прямой ссылке; затем — отдельная проверка того же маршрута при отсутствующем dist (чистая рабочая копия без сборки)
- THEN страница отдается входом каркаса Vue — HTML со ссылками на ассеты префикса /vue/ (`/vue/assets/*.<hash>.js|.css`), а не legacy-HTML-монолитом; маршрут не изменился (/instructors/rejected — тот же URL, на который ведет логин route='rejected'); у страницы нет сессионного контракта — гость видит нейтральный экран отказа; без dist маршрут отвечает 404 (паттерн пилотного хендлера /instructors/pending), после пересборки — снова 200

## Примечание
- Партия change add-vue-s11-status-forms (Спринт 11, задачи 3.1/3.2 — перенос
  маршрута на dist, ADR-008 п.4 — замена монолита целиком); механика отдачи
  `vue:`-маркера — design.md «Роуты и статика».
- 404 без dist — задокументированное поведение локального регресса без сборки
  (design.md «Dockerfile / compose / CI»); в CI/образе dist собирается всегда.
