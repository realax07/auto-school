# TC-S11UI-005 — Форма отзыва /review обслуживается входом каркаса Vue; редирект-контракт без ?instructor= сохранен (301 → /cabinet#/my-requests)

- Автоматизация: `tests/api/test_s3_backend.py::test_s4_static_route_review` (TC-S3BE-040: /review → 200 text/html, «Оставить отзыв» — без правок); `tests/api/test_s3_backend.py::test_bug047_old_routes_redirect_301` (301 /my-requests → /cabinet#/my-requests); редирект из формы — `tests/web/test_ui_playwright.py::test_s4_review_submit_then_repeat_blocked_409` (TC-UI-017, goto /review без параметра → wait_for_url /cabinet#/my-requests — дословно); якорь back-ссылки — TC-UI-019 (путь чтения перенесен на вход каркаса)
- Приоритет: Must
- Статус: ручной — проверка /vue/-входа; контрактные части (200, 301, редирект из формы) покрыты существующими автотестами без правок (NFR-27)
- Трассировка:
  - Requirement: Форма отзыва на Vue (/review) (openspec/changes/add-vue-s11-status-forms/specs/Frontend/spec.md)
  - Scenario: Страница обслуживается каркасом Vue
  - Scenario: Без ?instructor= — редирект в кабинет

## GIVEN / WHEN / THEN
- GIVEN сборка каркаса выполнена (dist существует); легаси `frontend/review-form.html` и `frontend/js/review-form.js` удалены; маршрут /review зарегистрирован в `_PAGE_ROUTES` с маркером `vue:review-form.html`; `_PAGE_REDIRECTS` без изменений (/my-requests → /cabinet#/my-requests, 301)
- WHEN ученик открывает /review?instructor=<id>; отдельные ветки — /review без query-параметра и /review?instructor=0
- THEN страница отдается входом каркаса Vue — HTML со ссылками на ассеты префикса /vue/, а не legacy-монолитом; маршрут /review и query-параметр не изменились; заголовок «Оставить отзыв» присутствует в разметке входа (якорь TC-S3BE-040); back-ссылка `<a class="back" href="/my-requests">← Назад к заявкам</a>` — в статической разметке входа (якорь TC-UI-019); без идентификатора (нет/0) — переход на /my-requests, который отдает 301 → /cabinet#/my-requests — раздел «Мои заявки» (#sec-requests, «Заявки инструкторам») открывается ВНУТРИ кабинета (BUG-047); редирект-контракт не изменен

  одной сессии работ; гейт — 5.1 (design.md «Роуты и статика»).
