# TC-ADM-004 — Границы учетных данных: пустой логин и/или пароль

- ID кейса: TC-ADM-004
- ID чеклиста: CHK-22
- Источник: CHK-22 → Requirement «Вход администратора» (домен admin) → FR-5; граница сценариев входа
- Тип: граничный
- Приоритет: Must

## Предусловия
- Сервис запущен (uvicorn, single-worker); базовый URL: http://127.0.0.1:8000.
- БД data/app.db инициализирована (init_db при старте), таблица users пуста (чистое тестовое окружение).
- Окружение .env задано: ADMIN_USER, ADMIN_PASSWORD_HASH (bcrypt), SECRET.
- Контроль живости: GET /api/health -> 200 {"ok": true}.

## Шаги
1. POST /api/admin/login: {"login": "", "password": "<верный пароль>"}.
2. POST /api/admin/login: {"login": "<ADMIN_USER>", "password": ""}.
3. POST /api/admin/login: {"login": "", "password": ""}.
4. В каждом ответе проверить статус и наличие ключа token.

## Ожидаемый результат
1–4. Каждый из трех прогонов: 401 {"ok": false}; token в теле отсутствует.

## Тестовые данные
- Прогон 1: пустой логин + верный пароль; Прогон 2: верный логин + пустой пароль; Прогон 3: оба пустые.
