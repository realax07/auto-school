# TC-REG-018 — Лендинг и модалки соответствуют макетам дословно

- ID кейса: TC-REG-018
- ID чеклиста: CHK-18
- Источник: CHK-18 → Requirement «Соответствие утвержденным макетам» (домен registration) → FR-9; Scenario «Лендинг и модалки соответствуют макетам»
- Тип: позитивный
- Приоритет: Must

## Предусловия
- Реализация перенесена: frontend/ содержит index.html, registered.html, admin-login.html, admin-dashboard.html; эталон — design/mocks.
- Инструмент сравнения (diff) доступен.

## Шаги
1. Побайтово/посимвольно сравнить frontend/index.html с design/mocks/index.html; зафиксировать все отличия.
2. Аналогично сравнить registered.html, admin-login.html, admin-dashboard.html.
3. Для каждого отличия классифицировать: относится ли оно к предписанному wiring (поля Пароль/Подтверждение в модалке регистрации, блок показа ошибки под формой, fetch/redirect-JS).
4. Выборочно проверить в браузере: заголовки и текстовки на страницах совпадают с макетами посимвольно.

## Ожидаемый результат
1–2. Заголовки и все текстовки совпадают с design/mocks дословно (посимвольно).
3. Отличия — ТОЛЬКО предписанный wiring: два новых поля Пароль/Подтверждение, блок вывода ошибки, JS (fetch на /api/register, редиректы). Иных текстовых/структурных расхождений нет.
4. Отображаемые текстовки совпадают с макетами.

## Тестовые данные
- Специальные тестовые данные не требуются; используются значения из предусловий и шагов.

## Примечания (дефекты спеки)
- D9 (недоопределено): «структура страниц совпадает» не имеет детерминированного критерия; FR-9 принят как мануальная проверка текстовок (дословно) + контроль wiring. Экспертная оценка структуры — за ревьюером.
