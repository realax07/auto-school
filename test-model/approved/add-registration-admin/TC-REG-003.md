# TC-REG-003 — Пароль не хранится в открытом виде

- ID кейса: TC-REG-003
- ID чеклиста: CHK-3
- Источник: CHK-3 → Requirement «Сохранение регистрации ученика» / «Пароль не хранится в открытом виде» (домен registration) → FR-1, FR-3; Scenario «Пароль не хранится в открытом виде»
- Тип: позитивный
- Приоритет: Must

## Предусловия
- Сервис запущен (uvicorn, single-worker); базовый URL: http://127.0.0.1:8000.
- БД data/app.db инициализирована (init_db при старте), таблица users пуста (чистое тестовое окружение).
- Окружение .env задано: ADMIN_USER, ADMIN_PASSWORD_HASH (bcrypt), SECRET.
- Контроль живости: GET /api/health -> 200 {"ok": true}.
- Для админ-проверок: валидный токен администратора (POST /api/admin/login с ADMIN_USER и паролем, соответствующим ADMIN_PASSWORD_HASH).

## Шаги
1. POST /api/register с базовым пользователем (пароль P = «Qwerty123»).
2. Дамп таблицы users (SELECT * FROM users;) — поиск подстроки «Qwerty123» во всех колонках.
3. GET /api/admin/users с заголовком X-Admin-Token — поиск подстроки «Qwerty123» в теле ответа (fio, email, phone, created_at).
4. GET /api/admin/users/export.csv с заголовком X-Admin-Token — поиск подстроки «Qwerty123» в теле CSV.
5. Убедиться, что в записи присутствует password_hash и он не равен «Qwerty123».

## Ожидаемый результат
1. 200 {"ok": true}.
2. Подстрока «Qwerty123» в хранилище не встречается ни в одной колонке.
3. Подстрока «Qwerty123» в списке админки отсутствует.
4. Подстрока «Qwerty123» в CSV-выгрузке отсутствует.
5. password_hash присутствует, непуст и != «Qwerty123» (см. TC-REG-014/015 — проверка самого хэша).

## Тестовые данные
Базовый валидный пользователь (все 7 полей):
```json
{
  "surname": "Петрова-Водкина",
  "name": "Анна",
  "patronymic": "Оттовна",
  "email": "petrova@example.com",
  "phone": "+7 (912) 345-67-89",
  "password": "Qwerty123",
  "password_confirm": "Qwerty123"
}
```

## Примечания (дефекты спеки)
- D8 (ограничение проверяемости): FR-1/FR-3 «пароль нигде не сохраняется» — универсальный квантор полностью не проверяем; область кейса ограничена хранилищем + списком админки + CSV. Логи сервера — вне области спринта 0 (подтвердить у ПМ).
