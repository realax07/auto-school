# TC-REG-017 — Отклонение регистрации не уводит со страницы регистрации

- ID кейса: TC-REG-017
- ID чеклиста: CHK-17
- Источник: CHK-17 → Requirement «Страница «Регистрация завершена»» (домен registration) → FR-4; Scenario «Отклонение не уводит со страницы регистрации»
- Тип: негативный
- Приоритет: Must

## Предусловия
- Браузерное окружение для UI-проверки (Playwright/ручной прогон), открыть http://127.0.0.1:8000.
- Сервис запущен; БД data/app.db доступна для контрольной сверки записей.

## Шаги
1. Открыть лендинг, открыть модалку регистрации.
2. Заполнить форму с ошибкой: email = "ivanov.example" (без @), остальные поля валидные.
3. Отправить форму.
4. Зафиксировать URL, наличие и текст сообщения под формой.
5. Попытка открыть /registered напрямую — зафиксировать поведение.
6. SELECT COUNT(*) FROM users;

## Ожидаемый результат
3–4. Пользователь остается на форме регистрации (URL /, модалка открыта); под формой показан текст причины отклонения («Email: неверный формат email»); редиректа нет.
5. Страница /registered не открывается как результат отклоненной регистрации (редирект на нее не выполнялся; прямой заход — статическая страница без созданной записи, шаг фиксирует отсутствие автоматического перехода).
6. COUNT(*) = 0.

## Тестовые данные
- email: `ivanov.example`; остальные поля — из базового набора.
