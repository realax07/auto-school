# TC-ADM-015 — Запрос с подделанным/несуществующим токеном

- ID кейса: TC-ADM-015
- ID чеклиста: CHK-33
- Источник: CHK-33 → Requirement «Токен доступа к админ-API» (домен admin) → FR-8; Scenario «Запрос с неверным токеном»
- Тип: негативный
- Приоритет: Must

## Предусловия
- Сервис запущен (uvicorn, single-worker); базовый URL: http://127.0.0.1:8000.
- БД data/app.db инициализирована (init_db при старте), таблица users пуста (чистое тестовое окружение).
- Окружение .env задано: ADMIN_USER, ADMIN_PASSWORD_HASH (bcrypt), SECRET.
- Контроль живости: GET /api/health -> 200 {"ok": true}.

## Шаги
1. Ничего не логинясь, выполнить GET /api/admin/users с заголовком X-Admin-Token: "forged-token-0123456789abcdef" (значение, которое система не выдавала).
2. Зафиксировать статус и тело.
3. GET /api/admin/users/export.csv с тем же поддельным токеном.

## Ожидаемый результат
1–2. 401 {"ok": false}; данных нет.
3. 401; тела CSV нет.

## Тестовые данные
- Токен: `forged-token-0123456789abcdef` (не выдавался системой).
