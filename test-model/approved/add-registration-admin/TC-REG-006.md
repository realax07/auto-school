# TC-REG-006 — Email без «@» и домена отклоняется

- ID кейса: TC-REG-006
- ID чеклиста: CHK-6
- Источник: CHK-6 → Requirement «Отклонение некорректной регистрации» (домен registration) → FR-2; Scenario «Неверный формат email»
- Тип: негативный
- Приоритет: Must

## Предусловия
- Сервис запущен (uvicorn, single-worker); базовый URL: http://127.0.0.1:8000.
- БД data/app.db инициализирована (init_db при старте), таблица users пуста (чистое тестовое окружение).
- Окружение .env задано: ADMIN_USER, ADMIN_PASSWORD_HASH (bcrypt), SECRET.
- Контроль живости: GET /api/health -> 200 {"ok": true}.

## Шаги
1. POST /api/register: email = "ivanov.example", остальные поля — валидные из базового набора.
2. Зафиксировать статус и тело ответа.
3. SELECT COUNT(*) FROM users;

## Ожидаемый результат
1–2. 422 {"ok": false, "error": "Email: неверный формат email"} (причина указывает на неверный формат email).
3. COUNT(*) = 0 — запись не создана.

## Тестовые данные
- email: `ivanov.example` (без «@» и домена); остальные 6 полей — из базового набора.

## Примечания (дефекты спеки)
- D1 (нетестируемо, эскалация): точное правило формата email в спеке не определено. Фактическое поведение фиксируем по sdd 3.1: email обязан содержать «@» и точку в домене; `ivanov.example` правилу не удовлетворяет → 422.
