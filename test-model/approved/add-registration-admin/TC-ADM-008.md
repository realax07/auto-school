# TC-ADM-008 — Формат CSV: BOM, разделитель, заголовок, роль

- ID кейса: TC-ADM-008
- ID чеклиста: CHK-26
- Источник: CHK-26 → Requirement «Выгрузка CSV» (домен admin) → FR-7; Scenario «Выгрузка CSV с корректным форматом»
- Тип: позитивный
- Приоритет: Must

## Предусловия
- Сервис запущен (uvicorn, single-worker); базовый URL: http://127.0.0.1:8000.
- БД data/app.db инициализирована (init_db при старте), таблица users пуста (чистое тестовое окружение).
- Окружение .env задано: ADMIN_USER, ADMIN_PASSWORD_HASH (bcrypt), SECRET.
- Контроль живости: GET /api/health -> 200 {"ok": true}.

## Шаги
1. Зарегистрировать двух пользователей (базовый набор и U2 c email "sidorov@example.com").
2. Войти администратором → токен.
3. GET /api/admin/users/export.csv с X-Admin-Token; сохранить тело как байты.
4. Проверить первые 3 байта тела; декодировать utf-8-sig; разобрать строки по «;».
5. Зафиксировать заголовки ответа (Content-Disposition).

## Ожидаемый результат
4. Тело начинается с BOM (байты EF BB BF); разделитель «;»; первая строка — заголовок «ФИО;Email;Телефон;Роль;Дата регистрации»; далее по строке на каждого пользователя (2 строки).
5. Content-Disposition: attachment (filename users.csv); Content-Type: text/csv; charset=utf-8.
4 (доп). В колонке «Роль» каждой строки — значение «Ученик».

## Тестовые данные
- U1: базовый набор; U2: email `sidorov@example.com`, остальные поля валидные (без префиксов =,+,-,@ — см. TC-ADM-009/010).
