# TC-S10BE-017 — Дифф-запись: id строк сохраняются; перепривязка брони при покрытой замене носителя (MAJ-1)

- Автотест: `tests/test_s10_backend.py::test_s10_availability_diff_write_and_rebind`
- Приоритет: Must (MAJ-1 — дифф-запись, design «Экземпляр и разворот серий»)
- Статус: автоматизирован (rule 6 — TC-ID в docstring теста); кейс партии change add-calendar-weeks-availability (Спринт 10, backend)
- Трассировка:
  - Requirement: Сохранение и восстановление графика

## GIVEN / WHEN / THEN
- GIVEN фиктивный NOW; инструктор с графиком recurring «Чт 16:00–18:00» + one_off на дату экземпляра (PUT 200); ученик пары с активной бронью (200) ЧЕРЕЗ one_off на эту дату
- WHEN PUT того же графика без правок; затем PUT, убирающий one_off при СОХРАНЯЮЩЕЙСЯ серии того же экземпляра
- THEN PUT без правок → 200: id обеих строк НЕ изменились (дифф, не DELETE+INSERT), бронь продолжает ссылаться на ту же строку one_off (availability_id, lesson_date, статус 'new' прежние); удаление one_off → 200 (экземпляр покрыт серией): в БД осталась ровно 1 строка с id серии, бронь ПЕРЕПРИВЯЗАНА на серию (availability_id = id серии, дата/статус прежние), JOIN booking×availability не разорван — бронь-сирота невозможна

## Примечание
- Партия change add-calendar-weeks-availability (Спринт 10, волна D-1 backend); кейсы живут трассировкой TC-ID в docstring автотеста (rule 6).
