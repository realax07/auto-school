# TC-S10BE-008 — Кросс-строчная занятость: бронь через вторую строку того же экземпляра → 409 (MAJ-1)

- Автотест: `tests/test_s10_backend.py::test_s10_booking_cross_row_same_instance_409`
- Приоритет: Must (MAJ-1 арх-ревью Спринта 10 — политика (б))
- Статус: автоматизирован (rule 6 — TC-ID в docstring теста); кейс партии change add-calendar-weeks-availability (Спринт 10, backend)
- Трассировка:
  - Requirement: Занятый слот недоступен другим ученикам
  - Scenario: Бронь через вторую строку того же экземпляра отклоняется (MAJ-1)

## GIVEN / WHEN / THEN
- GIVEN фиктивный NOW; инструктор с recurring-серией «Чт 16:00–18:00»; в БД прямым INSERT добавлена one_off-строка на дату экземпляра (обе строки одного экземпляра — дата+время совпадают); два ученика разных принятых пар; экземпляр = четверг следующей недели
- WHEN ученик А бронирует экземпляр через one_off-строку (POST {availability_id one_off, date}); ученик Б отправляет POST на ТОТ ЖЕ экземпляр через повторяющийся слот — вторую строку того же экземпляра
- THEN первая бронь — 200; бронь через вторую строку → 409 «Слот уже занят», записи нет: в БД ровно 1 бронь инструктора — максимум одна активная бронь на экземпляр независимо от строки графика (кросс-строчная проверка внутри BEGIN IMMEDIATE)
