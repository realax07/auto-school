# TC-S10BE-011 — GET slots: date-валидация 422 (MIN-4), легаси-ответ без date, доступ 403/404

- Автотест: `tests/test_s10_backend.py::test_s10_slots_date_validation_and_access`
- Приоритет: Must (NFR-7 — доступ; MIN-4 арх-ревью)
- Статус: автоматизирован (rule 6 — TC-ID в docstring теста); кейс партии change add-calendar-weeks-availability (Спринт 10, backend)
- Трассировка:
  - Requirement: Календарь ученика: недели, реальные даты и разворот повторений

## GIVEN / WHEN / THEN
- GIVEN фиктивный NOW; инструктор с recurring-серией «Чт 16:00–18:00», принятая пара с учеником 1; ученик 2 без принятой пары; base = /api/student/instructors/{id}/slots
- WHEN GET base?date= для «12.11.2026» (не ISO), «2026-02-30» (несуществующая), «2026-1-5» (неполный формат), «not-a-date»; GET base без date; GET ученика 2 без пары (легаси-форма и с date); GET /api/student/instructors/999999/slots (легаси-форма и с date)
- THEN каждый невалидный date → 422 {ok:false} ДО приведения к понедельнику недели (MIN-4); без date — легаси-ответ прежнего контракта: {ok, slots:[{id, weekday 3, «16:00», «18:00», state 'free'}]} — ровно один слот; ученик без пары → 403 в обеих формах выдачи; несуществующий инструктор → 404 в обеих формах (наследование NFR-7)

## Примечание
- Партия change add-calendar-weeks-availability (Спринт 10, волна D-1 backend); кейсы живут трассировкой TC-ID в docstring автотеста (rule 6).
