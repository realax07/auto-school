## GIVEN / WHEN / THEN
- GIVEN ES-модули переложены в контурные папки (frontend/js/{shared,student,instructor,admin}, корень js/ — гостевые instructors.js, policy.js), HTML-src обновлены (6 страниц; instructors.html:32, policy.html:35 — без правок, модули в корне), ES-импорты переписаны на `../shared/*` из подпапок и `./shared/api.js` из корня (9 строк в 6 модулях), route расширен до `/js/{filepath:path}` с гвардом (leading «/», «..» по сегментам, dot-сегменты, is_file; FileResponse с явным application/javascript; HTTPException 404 без detail — design.md «Раздача /js/*»)
- WHEN запрашиваются модуль из подпапки (например /js/student/cabinet.js), корневой модуль (/js/policy.js), несуществующий путь и путь с обходом каталога (/js/../.env — path-as-is, /js/.hidden); параллельно wiring-прогон: frontend_source собирает HTML + транзитивные ES-импорты (включая `../…` из подпапок через posixpath.normpath(dirname+ref))
- THEN первые два отдаются 200 с `application/javascript`; неизвестный путь, обход каталога и скрытые файлы — 404 (полная матрица 13 проб review-001 §3, включая //etc/passwd и %2e%2e — гвард закрывает все варианты обхода); wiring-тесты зеленые без изменения «единицы wiring» (дедупликация seen и объединение источников без изменений; состав модулей единицы каждой страницы эквивалентен прежнему), старый URL перенесенного модуля — 404, корневые URL валидны как прежде

## Примечание
- Единственная содержательная продуктовая правка партии — хендлер
  js_file в backend/app.py (сверен с design-кодом посимвольно,
  review-001 §3); инварианты прежнего хендлера сохранены: обход каталога
  и скрытые файлы — 404, неизвестный файл — 404, content-type явный.
- Внешний контракт статики не документирован и не потребляется третьими
  клиентами (grep /js/ по contracts/, docs/, deploy/ — ссылок нет,
  design.md «Сознательные ограничения»); клиенты — собственные страницы
  репо, их URL-схема обновлена в HTML-src (D4), wiring-тесты это
  контролируют.
- Хвостово-слэшевый 200 (/js/student/cabinet.js/) — расширение
  односегментного маршрута (прежде любой двухсегментный URL давал 404);
  URL недокументированы, контракт не задет (arch-review-001 §3,
  review-001 «Наблюдения») — действий не требуется, в матрицу включено
  как задокументированное поведение.
