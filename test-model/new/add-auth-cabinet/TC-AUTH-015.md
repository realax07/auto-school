# TC-AUTH-015 — Счетчик неудач сбрасывается после успешного входа

- ID кейса: TC-AUTH-015
- ID чеклиста: CHK-15
- Источник: CHK-15 → Requirement «Ограничение попыток входа (анти-брутфорс)» (домен auth) → FR-2; Scenario «Счетчик сбрасывается после успешного входа»; R-BF3
- Тип: негативный
- Приоритет: Must
- Статус: automated — tests/test_auth.py::test_bruteforce_reset_after_success

## GIVEN / WHEN / THEN
- GIVEN с IP выполнено несколько неудачных попыток входа (меньше порога блокировки)
- WHEN с этого же IP выполняется успешный вход
- THEN счетчик неудачных попыток для IP обнуляется; последующие изолированные неудачные попытки (меньше порога) не приводят к блокировке

## Предусловия
- Как в TC-AUTH-001; отдельный IP 10.0.0.5 (изоляция состояния анти-брутфорса).

## Шаги
1. POST /api/register → 200.
2. С IP 10.0.0.5 выполнить (_BF_MAX_FAILURES - 2) неудачных попыток (ghost) — каждая 401; зафиксировать fails = _BF_MAX_FAILURES - 2.
3. С того же IP выполнить успешный вход (корректные креды) → 200; зафиксировать fails.
4. Повторить (_BF_MAX_FAILURES - 2) изолированных неудачных попыток; затем еще один успешный вход.

## Ожидаемый результат
2. fails == _BF_MAX_FAILURES - 2 (меньше порога, блокировки нет).
3. 200 {"ok": true, "token": "..."}; fails == 0 — счетчик обнулен успешным входом.
4. Успешный вход снова 200 (блокировки нет) — изолированные неудачи не дошли до порога.

## Тестовые данные
IP 10.0.0.5; ghost@example.com; корректные креды базового пользователя TC-AUTH-001.
