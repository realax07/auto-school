# TC-CAB-010 — Оформление кабинета соответствует мокапу (структура и стили)

- ID кейса: TC-CAB-010
- ID чеклиста: CHK-26
- Источник: CHK-26 → Requirement «Соответствие утвержденному мокапу кабинета» (домен cabinet) → FR-9; Scenario «Оформление кабинета соответствует мокапу»
- Тип: позитивный
- Приоритет: Must
- Статус: manual/toBeAutomated (визуальная часть — сравнение скриншотов/рендера с мокапом; структурно-стилевая часть автоматизирована — tests/test_cabinet_page.py::test_cab_page_structure_matches_mockup_verbatim: разметка и все строки CSS мокапа посимвольно)

## GIVEN / WHEN / THEN
- GIVEN ученик открыл кабинет
- WHEN выполняется визуальное/структурное сравнение страницы с утвержденным мокапом
- THEN структура, расположение блоков и стили соответствуют мокапу

## Предусловия
- Браузер; рендер мокапа design/mocks/cabinet-student.html и рендер /cabinet в одинаковом вьюпорте.

## Шаги
1. Открыть мокап в браузере, зафиксировать скриншот (вьюпорт, например, 1280×800).
2. Открыть /cabinet в том же вьюпорте, зафиксировать скриншот.
3. Сравнить структуру: порядок и взаимное расположение блоков header (крошка, user, «Выйти»), hero/greet, assistant (чат-бар), tiles (3 плитки), footer.
4. Сравнить стили: шрифты, цвета фона/панелей, скругления, сетка плиток (по инспектору и/или pixel-diff с допуском на подставленное ФИО).

## Ожидаемый результат
3. Порядок и расположение блоков идентичны мокапу; отличий в структуре нет.
4. Стили совпадают (CSS мокапа перенесен дословно — контроль TC-CAB-009/автотестом); визуальные расхождения отсутствуют, кроме подстановки реального ФИО вместо «Иван Иванов»/«Иван».

## Тестовые данные
Мокап: design/mocks/cabinet-student.html; страница: /cabinet (пользователь с ФИО «Иванов Иван Иванович» для вариации подстановки).
