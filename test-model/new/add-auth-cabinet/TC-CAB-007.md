- Тип: позитивный

- Статус: automated — tests/test_cabinet_page.py::test_cab_page_exists_and_marker_texts, test_cab_page_structure_matches_mockup_verbatim (плитки дословно из мокапа); tests/test_integration_sprint1.py::test_cabinet_page_served

## GIVEN / WHEN / THEN
- GIVEN ученик открыл кабинет (/cabinet → 200)
- WHEN выполняется проверка состава элементов страницы
- THEN присутствуют чат-бар «Гига ГАИшник» и три плитки-сервиса: «Обучение ПДД», «Онлайн экзамен», «Найти водителя»

## Предусловия
- Сервис собран; GET /cabinet → 200 (проверка выполняется на HTML/отрисованной странице).

## Шаги
1. GET /cabinet (или открыть страницу в браузере под пользователем).
2. Проверить присутствие маркеров: «Гига ГАИшник», «Обучение ПДД», «Онлайн экзамен», «Найти водителя».
3. Проверить структуру: блок assistant (чат-бар) и ровно три элемента плиток (button.tile) в блоке tiles.

## Ожидаемый результат
2. Все четыре текстовых маркера присутствуют дословно.
3. Разметка: <section class="assistant">…«Гига ГАИшник»…; <div class="tiles"> содержит ровно 3 <button class="tile"> с текстами «Обучение ПДД», «Онлайн экзамен», «Найти водителя».

## Тестовые данные
Любой зарегистрированный пользователь (базовый TC-AUTH-001) для варианта с браузером; для HTML-проверки авторизация не влияет (файл отдается целиком).
