# TC-CAB-005 — ФИО в кабинете из учетной записи (шапка + приветствие)

- ID кейса: TC-CAB-005
- ID чеклиста: CHK-21
- Источник: CHK-21 → Requirement «Отображение ФИО ученика» (домен cabinet) → FR-5; Scenario «ФИО в кабинете совпадает с учетной записью»; sdd §10.3 (uname/greet)
- Тип: позитивный
- Приоритет: Must
- Статус: manual/toBeAutomated (браузерная подстановка ФИО; косвенный автоконтроль wiring — tests/test_cabinet_page.py::test_cab_wiring_fio_substitution; данные /me — TC-AUTH-005, automated)

## GIVEN / WHEN / THEN
- GIVEN ученик Иванов Иван Иванович зарегистрирован и вошел в систему
- WHEN он открывает кабинет (данные подставляются из GET /api/auth/me)
- THEN в кабинете полное ФИО из учетной записи в шапке («Иванов Иван Иванович» в .uname) и имя в приветствии («ЛИЧНЫЙ КАБИНЕТ» / «Добро пожаловать, Иван!» в .greet b)

## Предусловия
- Браузер/Playwright; зарегистрирован ученик с ФИО Иванов Иван Иванович (email ivanov@example.com, пароль Qwerty123).

## Шаги
1. POST /api/register с пользователем: surname="Иванов", name="Иван", patronymic="Иванович", email="ivanov@example.com".
2. Войти через модалку m-login, открыть /cabinet.
3. Прочитать текст элемента .uname (шапка) и .greet b (приветствие).
4. Перехватить GET /api/auth/me — убедиться, что значения совпадают с данными ответа.

## Ожидаемый результат
3. .uname = «Иванов Иван Иванович» (полное ФИО, шаблон "{surname} {name} {patronymic}"); .greet b = «ЛИЧНЫЙ КАБИНЕТДобро пожаловать, Иван!» — в приветствии имя «Добро пожаловать, Иван!».
4. Значения равны данным из ответа /me (не константе мокапа «Иван Иванов»).
