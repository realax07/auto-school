# TC-AUTH-006 — Нет заголовка X-Session-Token: 401 на /me и /logout

- ID кейса: TC-AUTH-006
- ID чеклиста: CHK-11
- Источник: CHK-11 → Requirement «Сессии с ограниченным сроком действия» (домен auth) → FR-1, FR-7 («токен выдается только после успешного входа»); контракт sdd.md §10.2–§10.3
- Тип: негативный
- Приоритет: Must
- Статус: automated — tests/test_auth.py::test_me_logout_without_token_401

## GIVEN / WHEN / THEN
- GIVEN успешный вход не выполнялся (реестр сессий пуст)
- WHEN GET /api/auth/me и POST /api/auth/logout без заголовка X-Session-Token
- THEN оба ответа 401 {"ok": false}; поле token в телах отсутствует

## Предусловия
- Как в TC-AUTH-001; сессий в реестре нет (чистый старт приложения).

## Шаги
1. GET /api/auth/me без заголовка → зафиксировать ответ.
2. POST /api/auth/logout без заголовка → зафиксировать ответ.

## Ожидаемый результат
1. 401 {"ok": false}.
2. 401 {"ok": false} — аннулировать нечего; токен не выдан ни в одном ответе.

## Тестовые данные
Заголовки не передаются вовсе (отсутствующий заголовок, не пустая строка).
