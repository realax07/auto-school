# TC-NFR-002 — SQL в auth.py параметризован (?-плейсхолдеры, инъекция не работает)

- ID кейса: TC-NFR-002
- ID чеклиста: CHK-32
- Источник: CHK-32 → requirements.md NFR-2 (сквозное); sdd §11 (единственный запрос домена — SELECT по email через db-слой с ?-плейсхолдером), §12
- Тип: НФТ
- Приоритет: Must
- Статус: manual/toBeAutomated (инспекция кода + динамическая проба; автоматическая часть пробы ложится на паттерн tests/test_auth.py::test_login_failures_identical_message — кейс пока manual)

## GIVEN / WHEN / THEN
- GIVEN код домена auth (backend/auth.py) содержит SQL-запросы
- WHEN (1) выполняется инспекция кода; (2) динамическая проба: вход с email вида `' OR 1=1 --`
- THEN (1) все SQL-запросы — только с ?-плейсхолдерами, без конкатенации/f-строк с пользовательскими данными; (2) инъекционный email обрабатывается как литерал: единый 401 {"ok": false, "error": "Неверный email или пароль"}, записи БД не затронуты, обход авторизации невозможен

## Предусловия
- Доступ к исходному коду backend/auth.py и db-слою; сервис запущен; в users есть хотя бы одна запись (базовый пользователь).

## Шаги
1. Инспекция: найти все SQL-строки в backend/auth.py (и вызовы db-слоя); убедиться, что каждый запрос использует ?-плейсхолдеры, параметры передаются отдельным кортежем/списком; конкатенация строк/f-string с переменными запроса отсутствует.
2. Динамическая проба: POST /api/auth/login {"email": "' OR 1=1 --", "password": "anything"}.
3. Зафиксировать ответ.
4. Прямой SELECT count(*) FROM users — сравнить с количеством до пробы; убедиться, что вход не выполнен (токен не выдан).
5. Контроль: обычный вход с корректными кредами по-прежнему работает.

## Ожидаемый результат
1. Только ?-плейсхолдеры; нарушений параметризации нет.
2–3. 401 {"ok": false, "error": "Неверный email или пароль"} — единое сообщение, email трактуется как литерал.
4. Число записей users не изменилось; поле token в ответе отсутствует; авторизация не обойдена.
5. Обычный вход → 200.

## Тестовые данные
- Инъекционная строка email: `' OR 1=1 --` (в JSON: "' OR 1=1 --"), пароль "anything".
- Контроль: petrova@example.com / Qwerty123.
