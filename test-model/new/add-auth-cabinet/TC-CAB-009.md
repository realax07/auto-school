# TC-CAB-009 — Тексты кабинета дословно соответствуют мокапу

- ID кейса: TC-CAB-009
- ID чеклиста: CHK-25
- Источник: CHK-25 → Requirement «Соответствие утвержденному мокапу кабинета» (домен cabinet) → FR-9; Scenario «Тексты кабинета совпадают с мокапом»
- Тип: позитивный
- Приоритет: Must
- Статус: automated — tests/test_cabinet_page.py::test_cab_page_exists_and_marker_texts, test_cab_page_structure_matches_mockup_verbatim (дословные тексты и все CSS-строки мокапа)

## GIVEN / WHEN / THEN
- GIVEN ученик открыл кабинет (страница frontend/cabinet.html отдается по /cabinet)
- WHEN выполняется текстовое сравнение страницы с утвержденным мокапом design/mocks/cabinet-student.html
- THEN заголовки, текстовки плиток, тексты чат-бара и подписи совпадают с мокапом дословно; допустимые отличия — только wiring (/api/auth/me, X-Session-Token, logout, редиректы) и подстановка ФИО ученика вместо примера «Иван Иванов»/«Иван»

## Предусловия
- Сервис собан; файл design/mocks/cabinet-student.html существует (утвержденный мокап).

## Шаги
1. GET /cabinet → 200; получить HTML страницы.
2. Пройти по маркерным текстам мокапа: «СберАвтошкола», «Личный кабинет · Ученик», «ЛИЧНЫЙ КАБИНЕТ», «Гига ГАИшник», «Твой AI-помощник в обучении и на дороге», «Спроси что угодно про обучение, экзамен или ПДД...», «Обучение ПДД», «Онлайн экзамен», «Найти водителя», «СКОРО», «СберАвтошкола · кабинет ученика», «Выйти».
3. Посимвольно сверить структурные фрагменты и каждую непустую строку <style> мокапа со страницей.
4. Проверить, что отличия страницы от мокапа — только wiring-фрагменты и шаблоны подстановки ФИО.

## Ожидаемый результат
2. Все тексты присутствуют дословно.
3. Структурные фрагменты (hero/frame, crumb, user, greet, assistant, prompt, footer) и все строки CSS мокапа — посимвольно в странице; ни одна строка стилей мокапа не изменена и не удалена.
4. Вне wiring и подстановки ФИО расхождений нет.

## Тестовые данные
Мокап: design/mocks/cabinet-student.html; страница: GET /cabinet (frontend/cabinet.html).
