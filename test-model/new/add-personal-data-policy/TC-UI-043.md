# TC-UI-043 — Модалка регистрации: чекбокс гейтит сабмит, ссылка /policy видна и ведет на страницу

- Автотест: `tests/test_ui_playwright.py::test_register_modal_consent_gates_submit_and_links_policy`
- Приоритет: Must (FR-78)
- Статус: автоматизирован (rule 6 — TC-ID в docstring теста); кейс партии change add-personal-data-policy (Спринт 9)
- Трассировка:
  - Scenario: Чекбокс не установлен — регистрация блокирована на клиенте
    (Requirement: Обязательное согласие при регистрации ученика)
  - Scenario: Ссылка на политику видна из обоих мест согласия
    (Requirement: Публичная страница политики персональных данных (/policy))
  - Scenario: Согласие установлено — пользователь создан
    (Requirement: Обязательное согласие при регистрации ученика)

## GIVEN / WHEN / THEN
- GIVEN открыт лендинг ученика, модалка «Регистрация» заполнена валидно, чекбокс согласия снят
- WHEN проверяется #reg-submit; принудительный клик по недоступной кнопке (dispatch); клик по ссылке «политикой персональных данных»; установка чекбокса и сабмит
- THEN #reg-submit disabled; регистрация не выполняется — #reg-error показывает «Согласие: поле обязательно», редиректа в /cabinet нет; ссылка видна и открывает /policy в новой вкладке (метаданные «Версия: …» на странице); после установки чекбокса кнопка активна и регистрация проходит (редирект /cabinet, session_token сохранен)
