# TC-INS-012 — Все 7 разделов переключаются; без реальных запросов данных

- ID кейса: TC-INS-012
- ID чеклиста: CHK-12
- Источник: CHK-12 → Requirement «Разделы сайдбара — визуальное переключение на демо-данных» → FR-21; Scenario «Все разделы сайдбара переключаются»; негатив-составляющая: переключение не выполняет реальных запросов данных разделов (расписание/ученики/доходы — вне объема)
- Тип: позитивный + негативный
- Приоритет: Must
- Статус: automated — статическая часть (tests/test_instructor_dashboard.py::test_dashboard_page_nav_sections_fr19, плановый ID TC-FR21D-008: полный перечень 7 data-tab, пометка «демо»); браузерная часть (последовательные клики, перехват сети) — manual/toBeAutomated (Playwright)

## GIVEN / WHEN / THEN
- GIVEN инструктор открыл кабинет, валидная сессия; перехват сетевых запросов включен
- WHEN он последовательно выбирает каждый из 7 разделов сайдбара (Мой день, Расписание, Мои ученики, Доходы и выплаты, Мой автомобиль, Материалы и обучение, Профиль и документы)
- THEN для каждого раздела заголовок (h1) и хлебная крошка меняются на его название, контент остается демо-данными; негатив: ни одно переключение не выполняет реальных запросов данных разделов (расписание/ученики/доходы — вне объема)

## Предусловия
- Инструктор вошел, кабинет открыт; браузер/Playwright с перехватом network.

## Шаги
1. Войти инструктором, открыть кабинет, включить запись всех сетевых запросов.
2. Последовательно кликнуть все 7 nav-кнопок (data-tab по перечню FR-19).
3. После каждого клика зафиксировать: текст h1 (#page-title), крошку (#crumb), активную кнопку, содержимое блоков.
4. Проанализировать журнал сети: все запросы, кроме первичного GET /api/instructor/dashboard и статики.

## Ожидаемый результат
2. Каждая кнопка при клике становится активной.
3. Для каждого из 7 разделов: h1 и крошка = название раздела; блоки — демо-данные (не изменились).
4. Никаких запросов данных разделов (расписание/ученики/доходы/авто/материалы/профиль) не отправлено — переключение чисто визуальное.

## Тестовые данные
Перечень разделов (data-tab): «Мой день», «Расписание», «Мои ученики», «Доходы и выплаты», «Мой автомобиль», «Материалы и обучение», «Профиль и документы».
