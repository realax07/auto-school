# TC-INS-007 — Структура кабинета дословно соответствует макету

- ID кейса: TC-INS-007
- ID чеклиста: CHK-7
- Источник: CHK-7 → Requirement «Соответствие утвержденному макету кабинета» → FR-19; Scenario «Структура кабинета соответствует макету»
- Тип: позитивный
- Приоритет: Must
- Статус: automated — tests/test_instructor_dashboard.py::test_dashboard_page_mockup_texts_verbatim (дословные тексты + все CSS-строки мокапа) и test_dashboard_page_nav_sections_fr19 (сайдбар из 7 nav-кнопок, плановый ID TC-FR19D-007); визуальная сверка рендера в браузере — manual/toBeAutomated

## GIVEN / WHEN / THEN
- GIVEN инструктор открыл /instructor/dashboard (страница отрисована)
- WHEN выполняется текстовое/структурное сравнение страницы с design/mocks/dashboard-instructor.html
- THEN присутствуют все блоки макета дословно: сайдбар (Мой день, Расписание, Мои ученики, Доходы и выплаты, Мой автомобиль, Материалы и обучение, Профиль и документы), 4 карточки статистики, расписание недели, список сегодняшних занятий, ближайшее занятие, автомобиль, последние операции, быстрые действия — тексты и стили ключевых блоков как в макете; допустимые отличия — только wiring-перечень design.md (nav-кнопки, ФИО/инициалы, демо-метки, элементы выхода, profile-panel)

## Предусловия
- Файл frontend/instructor-dashboard.html собран и смонтирован на /instructor/dashboard; макет design/mocks/dashboard-instructor.html доступен.

## Шаги
1. Прочитать HTML страницы и мокапа.
2. Проверить наличие каждого фрагмента-маркера макета в странице (шапка/бренд, приветствие, 4 карточки статистики с их значениями, расписание недели, занятия сегодня, ближайшее занятие, автомобиль, операции, быстрые действия, футер «Все данные вымышлены»).
3. Посимвольно сравнить CSS: каждая непустая строка <style> мокапа присутствует в <style> страницы.
4. Проверить сайдбар: data-tab для каждого из 7 разделов.
5. Зафиксировать все отличия страницы от мокапа и сверить с wiring-перечнем design.md — вне его отличий быть не должно.
6. (Визуально, manual) Открыть кабинет в браузере, сравнить рендер с макетом.

## Ожидаемый результат
2–4. Все текстовые фрагменты найдены и в странице, и в мокапе (фрагмент не «придуман»); CSS мокапа не изменен и не урезан; 7 разделов сайдбара на месте.
5. Отличия от мокапа ⊆ {nav-кнопки, подстановка ФИО/инициалов, демо-метки, элементы выхода, profile-panel}.
6. Рендер визуально соответствует макету.
