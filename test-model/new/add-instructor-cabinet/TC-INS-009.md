# TC-INS-009 — ФИО в шапке из учетной записи, не демо

- ID кейса: TC-INS-009
- ID чеклиста: CHK-9
- Источник: CHK-9 → Requirement «ФИО инструктора из учетной записи» → FR-20; Scenario «ФИО подставлено из учетной записи»
- Тип: позитивный
- Приоритет: Must
- Статус: automated — API-часть (tests/test_instructor_dashboard.py::test_dashboard_200_for_instructor_with_fio — surname/name/patronymic из записи users, плановый ID TC-FR18D-005) + wiring-контроль (test_dashboard_page_wiring_fr18_fr20_fr22: ФИО шапки из ответа, демо-ФИО заменяется); UI-подстановка в браузере (в т.ч. два инструктора) — manual/toBeAutomated (Playwright)

## GIVEN / WHEN / THEN
- GIVEN одобренный инструктор с ФИО «Иванов Иван Иванович» вошел и открыл кабинет
- WHEN страница отображается (fetch /api/instructor/dashboard выполнен, ответ получен)
- THEN в шапке показано «Иванов Иван Иванович» из ответа API (surname + name + patronymic), а не демо-«Михаил Самойлов»; у двух инструкторов с разными ФИО каждый видит собственное ФИО

## Предусловия
- Две одобренные учетки инструкторов с разными ФИО созданы флоу apply → approve → login.
- Для UI-части: браузер/Playwright.

## Шаги
1. Инструктор А («Иванов Иван Иванович»): GET /api/instructor/dashboard с токеном → зафиксировать instructor.{surname,name,patronymic}.
2. (UI) Открыть кабинет инструктором А: шапка .user b = «Иванов Иван Иванович»; демо-«Михаил Самойлов» в шапке отсутствует (заменен; строка приветствия «Добрый день, Михаил» не входит в объем подмены — демо-строка «Инструктор · Категория B» не подменяется, sdd §22).
3. (UI) Выйти, войти инструктором Б (другое ФИО, например «Петров Петр Петрович»): шапка = «Петров Петр Петрович».

## Ожидаемый результат
1. 200; instructor = {"surname": "Иванов", "name": "Иван", "patronymic": "Иванович", "email": "..."} — данные записи users.
2–3. Шапка каждого инструктора показывает его собственное ФИО из ответа API; демо-ФИО не отображается ни у кого.

## Тестовые данные
Инструктор А: instr@example.com / Instr1234, ФИО «Иванов Иван Иванович»; инструктор Б: instr2@example.com / Instr1234, ФИО «Петров Петр Петрович».
