# TC-INS-002 — Запрос данных кабинета без токена → 401

- ID кейса: TC-INS-002
- ID чеклиста: CHK-2
- Источник: CHK-2 → Requirement «Доступ к кабинету инструктора» → FR-18; Scenario «Обращение к данным кабинета без сессии отклоняется»
- Тип: негативный
- Приоритет: Must
- Статус: automated — API-часть (tests/test_instructor_dashboard.py::test_dashboard_401_without_token, плановый ID TC-FR18D-001); браузерная часть (страница не показывается, редирект на главную к модалке входа) — manual/toBeAutomated (Playwright)

## GIVEN / WHEN / THEN
- GIVEN пользователь не выполнял вход (токена нет)
- WHEN страница /instructor/dashboard запрашивает данные кабинета (GET /api/instructor/dashboard без заголовка X-Session-Token)
- THEN бэкенд отвечает 401 {"ok": false}; страница не показывается — клиент выполняет редирект на главную (к модалке входа)

## Предусловия
- Сервис собран (create_app(), чистая БД); sessionStorage пуст (вход не выполнялся).
- Для UI-части: браузер/Playwright.

## Шаги
1. GET /api/instructor/dashboard без заголовка X-Session-Token.
2. (UI) Открыть /instructor/dashboard в браузере без входа; наблюдать поведение страницы после fetch-ответа.

## Ожидаемый результат
1. 401, тело точно {"ok": false} (sdd §20.1, п.1 порядка проверок).
2. Контент кабинета не отрисован; выполнен редирект на `/` (location.href='/'), пользователь — на главной у модалки входа.

## Тестовые данные
Без учетных данных; пустой sessionStorage.
