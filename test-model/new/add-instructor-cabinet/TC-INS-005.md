# TC-INS-005 — Прямое открытие /instructor/dashboard без входа → редирект до отрисовки

- ID кейса: TC-INS-005
- ID чеклиста: CHK-5
- Источник: CHK-5 → Requirement «Доступ к кабинету инструктора» → FR-18; Scenario «Открытие страницы напрямую без сессии» (паттерн arch-review §1.1: статика отдается всем, редирект клиентский — D3)
- Тип: негативный (граничный)
- Приоритет: Must
- Статус: automated — серверная часть (tests/test_instructor_dashboard.py::test_dashboard_page_served — GET /instructor/dashboard → 200 text/html: статика отдается всем); браузерная часть (редирект до отрисовки контента) — manual/toBeAutomated (Playwright; сигнал риска review-001-3.1 — требует исполнения JS)

## GIVEN / WHEN / THEN
- GIVEN пользователь не выполнял успешный вход (sessionStorage пуст)
- WHEN он открывает /instructor/dashboard напрямую вводом URL в адресную строку
- THEN страница не открывается: контент кабинета не отрисован — клиентский редирект на главную (к модалке входа) выполнен до отрисовки; при этом GET /instructor/dashboard сам по себе отдает статику (осознанный паттерн arch-review §1.1)

## Предусловия
- Сервис собран (create_app()); маршрут /instructor/dashboard примонтирован (задача 3.1).
- Для UI-части: браузер/Playwright; sessionStorage пуст.

## Шаги
1. GET /instructor/dashboard без входа (чистый HTTP-запрос).
2. (UI) Открыть /instructor/dashboard вводом URL в браузере без входа; наблюдать: не мигает ли контент, куда ведет редирект.

## Ожидаемый результат
1. 200, content-type text/html — статика отдается всем (это НЕ дефект; защита на уровне данных: GET /api/instructor/dashboard → 401).
2. Контент кабинета пользователю не показан; редирект на `/` (к модалке входа) — до отрисовки защищенного контента.

## Тестовые данные
Без учетных данных; пустой sessionStorage.
