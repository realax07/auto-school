# TC-ADM-005 — Список зарегистрированных пользователей: состав колонок

- ID кейса: TC-ADM-005
- ID чеклиста: CHK-23
- Источник: CHK-23 → Requirement «Список зарегистрированных пользователей» (домен admin) → FR-6; Scenario «Просмотр списка пользователей»
- Тип: позитивный
- Приоритет: Must

## Предусловия
- Сервис запущен (uvicorn, single-worker); базовый URL: http://127.0.0.1:8000.
- БД data/app.db инициализирована (init_db при старте), таблица users пуста (чистое тестовое окружение).
- Окружение .env задано: ADMIN_USER, ADMIN_PASSWORD_HASH (bcrypt), SECRET.
- Контроль живости: GET /api/health -> 200 {"ok": true}.

## Шаги
1. Зарегистрировать двух пользователей U1 (базовый набор) и U2 (surname «Сидоров», email "sidorov@example.com", phone «+7 900 111-22-33»).
2. POST /api/admin/login → получить токен.
3. GET /api/admin/users с X-Admin-Token.
4. Для каждого элемента users проверить состав полей и значения.

## Ожидаемый результат
1. Обе регистрации: 200.
2–3. 200 {"count": 2, "users": [...]}.
4. Для каждого пользователя присутствуют: fio (= «{surname} {name} {patronymic}» через пробел), email, phone, дата регистрации (created_at); значения совпадают с введенными при регистрации (fio U1 = «Петрова-Водкина Анна Оттовна»).

## Тестовые данные
- U1: базовый набор; U2: surname `Сидоров`, name `Иван`, patronymic `Петрович`, email `sidorov@example.com`, phone `+7 900 111-22-33`, пароль `Parol9999`.
