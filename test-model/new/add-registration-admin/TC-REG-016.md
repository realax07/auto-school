# TC-REG-016 — После успешной регистрации — страница «Регистрация завершена»

- ID кейса: TC-REG-016
- ID чеклиста: CHK-16
- Источник: CHK-16 → Requirement «Страница «Регистрация завершена»» (домен registration) → FR-4; Scenario «Переход после успешной регистрации»
- Тип: позитивный
- Приоритет: Must

## Предусловия
- Браузерное окружение для UI-проверки (Playwright/ручной прогон), открыть http://127.0.0.1:8000.
- Сервис запущен; БД data/app.db доступна для контрольной сверки записей.

## Шаги
1. Открыть лендинг http://127.0.0.1:8000/.
2. Открыть модалку регистрации, заполнить все 7 полей валидными значениями (базовый набор).
3. Отправить форму.
4. Зафиксировать итоговый URL и заголовок/текст отображаемой страницы; сверить запись в БД.

## Ожидаемый результат
1–3. Форма отправлена без ошибок валидации.
4. Пользователь автоматически попадает на страницу «Регистрация завершена»: URL http://127.0.0.1:8000/registered (редирект после 200 {ok:true}); страница отображается; в users появилась запись.

## Тестовые данные
Базовый валидный пользователь (все 7 полей):
```json
{
  "surname": "Петрова-Водкина",
  "name": "Анна",
  "patronymic": "Оттовна",
  "email": "petrova@example.com",
  "phone": "+7 (912) 345-67-89",
  "password": "Qwerty123",
  "password_confirm": "Qwerty123"
}
```
