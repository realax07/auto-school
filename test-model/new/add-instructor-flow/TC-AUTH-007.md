# TC-AUTH-007 — Негатив: /instructors/rejected без входа — причина не раскрывается

- ID кейса: TC-AUTH-007
- ID чеклиста: CHK-41
- Источник: CHK-41 → Requirement «Роутинг после входа по статусу» (домен instructor-auth) → FR-13; Scenario «Статусный экран недоступен без проверки пароля» (прямое открытие)
- Тип: негативный
- Приоритет: Must
- Статус: automated (частично) — tests/test_instructor_pages.py::test_rejected_page_exists_and_reason_wiring (причина — только из sessionStorage-ключа instructor_rejected_reason; пусто/нет ключа → блок причины скрыт, style.display=''). Прямое открытие без выполненного входа — manual/toBeAutomated (браузер). Класс «повторный показ причины в живой вкладке» — исключен до решения ПМ (дефект D4, sessionStorage-компромисс)

## GIVEN / WHEN / THEN
- GIVEN существует deny-заявка с причиной C; прямой доступ к /instructors/rejected БЕЗ успешного входа с паролем (нет данных логина, sessionStorage пуст)
- WHEN страница /instructors/rejected открывается напрямую (новая вкладка/сессия)
- THEN причина отказа C НЕ раскрывается: страница без персональной причины (блок причины скрыт), данные заявки не показываются

## Предусловия
- Браузер/Playwright с чистым профилем (пустой sessionStorage); сервис запущен; deny-заявка существует (apply + deny через админ-API).
- Внимание: проверять в НОВОЙ вкладке/контексте — в живой вкладке после входа причина живет в sessionStorage (задокументированный компромисс D4, вне кейса).

## Шаги
1. Создать deny-заявку (apply + deny c комментарием «Не подтверждена квалификация»).
2. В новой вкладке/контексте открыть /instructors/rejected напрямую.
3. Зафиксировать содержимое страницы и состояние блока причины.
4. (wiring-контроль) В HTML: чтение ключа instructor_rejected_reason из sessionStorage; при пустом значении — скрытие reason-block.

## Ожидаемый результат
2–3. Страница открыта (200) как статический экран, но персональной причины НЕТ: блок причины скрыт, текст C на странице отсутствует, данных заявки нет.
4. Wiring: без ключа sessionStorage блок скрыт.

## Тестовые данные
Deny-заявка: instr@example.com / Instr1234, C «Не подтверждена квалификация».
