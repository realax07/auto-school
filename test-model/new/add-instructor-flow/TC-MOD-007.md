# TC-MOD-007 — Негатив: повторный deny → 409, сохраненная причина не меняется

- ID кейса: TC-MOD-007
- ID чеклиста: CHK-28
- Источник: CHK-28 → Requirement «Отклонение заявки с обязательным комментарием» (домен admin-moderation) → FR-15; Scenario «Повторное отклонение не меняет уже сохраненную причину»
- Тип: негативный
- Приоритет: Must
- Статус: automated — tests/test_instructor_admin.py::test_deny_twice_409_reason_unchanged (повторный deny → 409 «Заявка уже отклонена», review_comment остается C). Плановые ID в docstring действуют до утверждения (rule 6)

## GIVEN / WHEN / THEN
- GIVEN заявка уже в статусе deny с сохраненным комментарием C
- WHEN повторный POST deny с другим комментарием C2 и валидным админ-токеном
- THEN 409 {"ok": false, "error": "Заявка уже отклонена"}; сохраненная причина C остается в заявке и НЕ меняется на C2

## Предусловия
- Сервис собран через create_app() с роутерами; TestClient без сети; чистая БД в tmp, init_db; существует deny-заявка с review_comment C.

## Шаги
1. Создать заявку → id A; deny {A} с комментарием «Не подтверждена квалификация» → 200.
2. Повторный POST deny {A} с комментарием «другая причина» → зафиксировать.
3. Прочитать запись заявки A.

## Ожидаемый результат
2. 409 {"ok": false, "error": "Заявка уже отклонена"}.
3. status = 'deny'; review_comment = «Не подтверждена квалификация» (не «другая причина»).

## Тестовые данные
Заявка — базовый валидный набор (TC-APP-005). Первый комментарий C: «Не подтверждена квалификация»; повторный C2: «другая причина». Админ: admin / admin-pass-2026.
