# TC-AUTH-011 — Граница: блокировка изолирована по IP и нигде не названа

- ID кейса: TC-AUTH-011
- ID чеклиста: CHK-47
- Источник: CHK-47 → Requirement «Вход инструктора через общий механизм авторизации» (домен instructor-auth) → FR-13; sdd §15.5 (учет по IP); эталон test_auth.py::test_bruteforce_block_is_per_ip
- Тип: граничный
- Приоритет: Must
- Статус: automated (частично) — изоляция по IP: эталон users-пути tests/test_auth.py::test_bruteforce_block_is_per_ip (единый механизм); инструктор-вариант и «нераскрытие блокировки» — manual/toBeAutomated. До утверждения кейсов (rule 6)

## GIVEN / WHEN / THEN
- GIVEN IP-A заблокирован анти-брутфорсом (порог неудач достигнут); IP-B — чистый
- WHEN (1) вход с IP-B штатными кредами; (2) вход с заблокированного IP-A с КОРРЕКТНЫМИ кредами
- THEN (1) вход с другого IP штатен (блокировка одного IP не влияет на другие); (2) ответ идентичен единому отказу 401 — блокировка нигде не названа (ни в теле, ни в заголовках)

## Предусловия
- Сервис собран через create_app(); TestClient без сети; чистая БД; состояние анти-брутфорса чистое; approved-инструктор instr@example.com / Instr1234.
- Подмена IP: TestClient с заголовком/подменой client host (механика test_auth.py::test_bruteforce_block_is_per_ip).

## Шаги
1. Создать одобренного инструктора.
2. С IP-A выполнить 5 неудачных попыток (неверный пароль) → блокировка.
3. С IP-B выполнить вход с верными кредами → зафиксировать статус/тело.
4. С IP-A выполнить вход с ВЕРНЫМИ кредами → зафиксировать статус, тело, заголовки ответа.
5. Сравнить ответ шага 4 с ответом обычного 401 (неверные креды, чистый IP).

## Ожидаемый результат
3. IP-B: 200 {ok, token, route:"cabinet"} — блокировка не действует на другие IP.
4. IP-A: 401 с единым сообщением; тело и код идентичны обычному отказу; никаких признаков блокировки (нет Retry-After, нет отличий в теле/заголовках).

## Тестовые данные
instr@example.com / Instr1234, неверный WrongPass1. IP-A — заблокированный, IP-B — чистый.

## Трассировка

### Requirement: Вход инструктора через общий механизм авторизации
трассировка: нет канонического сценария (долг спеки) — сценарий нераскрытия блокировки каноничен в пакете add-auth-cabinet (auth): «Заблокированная попытка не раскрывает блокировку»
