# TC-APP-003 — Состав полей анкеты /instructors/apply по макету

- ID кейса: TC-APP-003
- ID чеклиста: CHK-3
- Источник: CHK-3 → Requirement «Анкета заявки инструктора» (домен instructor-application) → FR-11; Scenario «Анкета соответствует макету и собирает все поля»
- Тип: позитивный
- Приоритет: Must
- Статус: automated — tests/test_instructor_pages.py::test_apply_page_texts_verbatim (тексты/CSS макета дословно, включая required у ФИО) + tests/test_instructor_pages.py::test_apply_password_fields_added (password/password-confirm — обязательные password-инпуты). Плановые ID в docstring автотестов действуют до утверждения кейсов (rule 6)

## GIVEN / WHEN / THEN
- GIVEN пользователь открыл GET /instructors/apply
- WHEN страница отображается
- THEN 200; на форме присутствуют поля: ФИО (одним полем), телефон, email, адрес фактического проживания, переключатель формата работы (свой авто / авто Сбера), госномер (виден и активен при «свой автомобиль»), номер ВУ, дата выдачи ВУ, категория прав, стаж вождения, пароль, подтверждение пароля, чекбокс согласия на обработку ПДн со звездочкой; обязательность — по звездочкам макета плюс пароль и подтверждение

## Предусловия
- Сервис запущен; /instructors/apply доступен.

## Шаги
1. GET /instructors/apply → зафиксировать статус.
2. Инспекция DOM: найти элементы ФИО, телефон, email, адрес, формат работы (radio own/sber), госномер, номер ВУ, дата ВУ, категория, стаж, password, password-confirm, чекбокс согласия.
3. Сверить тексты и CSS с мокапом registration-instructor.html (дословно).
4. Проверить обязательность: поля со звездочкой макета имеют required; password и password-confirm — type="password" с обязательной отметкой; чекбокс согласия — со звездочкой (HTML5 required не обязателен — серверный 422, CHK-8).

## Ожидаемый результат
1. 200, text/html.
2. Все 13 элементов присутствуют, id совпадают с макетом (fio, phone, email, address, plate, license-number, license-date, license-category, experience) плюс добавленные password и password-confirm.
3. Все фрагменты мокапа дословно; CSS-строки мокапа не изменены.
4. Обязательность: по звездочкам + пароль с подтверждением.

## Тестовые данные
Тестовые данные не требуются (инспекция формы).
