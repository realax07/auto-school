# TC-AUTH-009 — Негатив: анти-брутфорс, порог неудач → блокировка без проверки кредов

- ID кейса: TC-AUTH-009
- ID чеклиста: CHK-45
- Источник: CHK-45 → Requirement «Вход инструктора через общий механизм авторизации» (домен instructor-auth) → FR-13; sdd §15.5 (R-BF1…R-BF4 без изменений; параметрически относительно _BF_MAX_FAILURES = 5, дефект D1 — порог в спеке потока не зафиксирован)
- Тип: негативный
- Приоритет: Must
- Статус: automated — tests/test_auth_route.py::test_bruteforce_on_application_counts (плановый ID TC-FR13-006; 5 неудач → 6-я с ВЕРНЫМ паролем отклонена 401) + эталон users-пути test_auth.py::test_bruteforce_blocks_ip_without_credential_check. До утверждения кейсов (rule 6)

## GIVEN / WHEN / THEN
- GIVEN существует одобренный инструктор (верный email E, пароль P); попытки идут с одного IP
- WHEN выполняются _BF_MAX_FAILURES (5) неудачных попыток входа (верный email, неверный пароль) подряд, затем очередная попытка
- THEN очередная попытка отклоняется БЕЗ проверки учетных данных тем же 401 с единым сообщением; токен не выдан (даже с верным паролем) — анти-брутфорс действует для инструкторов так же, как для учеников

## Предусловия
- Сервис собран через create_app(); TestClient без сети; чистая БД в tmp; состояние анти-брутфорса чистое (auth._bf.clear() до/после — механика test_auth_route.py; среда single-worker, учет в памяти).
- Параметр D1: порог проверяется относительно фактического _BF_MAX_FAILURES (=5 в backend/auth.py).

## Шаги
1. Создать одобренного инструктора (apply + approve, instr@example.com / Instr1234).
2. Выполнить 5 попыток POST /api/auth/login {"email": "instr@example.com", "password": "WrongPass1"} → каждая 401.
3. 6-я попытка с ВЕРНЫМ паролем Instr1234 → зафиксировать статус/тело.
4. Проверить отсутствие ключа token в ответе.

## Ожидаемый результат
2. Пять ответов 401 с единым сообщением.
3–4. 6-й ответ — 401 {"ok": false, "error": "Неверный email или пароль"} без проверки кредов (блокировка); token отсутствует.

## Тестовые данные
instr@example.com: верный Instr1234, неверный WrongPass1. IP — единый (TestClient).
