# TC-APP-008 — Негатив: без согласия на обработку ПДн → 422, сабмит не проходит

- ID кейса: TC-APP-008
- ID чеклиста: CHK-8
- Источник: CHK-8 → Requirement «Сохранение заявки со статусом waiting» (домен instructor-application) → FR-11; Scenario «Отправка без согласия отклоняется»
- Тип: негативный
- Приоритет: Must
- Статус: automated — tests/test_instructors_apply.py::test_apply_validation_contract_422 (вариант {"consent": False} → «Согласие: поле обязательно», COUNT=0); серверный 422 обязателен, клиентская блокировка сабмита опциональна (review-001-4.2 #1). Плановые ID в docstring действуют до утверждения (rule 6)

## GIVEN / WHEN / THEN
- GIVEN анкета заполнена корректно, чекбокс согласия на обработку персональных данных НЕ отмечен (consent=false)
- WHEN анкета отправляется
- THEN 422 «Согласие: поле обязательно», заявка НЕ создается; сабмит не выполняется (пользователь остается на форме), экран ожидания /instructors/pending НЕ показывается; клиентская блокировка сабмита не обязательна — контракт серверный

## Предусловия
- Сервис собран через create_app() с роутером instructors; TestClient без сети; чистая БД в tmp, init_db.

## Шаги
1. POST /api/instructors/apply с базовым валидным набором, consent=false.
2. Зафиксировать статус и тело ответа.

4. (браузерная часть, manual) Проверить, что при 422 редирект на /instructors/pending не выполняется — показано сообщение под формой.
