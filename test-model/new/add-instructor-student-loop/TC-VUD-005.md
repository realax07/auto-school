# TC-VUD-005 — Прямой URL файла ВУ не отдается статикой

- ID кейса: TC-VUD-005
- ID чеклиста: CHK-9
- Источник: CHK-9 → Requirement «Выдача изображения ВУ только по админ-токену» (instructor-documents) → FR-24, NFR-1; Scenario «Прямой URL файла не работает»
- Тип: негативный
- Приоритет: Must
- Статус: ручной (не исполнялся; автоматизация — после утверждения кейсов, контракт 6; плановые TC-ID в docstring автотестов действуют до утверждения, rule 6)

## GIVEN / WHEN / THEN
- GIVEN файл ВУ сохранен на сервере (data/uploads/license/<name>), путь известен из license_photo_path
- WHEN файл запрашивается по прямому URL без проверки доступа (GET /data/uploads/license/<name> и варианты /uploads/..., /static/...)
- THEN файл не выдается (404/статика без маршрута) — каталог загрузок не входит в раздаваемую статику

## Предусловия
- Сервис собран через create_app() (uvicorn, single-worker); допускается TestClient без сети (паттерн tests/conftest.py). Чистая БД (AUTOSCHOOL_DB_PATH в tmp), init_db при старте. Контроль живости: GET /api/health → 200 {"ok": true}.
- Сессии/данные фикстур: одобренные инструкторы А и Б (approved-заявка, Спринт 2; users.role='instructor'), ученик с валидной сессией (role='student'), X-Admin-Token администратора (Спринт 0). Сессии получены через /api/auth/login.
- Все запросы к API передают токены в заголовках X-Session-Token / X-Admin-Token (механика Спринтов 0–2).

## Шаги
1. Создать заявку с ВУ, взять фактический путь из license_photo_path.
2. GET прямого URL файла без заголовков; затем с любыми заголовками (ученическая сессия, admin-токен).
3. Зафиксировать коды и тела ответов.

## Ожидаемый результат
2–3. Ни один прямой URL не возвращает байты файла: 404 {ok:false} или отсутствие маршрута статики; изображение доступно только через admin-API с токеном (TC-VUD-003).
