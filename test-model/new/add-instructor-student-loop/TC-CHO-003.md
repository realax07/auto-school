# TC-CHO-003 — Фильтры каталога: КПП, рейтинг, стаж; пустой результат

- ID кейса: TC-CHO-003
- ID чеклиста: CHK-32, CHK-33, CHK-34, CHK-36
- Источник: CHK-32/33/34/36 → Requirement «Фильтры каталога» (student-instructor-choice) → FR-32; Scenarios «Фильтр по типу КПП», «Фильтр по рейтингу», «Фильтр по стажу», «Пустой результат фильтра — пустое состояние»
- Тип: позитивный + граничный
- Приоритет: Must
- Статус: ручной (не исполнялся; автоматизация — после утверждения кейсов, контракт 6; плановые TC-ID в docstring автотестов действуют до утверждения, rule 6)

## GIVEN / WHEN / THEN
- GIVEN одобренные инструкторы: А (авто механика, рейтинг 4.5, стаж 8), Б (авто автомат, рейтинг 3.0, стаж 2), В (авто автомат, рейтинг 4.2, стаж 6)
- WHEN ученик применяет фильтры query-параметрами GET /api/student/instructors: transmission=manual (A); min_rating=4 (B); min_experience=5 (C); комбинация без подходящих (D)
- THEN A → только А; B → А и В; C → А и В; D → 200 с пустым списком (корректное пустое состояние, не ошибка)

## Предусловия
- Сервис собран через create_app() (uvicorn, single-worker); допускается TestClient без сети (паттерн tests/conftest.py). Чистая БД (AUTOSCHOOL_DB_PATH в tmp), init_db при старте. Контроль живости: GET /api/health → 200 {"ok": true}.
- Сессии/данные фикстур: одобренные инструкторы А и Б (approved-заявка, Спринт 2; users.role='instructor'), ученик с валидной сессией (role='student'), X-Admin-Token администратора (Спринт 0). Сессии получены через /api/auth/login.
- Все запросы к API передают токены в заголовках X-Session-Token / X-Admin-Token (механика Спринтов 0–2).

## Шаги
1. Подготовить данные (авто, отзывы, стаж через users.experience_years).
2. GET ?transmission=manual → список.
3. GET ?min_rating=4 → список.
4. GET ?min_experience=5 → список.
5. GET ?min_rating=5&min_experience=50 → код и список.

## Ожидаемый результат
2. Только А.
3. Только А и В (средние: А 4.5, В 4.2; Б 3.0 отсечен).
4. Только А и В.
5. 200 {ok:true, instructors:[]} — пустое состояние; UI показывает «ничего не найдено», не ошибку.

## Тестовые данные
Рейтинги инструкторов формируются отзывами принятых учеников (механика TC-REQ-008 + TC-REV-001). Конкретные наборы оценок:
- А — 2 ученика с оценками (5, 4) → средняя 4.5;
- Б — 2 ученика с оценками (3, 3) → средняя 3.0;
- В — 5 учеников с оценками (4, 4, 4, 4, 5) → средняя 4.2;
- итого 9 принятых учеников: каждому POST /api/student/requests + accept инструктором (TC-REQ-008), затем POST reviews с указанной оценкой. Автомобили у А/Б/В заведены заранее (TC-CAR-001).
- Стаж задается через users.experience_years (А: 8, Б: 2, В: 6).
