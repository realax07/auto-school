# TC-CAR-002 — Изоляция автомобилей между инструкторами; доступ без сессии/чужой роли

- ID кейса: TC-CAR-002
- ID чеклиста: CHK-14, CHK-16
- Источник: CHK-14/16 → Requirement «Добавление автомобиля инструктором» (instructor-cars) → FR-26; Scenarios «Автомобиль не виден другому инструктору», «Доступ к разделу без инструкторской сессии отклоняется»
- Тип: негативный
- Приоритет: Must
- Статус: ручной (не исполнялся; автоматизация — после утверждения кейсов, контракт 6; плановые TC-ID в docstring автотестов действуют до утверждения, rule 6)

## GIVEN / WHEN / THEN
- GIVEN автомобиль заведен инструктором А; существуют сессия инструктора Б, сессия ученика, гость без сессии
- WHEN Б открывает свой раздел (GET /api/instructor/cars); список запрашивают ученик и гость
- THEN у Б автомобиля А в списке нет; ученик → 403; гость → 401; списки не возвращаются

## Предусловия
- Сервис собран через create_app() (uvicorn, single-worker); допускается TestClient без сети (паттерн tests/conftest.py). Чистая БД (AUTOSCHOOL_DB_PATH в tmp), init_db при старте. Контроль живости: GET /api/health → 200 {"ok": true}.
- Сессии/данные фикстур: одобренные инструкторы А и Б (approved-заявка, Спринт 2; users.role='instructor'), ученик с валидной сессией (role='student'), X-Admin-Token администратора (Спринт 0). Сессии получены через /api/auth/login.
- Все запросы к API передают токены в заголовках X-Session-Token / X-Admin-Token (механика Спринтов 0–2).

## Шаги
1. Создать автомобиль инструктором А (TC-CAR-001).
2. GET /api/instructor/cars с токеном Б — содержимое?
3. GET /api/instructor/cars с X-Session-Token ученика — код?
4. GET /api/instructor/cars без заголовков — код?

## Ожидаемый результат
2. 200, список Б не содержит автомобиль А (у Б пуст/только свои).
3. 403 {ok:false}.
4. 401 {ok:false}.
