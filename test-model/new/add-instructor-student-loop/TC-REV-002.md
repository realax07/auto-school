# TC-REV-002 — Отзыв без принятой заявки отклоняется, в т.ч. прямым API

- ID кейса: TC-REV-002
- ID чеклиста: CHK-39, CHK-40
- Источник: CHK-39/40 → Requirement «Отзыв только реальным учеником» (reviews) → FR-34, NFR-2; Scenarios «Ученик без принятой заявки получает отказ», «Прямой вызов API без UI тоже отклоняется»
- Тип: негативный
- Приоритет: Must
- Статус: ручной (не исполнялся; автоматизация — после утверждения кейсов, контракт 6; плановые TC-ID в docstring автотестов действуют до утверждения, rule 6)

## GIVEN / WHEN / THEN
- GIVEN у ученика нет принятой заявки к инструктору А: вариант с «новой» заявкой, вариант без заявок вовсе; отдельно — ученик, принятый другим инструктором Б
- WHEN POST /api/student/instructors/{A}/reviews выполняется напрямую (мимо интерфейса) с X-Session-Token ученика
- THEN в каждом варианте 403 {ok:false} — серверная проверка связи student_requests(student, A, status='accepted'); отзыв не создается

## Предусловия
- Сервис собран через create_app() (uvicorn, single-worker); допускается TestClient без сети (паттерн tests/conftest.py). Чистая БД (AUTOSCHOOL_DB_PATH в tmp), init_db при старте. Контроль живости: GET /api/health → 200 {"ok": true}.
- Сессии/данные фикстур: одобренные инструкторы А и Б (approved-заявка, Спринт 2; users.role='instructor'), ученик с валидной сессией (role='student'), X-Admin-Token администратора (Спринт 0). Сессии получены через /api/auth/login.
- Все запросы к API передают токены в заголовках X-Session-Token / X-Admin-Token (механика Спринтов 0–2).

## Шаги
1. Подготовка связей: ученик имеет принятую заявку инструктору Б (цепочка TC-REQ-008: POST /api/student/requests к Б, затем POST /api/instructor/requests/{id}/accept {car_id} с токеном Б). К инструктору А: вариант 1 — только 'new' заявка (POST /api/student/requests); вариант 2 — заявок к А нет вовсе.
2. Вариант 1: POST /api/student/instructors/{A}/reviews {rating:5, text:"..."} напрямую, минуя UI → код.
3. Вариант 2: ученик, принятый Б, но без заявок к А: POST /api/student/instructors/{A}/reviews напрямую → код.
4. Проверить таблицу reviews.

## Ожидаемый результат
2. 403 {ok:false} (сервер проверяет связь сам — NFR-2).
3. 403 {ok:false}.
4. Записей отзывов не появилось.
