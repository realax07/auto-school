- Автотест: `tests/test_s10_backend.py::test_s10_availability_validation_types`

## GIVEN / WHEN / THEN
- GIVEN свежий инструктор (пустой график); ok_date = среда следующей недели (weekday 2)
- WHEN последовательно пять PUT с единственным интервалом в payload: one_off без date; one_off с несуществующей датой «2026-02-30»; one_off с weekday 4, не совпадающим с днем недели ok_date; recurring с непустой date; slot_type='weekly' (неизвестный тип)
