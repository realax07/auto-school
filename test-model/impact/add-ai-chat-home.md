### MODIFIED `backend/core/db.py` — таблица ai_messages

- База: существующая схема SQLite (users, bookings, ...).
- Семантика: добавлена таблица ai_messages (user_id, role, text,
  created_at); параметризованный SQL; изоляция по user_id; retention
  14 дней (DELETE старше при чтении истории).
- Воздействие: схема только расширяется (ADD TABLE) — миграции
  существующих таблиц не требуются; существующие API-тесты (С1–С18)
  не затронуты — полный regress 614 passed подтверждает.

### ADDED `ai-chat` — POST /api/ai/chat, GET /api/ai/chat/history

- Контракт: auth X-Session-Token (401 без сессии), {message}→{reply},
  история 14 дней; адаптер-провайдер за контрактом (временная
  реализация — мост к hermes-сессии, таймаут ≤30s, ошибка —
  человеческий текст; секреты/argv не в логах).
- Воздействие: новый роутер include_router в backend/app.py — пути
  /api/ai/** не пересекаются с существующими; failing-open нет
  (ошибки провайдера → 200 с человеческим текстом отказа, темы
  вне ПДД — мягкий отказ по системному промпту).
