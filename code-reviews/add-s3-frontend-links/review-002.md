(отфильтрованного), а не из `reqs`; `noreq` по-прежнему считается по `list` —
после фикса рассинхрона «empty поверх полного списка» больше нет по построению.

- блок «empty при фильтре»: единственная заявка «На рассмотрении» → клик
  «Отказанные» → `#noreq` виден И `.req` count == 0 (именно тот сценарий,
  который раньше показывал пустой блок поверх полного списка); возврат на
  «Все» → карточка видна;
- блок «фильтрация по статусам»: после accept+deny — «Отказанные» → 1 карточка
  со статусом «Отказана», «Принятые» → 1 карточка «Принята», «Все» → 2.
Ассерты падали бы на прежнем коде (рендер игнорировал фильтр) — дыра NIT-5/F1
закрыта по существу. Подтверждено прогоном.
