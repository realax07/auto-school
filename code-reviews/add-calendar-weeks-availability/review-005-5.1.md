  пересмотреть — design это прямо допускает).
- «Сейчас» — МСК: nowMoscow() (utils.js, Europe/Moscow = UTC+3, единая
  точка с сервером); локальная таймзона не используется; сравнения
  границ строятся на наивных Date с МСК-компонентами с обеих сторон —
