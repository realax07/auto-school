## Проверенные Scenario (спека instructor-application)

- Успешная отправка: 200 {ok:true}, заявка waiting со всеми полями, ФИО
  разобрано, только хэш; работа на авто Сбера — plate необязателен.
- Отклонение анкеты с email существующего пользователя / существующей
  заявки — единое сообщение, заявка не создана.
- Гонка: ровно одна заявка на email (второй сабмит — контрактная 422).
- Отклонение некорректной анкеты: все 18 вариантов валидации → 422,
  запись не создается.
- Отправка без согласия → 422 «Согласие: поле обязательно» (MIN-2),
  порядок до формата email.
- В заявке хранится только хэш (TC-FR11.1-001).
- Файл ВУ не загружается (в контракте/INSERT отсутствует).
