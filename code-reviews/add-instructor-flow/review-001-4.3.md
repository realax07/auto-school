## Проверенные Scenario (спека instructor-auth)

- Заявка waiting — экран ожидания (страница существует, публична по GET,
  тон согласован).
- Заявка deny — экран отказа с причиной (после входа с паролем; прямое
  открытие без данных логина причины не показывает).
- Статусный экран недоступен без проверки пароля — причина не раскрывается
  (нет sessionStorage-ключа → пустой rejected).
