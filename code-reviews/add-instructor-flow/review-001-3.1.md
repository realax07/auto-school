## Проверенные Scenario (спека instructor-auth, бэкенд-часть)

- Вход одобренного инструктора (approve через реальный админ-API в тесте) —
  сессия + /me отвечает.
- Заявка waiting — экран ожидания (pending, без сессии).
- Заявка deny — экран отказа с причиной C (без сессии).
- Единое сообщение при отсутствии и пользователя, и заявки.
- Неверный пароль отклоняется единым сообщением.
- Анти-брутфорс единый по IP (включая попытки против заявки).
- Регресс Спринта 1: ученик — route=student-cabinet + токен.

(rejected без sessionStorage-ключа не показывает причину) проверена в
задаче 4.3; бэкенд-часть (reason только после верного пароля) — здесь.
