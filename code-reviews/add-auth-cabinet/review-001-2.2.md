## Проверенные Scenario (спека)

- auth / Вход ученика: сабмит → POST /api/auth/login (JSON {email,
  password}); ok → токен в sessionStorage, редирект /cabinet (wiring +
  живой прогон API на integration-ветке: 200 {ok,token}).
- auth / Единое сообщение: 401 → `err.textContent = res.data.error` под
  формой, без деталей причины в коде фронтенда; серверная единость
  проверена в 1.1 (идентичность всех причин) — связка сходится.
- cabinet / «После входа открыт кабинет»: wiring-редирект
  `location.href='/cabinet'` (исполнение — вне TestClient, паттерн
  проекта; см. замечание #3).
- cabinet / Соответствие мокапу (FR-9, модалка): тесты дословности
  LOGIN_MODAL_TEXTS + мой diff против login-modal.html — только wiring.
