Не является замечанием (соответствует контракту/решениям):
- **Маршрут /instructors/pending:** FileResponse
  `frontend/vue/dist/instructors-pending.html`, media_type `text/html; charset=utf-8`;
  запись убрана из `_PAGE_ROUTES` (комментарий в словаре объясняет), остальные 12

  Проверка is_file с 404 — тот же паттерн, что у остальных страниц.
- **Статика /vue/assets/{path:path}:** content-type по белому списку суффиксов
  (`.js` → application/javascript, `.css` → text/css) — явно, без системных
  mimetypes (паттерн `/js/{filename}`); неизвестный суффикс и скрытые файлы — 404.
  Обход каталогов исключен: `'/' in path or '..' in path or path.startswith('.')`
  → 404; URL-энкодинг (%2e%2e%2f) декодируется Starlette ДО хендлера и отсекается
  той же проверкой; слэш в path невозможен без 404 → конструирование пути вне
  assets не достижимо. Отдача тем же сервисом — ADR-001.
- **Legacy-файл удален целиком** (FR-86/ОВ-4, «замена монолита, без параллельного
  существования») — дифф удаляет файл; grep-контроль чист.
