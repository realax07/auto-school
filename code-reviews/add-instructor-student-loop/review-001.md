## Не является замечанием (проверено и соответствует)

- **SQL (фокус 2):** grep всех новых модулей — только `?`-плейсхолдеры; единственный f-string — `PRAGMA table_info({table})` в db.py:128 по именам из хардкод-кортежа `_COLUMN_MIGRATIONS`, пользовательский ввод не участвует. NFR-3 выполнен; тест test_new_modules_no_sql_concatenation фиксирует регресс.
- **Миграции (фокус 3):** pattern `users.role` воспроизведен корректно; test_migration_is_idempotent, test_migration_of_legacy_db_without_new_columns — повторный init и подъем легаси-БД Спринтов 0–2 зеленые; users.experience_years NOT NULL DEFAULT 0 / заявка NULL — по решению MAJ-3.
- **Файлы/доступ (фокус 1, матрица):** изображение ВУ — только X-Admin-Token (401 без токена, 404 без файла — test_admin_card_and_license_image, test_license_image_direct_url_not_served: data/ не раздается статикой); фото авто — только владельцу (401/403/404 по MIN-2, тест есть); публичная карточка — без фото и госномера. Имена uuid, magic bytes проверяются, содержимое не попадает в исполняемые пути. Ответ image/*.
- **ОВ-решения (фокус 4):** автозакрытие ОВ-1 (new+accepted, единый системный комментарий) в одной транзакции — тест test_accept_closes_other_active_requests_new_and_accepted покрывает разрыв чужой accepted-связи; ОВ-4 (0 авто → 409) и чужой car_id (422) покрыты; deny без комментария заблокирован (422) — тест и e2e с реальным вводом «только пробел». Гонки — см. #6/#7.
- **Админ-карточка:** textContent-паттерн, blob→objectURL с revoke, 401→логин, пустое состояние без битой картинки — сделано аккуратно.
