# Требования: Регистрация и админ-контур (Спринт 0)

> Автор: PM-агент (main, Egor Kotov)
> Статус: УТВЕРЖДЕН

## Описание

Площадка-автошкола (веб). Спринт 0: контур «регистрация ученика → БД → админка».
Фронт — утвержденные Заказчиком HTML-макеты (design/mocks). Бэкенд — один
API-сервис (FastAPI + SQLite). Личные кабинеты, инструкторы, деплой — НЕ в
этом спринте.

## Аудитория

Ученики (регистрация), администратор школы (просмотр/выгрузка записей).

## Функциональные требования

- FR-1: Система MUST сохранять регистрацию ученика: фамилия, имя, отчество,
  email, телефон, пароль, подтверждение пароля.
- FR-2: Система MUST отклонять регистрацию при: незаполненном поле, неверном
  формате email, короче 8 символов пароле, несовпадении пароля и подтверждения,
  уже существующем email.
- FR-3: Пароль MUST храниться bcrypt-хэшем (cost 12), никогда открытым текстом.
- FR-4: После успешной регистрации пользователь MUST попадать на страницу
  «Регистрация завершена».
- FR-5: Администратор MUST входить в админку по логину/паролю из .env
  (ADMIN_USER + ADMIN_PASSWORD_HASH, bcrypt).
- FR-6: Админка MUST показывать список зарегистрированных пользователей
  (ФИО, email, телефон, дата; свежие сверху).
- FR-7: Админка MUST выгружать CSV (BOM, разделитель «;», колонки ФИО;Email;
  Телефон;Роль;Дата регистрации).
- FR-8: Админ-API MUST требовать токен, выдаваемый только после успешного входа.
- FR-9: Страницы лендинга/модалок MUST соответствовать утвержденным макетам
  design/mocks (текстовки дословно).

## Нефункциональные требования

- NFR-1: Ответ API регистрации MUST быть ≤ 500 мс на типичных данных.
- NFR-2: SQL MUST быть параметризованным (без конкатенации строк).
- NFR-3: Секреты MUST жить в .env (.env в .gitignore, есть .env.example).

## Приоритеты (MoSCoW)

- Must: FR-1…FR-9, NFR-1…NFR-3.

## Ограничения

- Стек: FastAPI + SQLite + статика без сборки; Python ≥ 3.11.
- Спринт 0: без кабинетов, инструкторов, nginx, контейнеров, деплоя.

## Открытые вопросы

- Нет (все закрыты: пароль+подтверждение — да; админ из .env — да).
