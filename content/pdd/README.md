# Контент ПДД для кабинета ученика

Текстовый контент для будущих обучающих разделов кабинета ученика (знаки,
правила, билеты). Решение Заказчика 2026-11-15: собираем текст с
сайта-источника, на продукте ничего не реализуем до отдельного спринта.

## Источник

https://xn----7sbnackuskv0m.xn--p1ai/ («Экзамен ПДД онлайн от ГИБДД»).
Дата выгрузки: **2026-11-15**. В каждом файле — шапка с исходным URL и
датой (трассировка содержимого).

## Структура

```
content/pdd/
├── pravila/   26 глав правил ПДД (r1_…r26_, текст пунктов полностью)
├── znaki/      7 групп знаков (t1_…t7_, 244 знака: номер + название + описание)
└── bilety/
    ├── abm/   40 билетов категории A/B/M (по 20 вопросов)
    └── cd/    40 билетов категории C/D (по 20 вопросов)
```

## Формат билета

Каждый вопрос: текст вопроса → варианты ответа → верный помечен ✅ →
пояснение к ответу. Изображения вопросов НЕ выгружались (только текст —
решение Заказчика); для вопросов с картинкой в файле стоит пометка
`*Изображение вопроса: `<имя>`*` со ссылкой на источник.

## Обновление

Перегенерация — скриптом-краулером (Playwright, страница → DOM-селекторы
`.content-container` / `.znak-info` / `.bilet-otvety-block`). Скрипт не
в репозитории (разовая выгрузка), при необходимости повторной выгрузки —
восстанавливается по селекторам из этого README.
