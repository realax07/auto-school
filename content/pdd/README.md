# Контент ПДД для кабинета ученика

Текстовый контент обучающих разделов кабинета ученика (знаки, правила,
билеты, штрафы). Решение Заказчика 2026-11-15: текст выгружен с
сайта-источника; доставка на продукт — build-time генератор
`frontend/vue/scripts/generate-pdd-json.mjs` (шаг `npm run build`,
Спринт 17, change add-pdd-learning). Сами файлы корпуса руками не
правятся — только перегенерация (вне S17); этот README — документация
фактов корпуса (задача 17.2.4).

## Источник

https://xn----7sbnackuskv0m.xn--p1ai/ («Экзамен ПДД онлайн от ГИБДД»).
Дата выгрузки: **2026-11-15**. В каждом файле — шапка с исходным URL и

## Структура

```
content/pdd/
├── pravila/            26 глав правил ПДД (r1_…r26_, полный текст пунктов;
│                       у каждой ровно один H1 — заголовок главы)
├── znaki/              8 групп знаков (t1_…t8_, 321 знак: номер + название)
├── znaki-details.json  321 запись индивидуальных страниц источника
│                       (ключ — slug; поля title/desc/fine/img/long)
├── bilety/
│   ├── abm/            40 билетов категории A/B/M (по 20 вопросов)
│   └── cd/             40 билетов категории C/D (по 20 вопросов)
├── shtrafi/            shtrafi-gibdd.md — таблица штрафов КоАП
│                       (заголовок «Пункт КоАП/Нарушение/Наказание»,
│                       58 tab-separated строк + навигационный блок
│                       «Популярные штрафы» — не данные таблицы)
└── images/
    ├── znaki/          321 файл: <номер>small.png (у каждого знака ровно один)
    └── bilety/         1292 файла изображений вопросов (v3; выгружены)
```

## Знаки (группы и детали)

- **8 групп** t1…t8: Предупреждающие (47), Приоритета (13), Запрещающие
  (38), Предписывающие (24), Особых предписаний (63), Информационные (37),
  Сервиса (22), Таблички (77) — сумма 321.
- Формат заголовков group-md: `## N.N` (t1…t7) и `## | N.N` (t8,
  «Таблички» — pipe перед номером); генератор обрабатывает оба формата.
- **znaki-details.json** — второй вход генератора (детали и штрафы):
  title/desc/fine/img/long. Номер знака парсится из title
  («Знак 4.4.1 …» → 4.4.1; 321/321, множества номеров совпадают с
  group-md в обе стороны); **группа знака — только из group-md** (поле
  long — мусор источника: «Предупреждающие» у всех 321, не используется);
  **img пуст у всех 321** (не используется). desc непуст у 319/321 —
  пусты ровно 5.33.1 и 5.34.1 (допустимые пустоты источника, гейт-допуск
  генератора); fine непуст у 166/321 (опционален — блок штрафа рендерится
  при наличии записи).

## Формат билета

Каждый вопрос: текст вопроса → (опционально) изображение
`![…](../images/bilety/<имя>)` → варианты ответа (`- N. текст`) → верный
помечен ✅ → `**Пояснение:**`. Изображения вопросов выгружены (1292
файлов, v3). В images/bilety 198 файлов без ссылок из .md (дубли
загрузки, включая crawl-артефакт «none_gray.jpg?» с «?» в имени) — не
удаляются (корпус не трогается) и **в выдачу генератора не попадают**:
инвентарь изображений строится по белому списку ссылок из .md (design.md
«Гейты»); через URL-путь артефакт с «?» неотдаваем в принципе.

  pdd-manifest.json (манифест для тестов целостности).
- Гейты целостности — провал сборки: 80×20, один ✅ на вопрос, 2–5
  вариантов, ссылки ../images/bilety/* существуют, 321 знак с
  <номер>small.png, znaki-details 321 записи (join по title, допуски
  desc 5.33.1/5.34.1), 26 глав с одним H1, 3 tab-поля в строке штрафов.
- Изображения — статикой: GET /pdd-assets/{znaki|bilety}/{file}
  (backend/app.py, из content/pdd/images; Dockerfile COPY content/).

## Правовая заметка

Контент выгружен по прямой задаче Заказчика для внутреннего использования
в продукте. Экзаменационные вопросы ПДД — официальные материалы ГИБДД;
правила — действующая редакция ПДД РФ. Разделы обучения живут в
авторизованном кабинете; изображения отдаются публичным роутом /pdd-assets
(учебные материалы, как /vue/assets). Перед продакшн-использованием в
публичной части сайта проверить лицензионные условия источника.
