# PLAN.md — Auto School

> Источник правды по релизам проекта. Все релизы планируются здесь: что войдет,
> как, какие этапы. Дополняется по мере прогресса. Не зависит от сессий агента.

## Как читать этот файл

- **Релизы** — крупные поставки ценности, каждая со своим составом и этапами.
- **Этапы релиза** идут по конвейеру AI Factory (Флоу 1): требования → спека →
  разработка → QA → релиз.
- Статусы: `[ ]` план → `[~]` в работе → `[x]` готово.
- Пожелания в этот файл НЕ попадают напрямую — сначала в BACKLOG.md, оттуда
  при формировании спринта — сюда.

## Решения

- **Релизы планируются только через этот файл** (решение Заказчика 2026-10-06).
- **BACKLOG.md — вход пожеланий.** Разработка по пожеланию начинается только
  после включения в спринт (решение Заказчика 2026-10-06).
- **Спринты:** набор фич из бэклога; новый спринт формируется после окончания
  предыдущего (решение Заказчика 2026-10-06).
- Конвейер: AI Factory (см. agents/, contracts/), Флоу 1 для фич, Флоу 2 для багов.
- Стек: определяется на этапе СА первого релиза.
