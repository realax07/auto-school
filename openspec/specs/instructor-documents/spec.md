# instructor-documents Specification

## Purpose

Возможность обеспечивает загрузку и хранение документов инструктора (ВУ при регистрации, СТС автомобилей) с доступом: админ — полный, владелец — к своим; прямые URL исключены.

## Requirements

### Requirement: Сохранение файла ВУ при подаче анкеты

Анкета инструктора MUST сохранять загруженный файл изображения ВУ на
стороне сервера; заявка MUST хранить ссылку на сохраненный файл. Файл
MUST проверяться по типу (изображение JPEG/PNG) и размеру (не более
5 МБ); файл иного типа или превышающий лимит — заявка не создается,
клиент получает ошибку валидации. Отправка без файла — по правилам
обязательности полей утвержденного макета анкеты (трассировка: FR-23,
NFR-6).

Источник: requirements-instructor-student-loop.md FR-23, NFR-6; ОВ-5.

#### Scenario: Заявка с изображением ВУ сохраняет файл

- **GIVEN** анкета заполнена корректно и выбран файл изображения ВУ (JPEG, 2 МБ)
- **WHEN** анкета отправлена
- **THEN** файл сохранен на стороне сервера, заявка создана и хранит ссылку на сохраненный файл

#### Scenario: Файл недопустимого типа отклоняется

- **GIVEN** анкета заполнена и вместо изображения выбран файл PDF
- **WHEN** анкета отправлена
- **THEN** заявка не создается, клиент получает ошибку валидации типа файла

#### Scenario: Файл больше 5 МБ отклоняется

- **GIVEN** анкета заполнена и выбран файл изображения размером 6 МБ
- **WHEN** анкета отправлена
- **THEN** заявка не создается, клиент получает ошибку валидации размера файла

#### Scenario: Отправка без файла — по правилам макета

- **GIVEN** анкета заполнена без файла ВУ
- **WHEN** анкета отправлена
- **THEN** результат — по правилам обязательности полей утвержденного макета: поле обязательно — ошибка валидации и заявка не создана; поле необязательно — заявка создана без ссылки на файл

### Requirement: Выдача изображения ВУ только по админ-токену

Изображение ВУ заявки MUST выдаваться только при валидном админ-токене
(X-Admin-Token, механизм Спринта 0). Без токена, с неверным или истекшим
токеном — отказ доступа, изображение не возвращается. Изображение ВУ
никогда не выдается по ученической или инструкторской сессии и гостю.
Прямые URL файлов без проверки доступа недопустимы: каталог загрузок не
входит в раздаваемую статику (трассировка: FR-24, NFR-1).

Источник: requirements-instructor-student-loop.md FR-24, NFR-1.

#### Scenario: Админ с валидным токеном получает изображение

- **GIVEN** существует заявка с загруженным ВУ и валидный админ-токен
- **WHEN** админ запрашивает изображение ВУ этой заявки с заголовком X-Admin-Token
- **THEN** изображение возвращается (тип image/jpeg или image/png)

#### Scenario: Запрос изображения без токена отклоняется

- **GIVEN** существует заявка с загруженным ВУ
- **WHEN** изображение запрашивается без заголовка X-Admin-Token
- **THEN** отказ доступа, изображение не возвращается

#### Scenario: Запрос изображения с неверным токеном отклоняется

- **GIVEN** существует заявка с загруженным ВУ
- **WHEN** изображение запрашивается с неверным значением X-Admin-Token
- **THEN** отказ доступа, изображение не возвращается

#### Scenario: Ученическая сессия не дает доступ к изображению ВУ

- **GIVEN** существует заявка с загруженным ВУ и валидная сессия ученика
- **WHEN** изображение ВУ запрашивается с ученической сессией
- **THEN** отказ доступа, изображение не возвращается

#### Scenario: Прямой URL файла не работает

- **GIVEN** файл ВУ сохранен в каталоге загрузок сервера
- **WHEN** файл запрашивается по прямому URL без проверки доступа
- **THEN** файл не выдается (каталог загрузок не раздается как статика)

### Requirement: Карточка инструктора в админке с изображением ВУ

Детальная карточка инструктора в админке MUST открываться кликом по строке
таблицы заявок и MUST показывать полные данные заявки, включая загруженное
изображение ВУ (трассировка: FR-25).

Источник: requirements-instructor-student-loop.md FR-25.

#### Scenario: Клик по строке открывает карточку с данными и ВУ

- **GIVEN** заявка с загруженным ВУ присутствует в таблице админки
- **WHEN** админ кликает по строке заявки
- **THEN** карточка показывает данные анкеты и изображение ВУ

#### Scenario: Карточка заявки без ВУ

- **GIVEN** заявка без загруженного ВУ присутствует в таблице админки
- **WHEN** админ кликает по строке заявки
- **THEN** карточка показывает данные анкеты, место изображения — корректное пустое состояние (не ошибка и не «битая» картинка)
