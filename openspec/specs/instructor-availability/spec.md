# instructor-availability Specification

## Purpose

Возможность дает инструктору управлять рабочими интервалами недели (календарь часов работы): сохранение графика, валидация интервалов. График служит источником слотов для бронирования учениками (Спринт 5).

## Requirements

### Requirement: Выбор рабочих интервалов в календаре

Раздел «Календарь» кабинета инструктора MUST позволять выбирать часы
работы на сетке недели/дня: выделенные интервалы помечаются как рабочие.
Интервал MUST иметь корректные границы (начало раньше конца); некорректный
интервал не сохраняется (трассировка: FR-29, NFR-5).

Источник: requirements-instructor-student-loop.md FR-29, NFR-5.

#### Scenario: Выделенный интервал помечается рабочим

- **GIVEN** инструктор с валидной сессией находится в разделе «Календарь»
- **WHEN** он выделяет интервал (например, Пн 10:00–14:00) и сохраняет
- **THEN** интервал помечен как рабочий (сохранен как рабочий час инструктора)

#### Scenario: Некорректный интервал отклоняется

- **GIVEN** инструктор задает интервал с концом раньше начала (например, Пн 14:00–10:00)
- **WHEN** он пытается сохранить график с таким интервалом
- **THEN** интервал не сохраняется, клиент получает ошибку валидации

#### Scenario: Доступ к календарю без инструкторской сессии отклоняется

- **GIVEN** гость без сессии или пользователь с ролью 'student'
- **WHEN** запрашивается график часов работы этого инструктора
- **THEN** доступ запрещен (401 для гостя, 403 для иной роли), график не возвращается

### Requirement: Сохранение и восстановление графика

График часов работы MUST сохраняться (сущность availability) и MUST
восстанавливаться при следующем входе инструктора. Изменение графика
перезаписывает ранее сохраненный (трассировка: FR-30).

Источник: requirements-instructor-student-loop.md FR-30.

#### Scenario: График восстанавливается после перезахода

- **GIVEN** график сохранен (например, Пн 10:00–14:00)
- **WHEN** инструктор выходит, входит заново и открывает календарь
- **THEN** отмечены те же интервалы, что были сохранены

#### Scenario: Изменение графика перезаписывает сохраненный

- **GIVEN** график Пн 10:00–14:00 сохранен
- **WHEN** инструктор снимает этот интервал, добавляет Ср 09:00–12:00 и сохраняет
- **THEN** при следующем входе отмечен только Ср 09:00–12:00
