# reviews Specification

## Purpose

Возможность позволяет реальным ученикам (с принятой заявкой) оставлять отзывы инструкторам и формирует агрегированный рейтинг, используемый в каталоге и фильтрах.

## Requirements

### Requirement: Отзыв только реальным учеником

Отзыв об инструкторе (оценка + текст) MAY оставить только реальный
ученик — пользователь с принятой заявкой к этому инструктору. Проверка
связи MUST выполняться на сервере при создании отзыва; проверка только
на UI недостаточна. Без связи действие отклоняется, отзыв не создается.
Повторный отзыв (уникальная пара ученик↔инструктор) не создается.
Оценка — целое число 1–5, текст непустой (трассировка: FR-34, NFR-2,
NFR-5).

Источник: requirements-instructor-student-loop.md FR-34, NFR-2, NFR-5.

#### Scenario: Принятый ученик оставляет отзыв

- **GIVEN** заявка ученика к инструктору принята (связь подтверждена)
- **WHEN** ученик оставляет отзыв (оценка 5, текст) этому инструктору
- **THEN** отзыв сохраняется и учитывается в агрегате рейтинга инструктора

#### Scenario: Ученик без принятой заявки получает отказ

- **GIVEN** у ученика нет принятой заявки к этому инструктору (нет связи)
- **WHEN** он пытается оставить отзыв этому инструктору
- **THEN** действие отклонено, отзыв не создается

#### Scenario: Прямой вызов API без UI тоже отклоняется

- **GIVEN** у пользователя с сессией student нет принятой заявки к инструктору
- **WHEN** POST-запрос создания отзыва выполняется напрямую (мимо интерфейса)
- **THEN** сервер отклоняет действие (проверка связи на сервере), отзыв не создается

#### Scenario: Повторный отзыв отклоняется

- **GIVEN** ученик с принятой заявкой уже оставил отзыв инструктору
- **WHEN** он пытается оставить второй отзыв тому же инструктору
- **THEN** действие отклонено (уникальная пара ученик↔инструктор), второй отзыв не создается

#### Scenario: Некорректная оценка отклоняется

- **GIVEN** ученик с принятой заявкой заполняет форму отзыва
- **WHEN** он отправляет отзыв с оценкой вне диапазона 1–5 (например, 0 или 6) или с пустым текстом
- **THEN** отзыв не создается, клиент получает ошибку валидации

### Requirement: Агрегат рейтинга на карточке инструктора

Карточка инструктора MUST показывать агрегат рейтинга: средняя оценка по
отзывам и количество отзывов. При отсутствии отзывов MUST отображаться
«нет отзывов», а не 0.0 (трассировка: FR-35).

Источник: requirements-instructor-student-loop.md FR-35.

#### Scenario: Средний рейтинг и число отзывов на карточке

- **GIVEN** у инструктора есть отзывы (например, оценки 5, 4, 4)
- **WHEN** ученик открывает карточку инструктора
- **THEN** на карточке показаны средняя оценка (например, 4.3) и число отзывов (3)

#### Scenario: Нет отзывов — «нет отзывов»

- **GIVEN** у инструктора нет ни одного отзыва
- **WHEN** ученик открывает карточку инструктора
- **THEN** на карточке показано «нет отзывов», а не 0.0
