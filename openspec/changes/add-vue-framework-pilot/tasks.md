## План тестовых прогонов (наборы — отдельные делегации-раннеры)

1. **API/регресс**: `pytest tests/` (кроме playwright) — uvicorn/TestClient,

2. **e2e полный**: `pytest tests/test_ui_playwright.py` (49 сценариев) —
   стенд: собранный dist (`npm ci && npm run build` ДО прогона —
   обязательный шаг), uvicorn на эфемерном порту, Chromium headless;
   ~15–30 мин.
3. **Валидации**: `openspec validate --all --strict` +
   `python3 scripts/flow_check.py .` — секунды, локально без стенда.
Прогоны 1 и 2 НЕ объединять в один сабагент-раннер (разные стенды и
длительности); сборка dist выполняется один раз до прогонов 2 и приемки
бюджетов (4.1).
