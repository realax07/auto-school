# Delta: instructor-documents

## ADDED Requirements

### Requirement: Раздел «Мои документы» инструктора

Кабинет инструктора MUST содержать раздел «Мои документы» со списком
ВСЕХ загруженных документов инструктора: ВУ (загруженное в анкете) и СТС
по каждому автомобилю. Для каждого документа MUST быть видны тип,
привязка (для СТС — марка/модель/госномер автомобиля) и дата загрузки;
для каждого документа доступны просмотр (открыть изображение) и
скачивание. Документы доступны только самому инструктору (трассировка:
FR-45, NFR-7).

Источник: requirements-booking-docs.md FR-45, NFR-7.

#### Scenario: Список включает ВУ и СТС всех автомобилей

- **GIVEN** инструктор с анкетой, содержащей ВУ, и 2 автомобилями (СТС у каждого)
- **WHEN** он открывает раздел «Мои документы»
- **THEN** он видит 3 записи: ВУ и два СТС — с типом, привязкой (для СТС — марка/модель/госномер авто) и датой загрузки

#### Scenario: Анкета без ВУ — корректное пустое состояние

- **GIVEN** инструктор подавал анкету без файла ВУ
- **WHEN** он открывает раздел «Мои документы»
- **THEN** ВУ в списке отсутствует с корректным пустым состоянием и подсказкой (механизма досыла ВУ в этом объеме нет); СТС автомобилей отображаются

#### Scenario: Просмотр и скачивание документа

- **GIVEN** у инструктора есть загруженный документ
- **WHEN** он открывает документ для просмотра или скачивает его
- **THEN** изображение возвращается (просмотр и скачивание доступны)

#### Scenario: Документы доступны только владельцу

- **GIVEN** документы принадлежат инструктору А
- **WHEN** другой инструктор, ученик (в том числе из пары с А) или гость запрашивает список или файл документов А
- **THEN** доступ запрещен, документы не возвращаются
