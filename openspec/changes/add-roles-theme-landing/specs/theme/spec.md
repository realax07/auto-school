# Delta: theme

## ADDED Requirements

### Requirement: Темы интерфейса: светлая, тёмная, системная

Интерфейс MUST поддерживать тёмную (канон) и светлую темы и MUST
переключать их сегмент-переключателем в кабинете (Тёмная/Светлая/Авто);
выбор MUST сохраняться в localStorage и применяться при следующих
визитах; при отсутствии сохранённого выбора MUST применяться системная
схема (prefers-color-scheme). Переключение MUST происходить без
перезагрузки страницы. Реализация волны 21.4 (MVP по решению Заказчика):
светлый режим — инверсионный поверх тёмного канона (filter-подход с
обратной инверсией изображений); полноценная светлая палитра —
следующая волна.

#### Scenario: Переключение темы без перезагрузки

- **GIVEN** открыт кабинет в тёмной теме
- **WHEN** пользователь переключает тему на светлую
- **THEN** тема применяется без перезагрузки страницы (data-theme на html); выбор сохраняется в localStorage

#### Scenario: Системная тема по умолчанию

- **GIVEN** пользователь впервые открывает сайт без сохранённого выбора
- **WHEN** система определяет prefers-color-scheme
- **THEN** применяется тема, соответствующая системной настройке пользователя

#### Scenario: Сохранение выбора между визитами

- **GIVEN** пользователь выбрал светлую тему
- **WHEN** он закрывает и заново открывает сайт
- **THEN** светлая тема применена, переключатель отражает сохранённый выбор
