# Delta: theme

## ADDED Requirements

### Requirement: Темы интерфейса: светлая, тёмная, системная

Интерфейс MUST поддерживать светлую и тёмную темы и MUST переключать их
переключателем в кабинете; выбранная тема MUST сохраняться для
пользователя (localStorage) и применяться при следующих визитах; при
отсутствии сохранённого выбора MUST применяться системная схема
(prefers-color-scheme). Переключение MUST происходить без перезагрузки
страницы (CSS-переменные на корневом элементе).

#### Scenario: Переключение темы без перезагрузки

- **GIVEN** открыт кабинет в тёмной теме
- **WHEN** пользователь переключает тему на светлую
- **THEN** цвета интерфейса меняются без перезагрузки страницы; выбор сохраняется в localStorage

#### Scenario: Системная тема по умолчанию

- **GIVEN** пользователь впервые открывает сайт без сохранённого выбора
- **WHEN** система определяет prefers-color-scheme
- **THEN** применяется тема, соответствующая системной настройке пользователя

#### Scenario: Сохранение выбора между визитами

- **GIVEN** пользователь выбрал светлую тему
- **WHEN** он закрывает и заново открывает сайт
- **THEN** светлая тема применена, переключатель отражает сохранённый выбор
