# Delta: landing-assistant

## ADDED Requirements

### Requirement: Интерактивный блок ГигаЧата на публичном лендинге

Блок ГигаЧата на публичном лендинге MUST быть интерактивным: поле ввода
активно, кнопки сценариев кликабельны и ведут на регистрацию/вход
(для незалогиненных) либо в живой чат «Главной» (для залогиненных).
Блок MUST соответствовать канону чата Спринта 19 (мокапы mobile-v2 /
web-v3, решение Заказчика 2026-11-18) и MUST быть доступен на мобильном
и десктопном вьюпортах без переполнений.

#### Scenario: Поле ввода ведёт незалогиненного на регистрацию

- **GIVEN** пользователь не залогинен и открыл публичный лендинг
- **WHEN** он вводит вопрос в поле ГигаЧата и нажимает отправить
- **THEN** открывается модалка регистрации с подсказкой «Задайте этот вопрос ГигаЧату после входа», введённый текст сохраняется в поле

#### Scenario: Кнопки сценариев интерактивны

- **GIVEN** открыт публичный лендинг
- **WHEN** пользователь нажимает кнопку сценария (например «Хочу выучиться на права»)
- **THEN** выполняется соответствующее действие: переход к регистрации с предзаполненным контекстом сценария, без мёртвых кнопок
