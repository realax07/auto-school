# Design: add-roles-theme-landing (Спринт 21)

## Роли в регистрации

Мокап auth-register-choice (утверждён 2026-11-19): экран выбора —
две карточки («Я ученик» / «Я инструктор»). Реализация: модалка
m-register лендинга получает шаг 0 (choice) → выбор student рендерит
существующую форму ученика (поля без изменений), выбор instructor —
редирект в существующую анкету инструктора (/#instructor-application
маршрут анкеты — текущее место инструкторской регистрации). Сервер:
RegisterRequest.role уже принимает student|instructor (19.2 не трогаем),
инструкторская регистрация сохраняет заявку route=pending (существующий
контракт). Ничего в backend не меняется — фронтовая развилка.

## Лендинг-блок ГигаЧата

Блок assistant остаётся на месте (hero-grid), но: поле ввода активно —
send при незалогиненном открывает m-register с подсказкой (спека
landing-assistant, Scenario 1); quick-кнопки → registration с
data-context сценария; для залогиненных (токен в sessionStorage) send
редиректит в /#home чат с предзаполнением сообщения (событие через
sessionStorage-бридж). Верстка: канон чата С19 (bubble-стиль, зелёный
акцент), scrollWidth ≤390 на мобильном.

## Темы

CSS-переменные объявлены дважды: :root (тёмная, текущий канон) и
:root[data-theme="light"] (светлая палитра: bg #f6f8f6, ink #17201b,
green #1f9d5b). data-theme ставится на document.documentElement из
localStorage('theme') при boot (main.js до монтирования — MPA-префикс:
правка в ОБЕИХ копиях: статический HTML-ввод + компонент, правило
pre-mount). Переключатель: сегмент-контрол в сайдбаре кабинета
(День/Ночь/Авто). prefers-color-scheme при отсутствии ключа.
Правка затрагивает все страницы — носители-цвето-зависимые проверяются
на канон без ослаблений (тёмный канон — база, светлый — новая палитра).

## Риски

- Светлая палитра должна пройти контраст на носителях TC-UI (серые
  подписи 9aa39d на светлом не читаются — палитра пересчитана).
- Регистрация инструктора ведёт на анкету — проверить модерационный
  статус-пейдж не сломан развилкой (существующие носители).
