# Delta: Frontend

## ADDED Requirements

### Requirement: Лендинг ученика на Vue (/)

Страница / MUST обслуживаться каркасом Vue 3 + Vite (вход из dist);
legacy index.html и js/landing.js MUST быть удалены (монолит целиком).
Модалки входа/регистрации MUST быть вынесены в shared-компоненты
каркаса (разметка 1:1). Контракт входа (route/reason → sessionStorage
«instructor_rejected_reason» до редиректа) и регистрации (согласие
FR-78) MUST не изменяться; вид — без редизайна.

Источник: FR-1/2/13/17/78; FR-84…86; NFR-26/27; ADR-008.

#### Scenario: Лендинг обслуживается каркасом Vue

- **GIVEN** сборка каркаса выполнена (dist существует)
- **WHEN** гость открывает /
- **THEN** страница отдается входом каркаса Vue (html со ссылками на ассеты префикса /vue/), а не legacy-HTML-монолитом; маршрут / не изменился; legacy index.html и js/landing.js отсутствуют в исходниках

#### Scenario: Вход — route/reason контракт не меняется, включая rejected

- **GIVEN** вход из модалки m-login на Vue-лендинге с email заявки в статусе deny с комментарием C (логин отвечает route=rejected и reason=C)
- **WHEN** ответ получен
- **THEN** Vue-wiring модалки пишет sessionStorage «instructor_rejected_reason»=C ДО редиректа на /instructors/rejected (сценарий TC-S9UI-003 проходит без правок); approved → /instructor/dashboard, waiting → /instructors/pending, ученик → /cabinet; ошибка — текст сервера в #login-error

#### Scenario: Регистрация — согласие обязательно (FR-78)

- **GIVEN** модалка m-register на Vue-лендинге (TC-UI-002/043 без правок)
- **WHEN** чекбокс согласия снят / установлен
- **THEN** #reg-submit недоступен до установки и выполняет POST /api/register с consent после нее (200 → сессия и /cabinet; 422 — текст сервера в #reg-error); ссылка на /policy видна в блоке согласия

#### Scenario: Семантика модалок и заглушки сохранены

- **GIVEN** гость на Vue-лендинге
- **WHEN** открыты/закрыты модалки и нажаты элементы-заглушки
- **THEN** крестик #login-close, «Отмена» и Esc закрывают, клик по фону НЕ закрывает #m-login (BUG-055/056, TC-UI-053 без правок); чат-бар «Гига ГАИшник», .quick и #to-teachers ведут себя как в legacy (визуальные заглушки); TC-UI-001 проходит без правок

#### Scenario: Визуальная эквивалентность текущему лендингу

- **GIVEN** сравнение Vue-версии с текущим лендингом
- **WHEN** выполнено сопоставление содержимого
- **THEN** эквивалентность без редизайна: шапка с брендом, hero «Права — без лишнего пути.», шаги 01–04, чат-бар «Гига ГАИшник», плитки сервисов и футер — тексты дословно

### Requirement: Анкета инструктора на Vue (/instructors/apply)

Страница /instructors/apply MUST обслуживаться каркасом Vue 3 + Vite
(вход из dist); legacy instructor-apply.html и js/apply.js MUST быть
удалены (монолит целиком). Wiring MUST быть 1:1: multipart POST
/api/instructors/apply (поля + license_photo), согласие обязательно
(FR-77: кнопка блокирована до чекбокса; 422 позиция 1a), файловые
ошибки у поля ВУ, 200 → токены опроса и редирект
/instructors/pending; вид — без редизайна.

Источник: FR-10…12, FR-77; FR-84…86; NFR-26/27; ADR-008.

#### Scenario: Анкета обслуживается каркасом Vue

- **GIVEN** сборка каркаса выполнена (dist существует)
- **WHEN** пользователь открывает /instructors/apply
- **THEN** страница отдается входом каркаса Vue (html со ссылками на ассеты префикса /vue/), а не legacy-HTML-монолитом; маршрут /instructors/apply не изменился

#### Scenario: Валидная анкета — экран ожидания, контракт не меняется

- **GIVEN** заполненная анкета с фото ВУ и установленным согласием (TC-UI-004 без правок)
- **WHEN** отправлена multipart-форма
- **THEN** POST /api/instructors/apply содержит те же поля и license_photo; 200 → application_poll_token/application_exchange_token в localStorage ДО редиректа на /instructors/pending (h1 «Заявка на рассмотрении»); механика опроса (С9) не изменена

#### Scenario: Согласие обязательно — 422 позиция 1a (FR-77)

- **GIVEN** анкета заполнена, чекбокс согласия не установлен
- **WHEN** пользователь пытается отправить форму / отправляет POST напрямую
- **THEN** кнопка сабмита недоступна на клиенте; прямой POST без согласия отвечает 422 {ok:false, error:"Согласие: поле обязательно"} — контракт сервера не изменен, заявка не создана

#### Scenario: Ошибки файла ВУ — видимое сообщение у поля загрузки

- **GIVEN** выбран файл ВУ больше 5 МБ / не-JPEG-PNG, либо сервер отвечает 413/415
- **WHEN** валидация выполнена / форма отправлена
- **THEN** текст ошибки («Файл: …» — совпадает с серверным) виден у поля загрузки (#license-error), отправка блокирована; прочие ошибки — notice под формой; тексты 1:1 с legacy

#### Scenario: Визуальная эквивалентность текущей анкете

- **GIVEN** сравнение Vue-версии с текущей анкетой
- **WHEN** выполнено сопоставление содержимого
- **THEN** эквивалентность без редизайна: тексты и CSS-строки мокапа registration-instructor дословно (шапка, intro-шаги 01/02/03, секции формы, upload с миниатюрой, согласие со ссылкой /policy, футер)
