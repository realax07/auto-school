# Delta: student-instructor-choice

## ADDED Requirements

### Requirement: Шапка «Выбора инструктора» без плитки-аватара (BUG-062)

Шапка страницы /instructor-choice MUST НЕ содержать плитку-аватар
(span#avatar с инициалами/«—», правило CSS .avatar): блок пользователя —
только ФИО (#uname) и кнопка «Выйти». Заполнение плитки из ответа
/api/auth/me MUST быть удалено вместе с правилом. Мокапы
choice-instructor-a/b MUST быть синхронизированы (плитка и правило
.avatar убраны). ФИО и «Выйти» MUST остаться без изменений.

Источник: BUG-062 (реестр test-model/bugs/, решение Заказчика
2026-11-07); TC-UI-059; NFR-27.

#### Scenario: В шапке нет плитки-аватара

- **GIVEN** ученик с валидной сессией на /instructor-choice
- **WHEN** просмотрена шапка страницы (блок .user)
- **THEN** элемента .avatar в шапке нет (удалены span#avatar, правило .avatar и его заполнение из js); сценарий TC-UI-059 дополнен негативным инвариантом «в шапке нет .avatar» (дополнение прямо предписано планом фикса BUG-062)

#### Scenario: ФИО и «Выйти» не пострадали

- **GIVEN** ученик с валидной сессией на /instructor-choice
- **WHEN** GET /api/auth/me вернул ФИО
- **THEN** ФИО отображается в #uname и кнопка «Выйти» на месте — шапка не пустеет, заполнение ФИО работает как прежде

#### Scenario: Мокапы синхронизированы

- **GIVEN** открыты design/mocks/choice-instructor-a.html и choice-instructor-b.html
- **WHEN** проверены их шапки и стили
- **THEN** плитки-аватара и правила .avatar в мокапах нет — мокапы соответствуют прод-экрану (прецедент «мокапы choice-a/b синхронно» BUG-059/060/061)
