      (X-Session-Token): require_session (401 {"ok": false} без/с неверным/
      истекшим токеном — механика auth.py) → SELECT users по user_id

      Готовность: тесты — инструкторская сессия получает ФИО/email;
      student-сессия → 403; без токена/неверный/истекший → 401; logout →
      повторный вызов 401; SQL параметризован (0 конкатенаций).
      FR: FR-18, FR-20. NFR: NFR-2, NFR-3. Зависит от: — (users + role
      существуют с Спринта 2.1).
