# mobile-instructor — Delta

## ADDED Requirements

### Requirement: Таб-бар инструктора ≤760px

На ширинах ≤760px кабинет инструктора MUST показывать фиксированный
нижний таб-бар высотой ~54px с пятью позициями: «День» (Мой день),
«Неделя» (Расписание), «Кошелёк» (Доходы и выплаты), «Профиль»
(Профиль и документы), «Ещё» (bottom-sheet: Календарь, Мои ученики,
Мои автомобили, Материалы и обучение, Выход). Целевые области ≥44px.

#### Scenario: Переключение разделов таб-баром
- **WHEN** инструктор на 390×844 нажимает «Неделя»
- **THEN** открывается раздел «Расписание», активная позиция таб-бара подсвечена, горизонтального скролла нет

### Requirement: Top-bar с инициалами ≤760px

Липкий top-bar ≤760px MUST показывать бренд и инициалы инструктора
(источник — GET /api/auth/me, тот же контракт, что С18); 401/403 →
переход на вход. Десктопный сайдбар ≤760px скрыт.

#### Scenario: Сайдбар скрыт, контент у верха
- **WHEN** ширина окна ≤760px
- **THEN** десктопный сайдбар не отображается, контент начинается с отступа ~26px, scrollWidth ≤ ширины вьюпорта

### Requirement: Hit-targets и отсутствие переполнения

Все интерактивные элементы ≤760px MUST иметь целевую область ≥44px;
страницы НЕ ДОЛЖНЫ создавать горизонтальное переполнение на 390px
(длинные тексты — ellipsis).

#### Scenario: Геометрия на reference-вьюпорте
- **WHEN** e2e-носитель открывает разделы кабинета на 390×844
- **THEN** scrollWidth ≤390, кликабельные элементы ≥44px, контент-паддинг верха 20–30px
