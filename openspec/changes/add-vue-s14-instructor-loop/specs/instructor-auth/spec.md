# Delta: instructor-auth

## MODIFIED Requirements

### Requirement: Роутинг после входа по статусу

После успешной проверки пароля система MUST направлять пользователя по
состоянию его учетной записи/заявки: пользователь существует (заявка
approved) → кабинет инструктора /instructor/dashboard; заявка waiting →
экран ожидания /instructors/pending; заявка deny → экран отказа
/instructors/rejected с причиной. Контракт ответа логина (route/reason)
и запись причины в sessionStorage «instructor_rejected_reason» ДО
редиректа MUST не изменяться.

Источник: FR-13; решение Заказчика 2026-11-09 (кабинет вместо
заглушки — фактическое поведение с Спринта 2.2, sdd.md).

#### Scenario: Пользователь найден — заглушка кабинета

- **GIVEN** заявка одобрена, пользователь с email E существует в users
- **WHEN** он успешно входит по email E и паролю
- **THEN** он попадает в кабинет инструктора /instructor/dashboard («Мой день»); прежняя цель /instructor/cabinet-stub («кабинет скоро») УДАЛЕНА в Спринте 14 (решение Заказчика 2026-11-09 п.4 — заглушка недостижима с 2.2); ответ логина route='cabinet' — контракт не изменен

#### Scenario: Заявка waiting — экран ожидания

- **GIVEN** отправлена заявка с email E (статус waiting, записи в users нет)
- **WHEN** выполняется вход по email E с паролем из анкеты
- **THEN** пользователь попадает на экран ожидания /instructors/pending («заявка на рассмотрении»), сессия не выдается

#### Scenario: Заявка deny — экран отказа с причиной

- **GIVEN** заявка с email E отклонена администратором с комментарием C
- **WHEN** выполняется вход по email E с паролем из анкеты
- **THEN** пользователь попадает на экран отказа /instructors/rejected, на котором видна причина отказа C; сессия не выдается

#### Scenario: Статусный экран недоступен без проверки пароля

- **GIVEN** существует заявка в статусе deny с комментарием C
- **WHEN** выполняется попытка открыть /instructors/rejected напрямую (без входа с паролем)
- **THEN** причина отказа C не раскрывается: прямой доступ к статусному экрану без успешной проверки логина/пароля не показывает данные заявки
