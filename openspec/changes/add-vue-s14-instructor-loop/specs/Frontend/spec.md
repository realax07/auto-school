# Delta: Frontend

## ADDED Requirements

### Requirement: Лендинг инструкторов на Vue (/instructors)

Страница /instructors MUST обслуживаться каркасом Vue 3 + Vite (вход из
dist); legacy instructors.html и js/instructors.js MUST быть удалены
(монолит целиком). Модалка входа — последний дубль: вход MUST идти через
shared-компонент и общий wiring каркаса. Контракт входа (route/reason →
sessionStorage «instructor_rejected_reason» до редиректа) MUST не
изменяться; вид — без редизайна.

Источник: FR-10, FR-13; FR-84…86; NFR-26/27; ADR-008; решение
Заказчика 2026-11-09.

#### Scenario: Лендинг обслуживается каркасом Vue

- **GIVEN** сборка каркаса выполнена (dist существует)
- **WHEN** гость открывает /instructors
- **THEN** страница отдается входом каркаса Vue (html со ссылками на ассеты префикса /vue/), а не legacy-HTML-монолитом; маршрут /instructors не изменился; legacy instructors.html и js/instructors.js отсутствуют в исходниках

#### Scenario: Вход — модалка на месте, контракт не меняется

- **GIVEN** гость на /instructors нажал «Войти» (data-open-login) и ввел email заявки в статусе deny с комментарием C
- **WHEN** модалка открылась локально (без редиректа и sessionStorage-флагов — BUG-055) и вход выполнен
- **THEN** wiring пишет sessionStorage «instructor_rejected_reason»=C ДО редиректа на /instructors/rejected; approved → /instructor/dashboard, waiting → /instructors/pending, ученик → /cabinet; ошибка — текст сервера в #login-error; закрытие — крестик/«Отмена»/Esc, клик по фону НЕ закрывает (TC-UI-052 без правок)

#### Scenario: Последний дубль модалок устранен

- **GIVEN** партия выполнена
- **WHEN** проверены исходники frontend/
- **THEN** копий модалки m-login вне каркаса нет (только frontend/vue/*); обе точки входа модалок входа — страницы каркаса (/ и /instructors), wiring входа — общий shared-модуль; tc test_login_modal зелен после переноса носителя

#### Scenario: Визуальная эквивалентность и CTA анкеты

- **GIVEN** сравнение Vue-версии с текущим лендингом инструкторов
- **WHEN** выполнено сопоставление содержимого
- **THEN** эквивалентность без редизайна: бренд (.brand em «Сбер»), hero «Учи водить. Меняй подход.», форматы own/sber, возможности, нижний CTA; CTA шапки/hero/карточек/кнопки #open-form ведут на /instructors/apply (TC-UI-003 без правок)

### Requirement: Кабинет инструктора на Vue (/instructor/dashboard)

Страница /instructor/dashboard MUST обслуживаться каркасом Vue 3 + Vite;
legacy instructor-dashboard.html и js/instructor/dashboard-instructor.js
MUST быть удалены (монолит целиком). Гвард и контракты MUST не
изменяться: /api/auth/me, GET /api/instructor/dashboard (401/403 → «/»),
ФИО из учетной записи; данные «Мой день»/«Мои ученики» — 1:1, демо 2.2
сохраняется; «Выйти» → /instructors. Вид — без редизайна.

Источник: FR-18…22, FR-39…41; FR-84…86; NFR-26/27; ADR-008; решение
2026-11-09.

#### Scenario: Кабинет обслуживается каркасом Vue

- **GIVEN** сборка каркаса выполнена (dist существует)
- **WHEN** одобренный инструктор с сессией открывает /instructor/dashboard
- **THEN** страница отдается входом каркаса Vue (html со ссылками на ассеты префикса /vue/), а не legacy-HTML-монолитом; маршрут /instructor/dashboard не изменился; legacy-файлы отсутствуют в исходниках

#### Scenario: Гвард и данные кабинета — контракты не меняются

- **GIVEN** инструктор открыл кабинет (TC-UI-005 без правок)
- **WHEN** страница запрашивает данные
- **THEN** гвард прежний: /api/auth/me с X-Session-Token, 401 → «/»; GET /api/instructor/dashboard 401/403 → «/»; ФИО шапки из ответа; «Мой день» — данные /api/instructor/summary и /api/instructor/requests, «Мои ученики» — /api/instructor/students с accept/deny запросов (TC-UI-009/024 без правок)

#### Scenario: Разделы и выход сохранены

- **GIVEN** инструктор работает с разделами кабинета
- **WHEN** переключаются разделы и выполняется выход
- **THEN** сайдбар — ровно текущий перечень (BUG-051; «Профиль и документы» остается разделом кабинета, TC-UI-028 без правок); «Календарь», «Мои автомобили» (хеш #/my-cars), документы раздела — поведение 1:1 (TC-UI-008/015/016/023/030/033/034/040/042 без правок); «Выйти» — POST /api/auth/logout, очистка сессии, редирект /instructors (TC-UI-010 без правок)

#### Scenario: Визуальная эквивалентность кабинету

- **GIVEN** сравнение Vue-версии с текущим кабинетом
- **WHEN** выполнено сопоставление содержимого
- **THEN** эквивалентность без редизайна: макет dashboard-instructor дословно (каркас aside+main grid 2 колонки, topbar, hello, виджеты, панели, demo-tag «демо»); дизайн-гварды (BUG-047-перечень разделов) зеленые на новых носителях

### Requirement: Мои документы на Vue (/instructor/documents)

Страница /instructor/documents MUST обслуживаться каркасом Vue 3 + Vite
как новая точка входа; legacy-монолит documents.html MUST НЕ
создаваться. MUST воспроизводить раздел «Мои документы» (Спринт 8):
версии ВУ/СТС, замена (FR-71), дозагрузка СТС, просмотр действующей.
Контракты /api/instructor/documents (список/файл/license) и
/api/instructor/cars/{id}/photo/sts MUST не изменяться; доступ —
только владельцу.

Источник: FR-45, FR-69…73; FR-84…86; NFR-26/27; ADR-008; решение
2026-11-09.

#### Scenario: Новая страница обслуживается каркасом Vue

- **GIVEN** сборка каркаса выполнена (dist существует)
- **WHEN** инструктор открывает /instructor/documents
- **THEN** страница отдается входом каркаса Vue (html со ссылками на ассеты префикса /vue/); legacy-монолит frontend/documents.html не существует (инвариант BUG-047 зелен без правок); маршрут /instructor/documents — новый, других маршрутов не затронул

#### Scenario: Список и версии — контракт не меняется

- **GIVEN** инструктор с ВУ и автомобилями (включая авто без СТС) открыл /instructor/documents
- **WHEN** получен GET /api/instructor/documents (+ /api/instructor/cars для дозагрузки)
- **THEN** ВУ и СТС по каждому авто показаны с типом/привязкой/датой действующей версии и статусами: «Действует», «Ожидает проверки замены», «Отклонено» с причиной (ОВ-1/ОВ-7); авто без СТС — карточка «нет СТС» с кнопкой загрузки; просмотр — действующая версия через GET /api/instructor/documents/{doc_id}/file

#### Scenario: Загрузка и замена — предупреждение и явная кнопка (FR-71)

- **GIVEN** инструктор нажал «Заменить» у документа
- **WHEN** открыт диалог замены
- **THEN** показано предупреждение «замена вступит в силу только после проверки администратором…»; отмена — файл не отправлен; подтверждение кнопкой «Заменить» — POST на контрактный эндпоинт (multipart), после успеха список перезагружен; недопустимый файл (не JPEG/PNG, >5 МБ) отклонен клиентской валидацией с текстами сервера; тосты — тексты legacy дословно

#### Scenario: Доступ только владельцу

- **GIVEN** документы принадлежат инструктору А
- **WHEN** гость открывает /instructor/documents, ученик или другой инструктор запрашивает список/файл
- **THEN** гость без сессии возвращается на вход (гвард /api/auth/me → «/»); чужие сессии получают отказ API (401/403 — контракт прежний); страница редиректится на «/»
