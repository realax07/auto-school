# Proposal: add-mobile-adaptive — мобильная адаптивная версия

## Почему

Решение Заказчика 2026-11-16 (дословно): «Давай сделаем большой релиз - по
мобильной версии сайта адаптивной. Нужны мокапы на все экраны. В репозитории
сохрани их в отдельном корне внутри папки с дизайн мокапами - mobile».

Мокапы v3 спроектированы, согласованы Заказчиком 2026-11-17 («Давай
реализуем. Править уже постфактум будем на живую») — design/mocks/mobile/
(21 экран, 390px, канон дизайн-системы, таб-бар снизу, bottom-sheet модалки,
учётка в top-bar). Правки после реализации — на живую силами ПМ.

## Что

Мобильная адаптация ВСЕХ ученических и публичных страниц (390–760px):
- компактный таб-бар снизу (5 разделов, SVG-иконки) вместо desktop-сайдбара;
  сайдбар скрывается на <760px, таб-бар появляется; ФИО — в top-bar
- одноколоночные карточки вместо таблиц (заявки, брони, история кошелька,
  штрафы, транзакции админа)
- неделя-календарь бронирования — горизонтальная полоса дней
- модалки — bottom-sheet с граб-хендлом (вход, регистрация, бронь, оспорить)
- разделы ПДД (Знаки/Правила/Билеты/Штрафы) — уже одноколоночные, polish
- контент поднят к верху с отступом логотипа на всех страницах
- инструкторские и админские страницы — адаптив по тем же правилам

## Границы

- Только CSS/разметка: НЕ меняются контракты API, данные, логика, сценарии
- Desktop-версия (>760px) — без изменений (носители e2e 84 защищают)
- Модалки уже bottom-sheet (С17) — сохраняются

## Волны

- 18.1 таб-бар (компонент MobileTabBar, показ <760px) + сокрытие сайдбара
- 18.2 адаптив кабинета: все 8 разделов (карточки/списки/календарь-полоса)
- 18.3 адаптив ПДД-разделов + инструктор/админ/публичных
- 18.4 носители + e2e (мобайл-вьюпорт 390: прогон ключевых сценариев) + карта
