# Delta: student-requests

## MODIFIED Requirements

### Requirement: Виджет «Привязанные ученики»

Виджет «Привязанные ученики» на главной кабинета инструктора MUST
показывать принятых учеников (после принятия заявки); до принятия
ученик отсутствует; пустой список — корректное пустое состояние
(FR-40). Виджет — ТОЛЬКО на главной кабинета: на экранах «Мои
автомобили» и «Мои документы» он отсутствует (FR-73). Список учеников
с занятями — в разделе «Мои ученики» (ADDED).

Источник: requirements-sprint8.md FR-73, FR-75; наследует FR-40.

#### Scenario: После принятия ученик появляется в виджете

- **GIVEN** инструктор принял заявку ученика
- **WHEN** инструктор открывает главную кабинета
- **THEN** в виджете «Привязанные ученики» отображается этот ученик

#### Scenario: До принятия и без учеников — пустое состояние

- **GIVEN** у инструктора нет принятых учеников (есть только «новые» заявки или список пуст)
- **WHEN** инструктор открывает главную кабинета
- **THEN** виджет показывает корректное пустое состояние; «новые» заявки в виджете учеников не перечислены

#### Scenario: Экраны «Мои автомобили» и «Мои документы» — без виджета

- **GIVEN** инструктор с принятыми учениками
- **WHEN** он открывает экран «Мои автомобили», затем «Мои документы»
- **THEN** виджет «Привязанные ученики» (как и «запросы учеников» и «занятия на сегодня») на этих экранах не отображается; WHEN он открывает главную кабинета THEN виджеты на месте

### Requirement: Виджет «Занятия на сегодня» — честная заглушка

Виджет «Занятия на сегодня» MUST показывать список занятий инструктора на
текущую дату. В этом объеме занятий еще нет (реальное расписание вне
скоупа), поэтому виджет показывает корректное пустое состояние «Сегодня
занятий нет» — не ошибку и не фиктивные данные (трассировка: FR-41).
Виджет MUST отображаться ТОЛЬКО на главной кабинета инструктора: на
экранах «Мои автомобили» и «Мои документы» он ОТСУТСТВУЕТ (FR-73,
явные исключения).

Источник: requirements-sprint8.md FR-73; наследует FR-41.

#### Scenario: Виджет показывает «Сегодня занятий нет»

- **GIVEN** реального расписания занятий не существует
- **WHEN** инструктор открывает главную кабинета
- **THEN** виджет «Занятия на сегодня» показывает «Сегодня занятий нет» (пустое состояние)

#### Scenario: Экраны «Мои автомобили» и «Мои документы» — без виджета

- **GIVEN** инструктор открыл экран «Мои автомобили» или «Мои документы»
- **WHEN** экран отображен
- **THEN** виджет «Занятия на сегодня» на нем не отображается

## ADDED Requirements

### Requirement: Раздел «Мои ученики» со счетчиками занятий

Раздел «Мои ученики» MUST показывать принятых учеников (пары
status='accepted'); новые сущности не заводятся (ADR-005). По каждому:
следующее плановое занятие (ближайшая confirmed бронь ≥ сегодня,
иначе «нет»), плановых дальше и проведенных (только confirmed — ОВ-5;
дата — локальная дата сервера, MIN-1). «Запросы учеников» —
подраздел внутри раздела, по требованию (ОВ-5); отдельного пункта
сайдбара нет. Доступ — только владельцу (NFR-22).

Источник: requirements-sprint8.md FR-75, NFR-22/23; ОВ-5.

#### Scenario: Карточка ученика с занятями показывает счетчики

- **GIVEN** пара принята; у ученика 1 подтвержденная бронь на завтра, 2 на следующей неделе, 3 в прошлом
- **WHEN** инструктор открывает «Мои ученики»
- **THEN** карточка ученика показывает: следующее — завтра, плановых дальше — 2, проведенных — 3

#### Scenario: Пара без броней — корректное пустое состояние

- **GIVEN** пара принята, подтвержденных броней нет
- **WHEN** инструктор открывает «Мои ученики»
- **THEN** карточка показывает: следующее — «нет», плановых дальше — 0, проведенных — 0

#### Scenario: Запросы не входят в счетчики (только confirmed)

- **GIVEN** у ученика пара с инструктором: 1 новый запрос на слот и ни одной подтвержденной брони
- **WHEN** инструктор смотрит карточку ученика
- **THEN** следующее — «нет», счетчики 0/0 (запрос счетчиками не обещается, ОВ-5)

#### Scenario: Запросы — подраздел по требованию внутри раздела

- **GIVEN** есть новый запрос ученика
- **WHEN** инструктор открывает «Мои ученики»
- **THEN** основной список — карточки принятых учеников; запрос виден в подразделе «Запросы учеников», который открывается по требованию (вкладка/окно внутри раздела); отдельного пункта сайдбара «Запросы учеников» нет; GIVEN запрос принят THEN ученик появляется в основном списке

#### Scenario: Раздел доступен только владельцу

- **GIVEN** пары принадлежат инструктору А
- **WHEN** другой инструктор, ученик или гость запрашивает список учеников А
- **THEN** доступ запрещен; чужие пары не возвращаются (404-неразличение)
