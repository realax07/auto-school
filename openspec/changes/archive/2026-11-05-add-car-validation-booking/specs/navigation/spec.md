# Delta: navigation

## ADDED Requirements

### Requirement: Единая навигация по ролям без демо-заглушек

Навигация интерфейсов MUST быть очищена от демо-заглушек и
унифицирована: админка — без пунктов «Расписание» и «Отношения»;
кабинет ученика — «Выбор инструктора» в едином сайдбаре кабинета
(BUG-047), без кнопки «← В кабинет»; главная инструктора — без
декоративного блока «Ваш следующий маршрут». Удаленные пункты не
отображаются и не реагируют на действия.

Источник: requirements-car-validation-booking.md (раздел «Навигация»;
BUG-047 — единый сайдбар).

#### Scenario: В админке нет пунктов «Расписание» и «Отношения»

- **GIVEN** администратор открыл админку
- **WHEN** отображается боковая навигация
- **THEN** пунктов «Расписание» и «Отношения» нет; доступные разделы (пользователи, заявки, «Автомобили») работают

#### Scenario: Выбор инструктора открывается в едином сайдбаре ученика

- **GIVEN** ученик с валидной сессией находится в кабинете
- **WHEN** он переходит в раздел «Выбор инструктора»
- **THEN** раздел открывается внутри единого сайдбара кабинета (как «Главная», «Мои заявки»); отдельной кнопки «← В кабинет» на странице нет, возврат — через тот же сайдбар

#### Scenario: Активный пункт сайдбара подсвечен на «Выборе инструктора»

- **GIVEN** ученик открыл раздел «Выбор инструктора» из единого сайдбара
- **WHEN** отображается навигация
- **THEN** пункт «Выбор инструктора» подсвечен как активный; после перезагрузки страницы раздел и подсветка сохраняются

#### Scenario: Главная инструктора без «Ваш следующий маршрут»

- **GIVEN** главная страница инструктора (/instructors) открыта
- **WHEN** страница отрисована
- **THEN** декоративного блока/подписи «Ваш следующий маршрут» нет; остальной лендинг без изменений
