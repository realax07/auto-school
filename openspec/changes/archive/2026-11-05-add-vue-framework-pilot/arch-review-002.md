## Проверка закрытия мажоров review-001

### MAJ-1 (судьба legacy-тестов страницы ожидания) — ЗАКРЫТ

По фактам диффа ca4b790 и сверки с репо:

1. **Ложное утверждение design исправлено.** «Отдача мигрированных
   страниц» больше не говорит «ссылок на файл вне `_PAGE_ROUTES` нет» —
   поименно назван известный потребитель: tests/test_instructor_pages.py,
   `test_pending_page_exists_and_text` (строки 256–268), чтение через
   локальный helper `page()` (строка 24). Сверено с репо: helper
   `def page(...)` — :24, тест — :256, читает `page("instructor-pending.html")`
   — ссылки в тексте пакета теперь соответствуют коду.
2. **Новый раздел design «Миграция legacy-тестов страницы ожидания»** —
   судьба обоих тестов определена:
   - `test_pending_page_exists_and_text` — ПЕРЕВОД на вход пилотной
     страницы (не удаление), источник чтения переключается на
     `frontend/vue/instructors-pending.html`; проверяемые тексты,
     селекторы и URL не меняются — маршруты сохранены
     (`/instructors/pending`, h1 «Заявка на рассмотрении»); контроль
     остается статическим, e2e не дублируется. Состоятельность сверенa
     с каркасом: вход instructors-pending.html по design — «статическая
     разметка экрана (эквивалент legacy) + модуль-скрипт», т.е. тексты
     для статического контроля на входе присутствуют.
   - **TC-UI-004** (tests/test_ui_playwright.py:358–360) — без правок:
     `wait_for_url("**/instructors/pending")` + `expect(h1).to_have_text`
     — автожидание покрывает момент гидрации Vue (сверено с кодом:
     строки совпадают). Сценарий не переписывается — NFR-27 не нарушен.
   - Разграничение с NFR-27: «0 правок» касается ТОЛЬКО
     tests/test_ui_playwright.py; правка test_instructor_pages.py —
     разрешенная и ожидаемая работа пакета.
3. **tasks 2.3 — явная задача миграции в составе пилотной работы:**
   «В СОСТАВЕ ЭТОЙ ЗАДАЧИ (не отдельная волна)» — перевод теста на вход
   пилотной страницы с сохранением текстов/селекторов/URL; готовность 2.3
   переформулирована: «tests/test_instructor_pages.py обновлен (…против
   нового входа)» + grep-контроль ПОСЛЕ правки + pytest зеленые —
   самопротиворечивый чек-лист («файл удален И тесты зеленые» без
   мандата на правку) устранен. tests/test_instructor_pages.py внесен в
   зону файлов («только 2.3»). Разграничение продублировано в 5.1 и 6.1.

Замечание review-001 полностью отработано: ни одного незапланированного
