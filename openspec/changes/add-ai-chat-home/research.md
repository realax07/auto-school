# Research: add-ai-chat-home

Ключевые альтернативы до design (выбор зафиксирован в design.md):

1. Инференс ассистента: (а) временно сессия hermes (`hermes chat -q`,
   oneshot) с системным промптом — выбрано (решение Заказчика, BACKLOG #5
   в редакции requirements-ai-chat-home.md); (б) внешний инференс сразу —
   вне спринта по решению Заказчика.
2. Хранение истории: (а) SQLite-таблица ai_messages — выбрано (прецедент
   wallets С16, серверная retention, изоляция по user_id); (б) клиентское
   хранение — отвергнуто (FR-19.5 требует серверного хранения и подхвата
   в обеих версиях, NFR — retention на сервере).
3. Смена реализации: адаптер-провайдер в одном доменном модуле backend/ai —
   выбрано (замена на внешний инференс без правок фронтенда); вызов
   модели из фронтенда — отвергнуто (секреты и промпт у клиента).
4. Retention 14 дней: DELETE старше при чтении истории — выбрано
   (простое и детерминированное); фоновая чистка на lifespan —
   опциональное усиление, без нового сервиса (IR-02 не задевается).
