## MODIFIED Requirements

### Requirement: Отображение ФИО ученика

Кабинет MUST отображать ФИО ученика из его учетной записи (трассировка:
FR-5) — в блоке учетки сайдбара (>760px) и профиле таб-бара (≤760px).
Приветствие раздела «Главная» — чатовое по макету («Добрый день!») и
ФИО не содержит; приветствие по имени в «Главной» MUST отсутствовать.

Источник: requirements.md FR-5; правка — решение Заказчика 2026-11-18
(макеты чата).

#### Scenario: ФИО в кабинете совпадает с учетной записью

- **GIVEN** ученик Иванов Иван Иванович зарегистрирован и вошел в систему
- **WHEN** он открывает кабинет
- **THEN** его ФИО из учетной записи отображается в блоке учетки сайдбара/профиле таб-бара

#### Scenario: ФИО берется из учетной записи, а не подставляется константой

- **GIVEN** зарегистрированы два ученика с разными ФИО, оба вошли в систему
- **WHEN** каждый открывает свой кабинет
- **THEN** в кабинете каждого отображается его собственное ФИО из учетной записи

#### Scenario: Приветствие «Главной» без ФИО

- **GIVEN** любой авторизованный ученик
- **WHEN** он открывает раздел «Главная»
- **THEN** приветствие «Добрый день!» из макета чата; «Добро пожаловать, {Имя}!» отсутствует

### Requirement: Соответствие утвержденному мокапу кабинета

Тексты и стили кабинета MUST соответствовать утвержденным мокапам
дословно: раздел «Главная» — design/mocks/home-chat-web.html и
design/mocks/mobile/mobile-home-chat.html (capability ai-chat),
остальные разделы — design/mocks/cabinet-student.html. Допустимые
отличия — только wiring (связка с API) и подстановка ФИО ученика
вместо примера мокапа.

Источник: requirements.md FR-9; решение Заказчика 2026-11-18 (макеты чата).

#### Scenario: Тексты кабинета совпадают с мокапом

- **GIVEN** ученик открыл раздел кабинета вне «Главной» («Мои заявки», «Мои брони», «Кошелек», разделы ПДД)
- **WHEN** выполняется текстовое сравнение страницы с design/mocks/cabinet-student.html
- **THEN** заголовки, тексты и подписи совпадают с мокапом дословно (кроме подстановки ФИО ученика вместо примера)

#### Scenario: Оформление кабинета соответствует мокапу

- **GIVEN** ученик открыл раздел кабинета вне «Главной»
- **WHEN** выполняется визуальное сравнение с design/mocks/cabinet-student.html
- **THEN** структура, расположение блоков и стили соответствуют мокапу

#### Scenario: «Главная» — макеты чата

- **GIVEN** ученик открыл раздел «Главная»
- **WHEN** выполняется сравнение с макетами чата (обе версии представления)
- **THEN** тексты и структура совпадают дословно; отличия — только wiring и данные чата
