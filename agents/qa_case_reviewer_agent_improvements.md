## Проблема: e2e-прогон playwright в среде ревью невозможен
- Проблема: pytest tests/test_ui_playwright.py -k s9_pilot — 6 error при старте chromium: chrome-headless-shell не стартует, нет системной библиотеки libatk-1.0.so.0 (и прочих GUI-deps); playwright install-deps требует sudo (пароль недоступен).
- Решение: прогон не повторять; соответствие кейс↔тест ревьюить по коду (docstring + тела + моки), факт прогона — за ПМ/раннером (ссылочные прогоны в кейсах с пометкой «факт ПМ»).
- Предложение: для ролей, ревьюящих e2e, завести отдельный раннер-стенд с предустановленными браузерными deps (см. tasks.md «План тестовых прогонов» — набор 2), в ревью-среде помечать прогон как «не проверено» без попыток установки.
