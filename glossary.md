# Глоссарий Auto School

> Правило Заказчика 2026-10-15: пополняется в процессе работы; новые сущности/понятия фиксируем здесь же, где вводим (спека/ADR + строка здесь).

## Роли
- **Ученик** — клиент автошколы; учетка users role='student'; кабинет /cabinet.
- **Инструктор (водитель)** — дает занятия; учетка users role='instructor'; кабинет /instructor/dashboard.
- **Администратор** — модерация заявок инструкторов, админка (X-Admin-Token).

## Домен
- **Анкета инструктора** — заявка на модерацию: instructor_applications (ФИО тремя полями surname/name/patronymic, формат работы, ВУ, согласие).
- **Статусы заявки инструктора**: waiting (на рассмотрении) / approved (создан users-аккаунт) / rejected (отказ с комментарием).
- **ВУ** — водительское удостоверение (номер, категория, даты; в перспективе фото).
- **Формат работы** — own / sber (свой автомобиль / от автошколы).
- **Занятие** — урок инструктора с учеником (в Спринте 3 — виджет «Занятия на сегодня», реальные данные позже).
- **Часы работы (availability)** — выбираемые инструктором интервалы в календаре (Спринт 3).
- **Мои автомобили** — instructor_cars, связь 1-ко-многим к инструктору, с фото (Спринт 3).
- **Рейтинг / Отзыв (reviews)** — оценка инструктора; отзыв оставляет только реальный ученик (Спринт 3).
- **Заявка ученика (student_request)** — запрос ученика на выбор инструктора; решение инструктора: отказ (обязательный комментарий, виден ученику) / принятие (→ «Мои ученики» + привязка авто) (Спринт 3).
- **Выбор инструктора** — раздел кабинета ученика: карточки с фильтрами машина/рейтинг/стаж/свободное время; карта — вне скоупа Спринта 3.

## Технические
- **Сессия** — X-Session-Token (users, TTL 12 ч); **админ-токен** — X-Admin-Token (.env).
- **design-guard** — тесты verbatim-сверки page↔mock (CSS-строки/фрагменты); правило: page+mock+тест в одном коммите.
- **Флоу 1–5** — процессы конвейера (см. PLAN.md / skills/devops/ai-factory-sprint-cycle-v2).
