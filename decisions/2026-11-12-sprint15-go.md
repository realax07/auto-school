## Состав Спринта 15 (партия add-vue-s15-final-migration)

Мигрируются ВСЕ оставшиеся легаси-страницы (после партии легаси-HTML
в frontend/ не остается):

1. **Календарь-контур** (самый сложный — перенос недель/попапа С10):
   - `/instructor/bookings` — instructor-bookings.html (запросы брони +
     недельный календарь инструктора: навигация ‹ ›, попап-редактор
     разово/повторяющееся, запросы confirm/reject)
   - `/booking` — booking.html (ученик: слоты/брони + недельный календарь
     ученика)
2. **Ученический кабинет**: `/cabinet` — cabinet.html (главная кабинета:
   чат-бар, плитки СЕРВИСЫ без тегов, приветствие) + подстраница
   `/instructor-choice` — instructor-choice.html (каталог + форма отзыва
   уже Vue... сверить: review-form отдельно)
3. **Admin-контур**: `/admin-login` — admin-login.html, `/admin/dashboard`
   — admin-dashboard.html, `/admin/cars` — admin-cars.html
   (комплектность/блокировка), `/admin/documents` — admin-documents.html
   (верификация ВУ/СТС)
4. **Мелкие**: `/registered` — registered.html; `/policy` — policy.html
   (оболочка текста политики)
5. После партии: каталог frontend/ без легаси-HTML (кроме файлов,
   требуемых сборкой), каталог /js/ удален целиком, _PAGE_ROUTES —
   все значения vue: (или прямая отдача), instructor-cabinet-stub уже
   удален.

## Критические ограничения

- ADR-008 (multi-entry MPA, no SPA/router/pinia; бюджеты NFR-26 на все
  page-чанки — станет ~17 входов; e2e NFR-27 — сценарии не переписывать,
  только переносы источников чтения по прецеденту С11–С14).
- Календарь С10: недели, попап-редактор, запрет прошлого — перенос 1:1
  (логика уже выверена, тесты s10/s13 не должны пострадать: они API и
  e2e по якорям).
- Admin: X-Admin-Token сессии, /api/admin/* контракты не меняются.
- policy: оболочка fetch /api/policy — рендер текстовыми узлами (С9).
- Роутинг входа: route/reason из логина ученика (cabinet) и инструктора
  (instructors.html уже Vue с С14 — модалки общие в shared) — не
  дублировать, использовать shared/LoginModal/RegisterModal.

## Критерии приема

- Полный e2e зелен (67+ сценариев — ноль правок сценариев, только
  переносы источников чтения); бюджеты все page-чанки; openspec strict;
  regress-final PASS; в frontend/ не осталось легаси-HTML.
