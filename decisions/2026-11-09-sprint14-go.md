# Решение Заказчика: Спринт 14 — инструкторский контур на Vue

Дата: 2026-11-09 (telegram:144324141; состав утвержден: «давай дальше»)

## Состав Спринта 14 (партия add-vue-s14-instructor-loop)

1. **`/instructors`** — лендинг инструкторов (`frontend/instructors.html` +
   `frontend/js/instructors.js`): hero, модалка входа инструктора (последний
   дубль m-login — после партии легаси-копий модалок не остается), CTA на
   анкету, статусные переходы (pending/rejected — уже на Vue с С9/С11).
2. **`/instructor/dashboard`** — кабинет инструктора
   (`frontend/instructor-dashboard.html` +
   `frontend/js/dashboard-instructor.js`): GET /api/instructor/me +
   /api/instructor/dashboard, демо-данные по решению Спринта 2.2.
3. **`/instructor/documents`** — «Мои документы»
   (`frontend/documents.html`): ВУ/СТС с версиями (Спринт 8), кнопки
   загрузки/замены, админ-верификация — только чтение контура.
4. **Чистка мертвой страницы**: `instructor-cabinet-stub.html` (+ js) —
   удалить (недостижима с Спринта 2.2; подтверждить грепом переходов).

## Вне состава (следующие партии)

- `instructor-bookings.html` — календарь инструктора (недели/попап,
  Спринт 10) — отдельная тяжелая партия вместе с ученическим
  booking.html/instructor-choice.html;
- admin-контур (admin-login/dashboard/cars/documents) — финальная партия.

## Критические ограничения

- ADR-008 (multi-entry MPA, no SPA/router/pinia, удаление legacy целиком,
  бюджеты NFR-26 на все page-чанки — станет 7 страниц, e2e NFR-27).
- Модалка входа instructors.html — последний дубль: после миграции
  instructors.html все входы в инструкторский контур идут через Vue.
  instructors.js wiring (login route/reason, pending/rejected-редиректы)
  — контракты не меняются; instructors-rejected уже Vue (С11) — не
  дублировать, связать с существующей страницей.
- dashboard-страница: серверная проверка роли (guards) не меняется,
  демо-данные Спринта 2.2 сохраняются (реальные данные — будущие
  функциональные партии).

## Критерии приема

- Полный e2e зелен (сценарии не переписываются; переносы источников
  чтения — по прецеденту С11/С12); бюджеты 7 чанков; openspec strict;
  regress-final PASS на merged-дереве; instructors.html и
  instructor-dashboard.html и documents.html — в archive легаси.
