# Решение Заказчика: Спринт 11 — UI-гигиена кабинета ученика + Vue С11

Дата: 2026-11-06 (telegram:144324141, дословно)

## Цитата Заказчика

> 1. В каждом разделе личного кабинета ученика, есть задвоение логотипа.
> Надо убрать логотип на подстранице, оставим только один логотип на сайдбаре.
> + убираем надписи "Личный кабинет · ученик" и "Кабинет ученика · Выбор инструктора" с подстраниц
> 2. Убрать тег "В кабинете" с главной страницы кабинета ученика на тех плитках, на которых он есть.
> 3. Продолжаем пункт 1 из бэклога

## Решения

1. **BUG-059 (задвоение логотипа + крошки):** в кабинетных страницах
   ученика логотип остается ТОЛЬКО в сайдбаре (`.side-brand`); шапка
   контента теряет дубль `.brand` и строки-крошки:
   - frontend/cabinet.html (главная): убрать `.brand` + `.crumb`
     («Личный кабинет · Ученик»), шапка — только блок пользователя;
   - frontend/instructor-choice.html (подстраница «Выбор инструктора»):
     убрать `.brand` + `.crumb` («Кабинет ученика · Выбор инструктора»);
   - мокапы design/mocks/ синхронизируются (кабинет + choice-a/b) —
     FR-9 дословность сохраняется относительно синхронного мокапа;
   - review-form.html не трогается: крошка «Отзыв об инструкторе» —
     функциональный заголовок формы, дубля логотипа там нет;
   - кабинет ИНСТРУКТОРА не трогается (Заказчик сказал «ученика»).
2. **BUG-060 (тег «В КАБИНЕТЕ»):** с плиток «Найти водителя» и «Мои
   заявки» на главной кабинета ученика тег `<span class="soon">В
   КАБИНЕТЕ</span>` убирается (плитки остаются, навигация работает).
3. **Vue С11 (бэклог №1, ADR-008):** следующая партия постраничной
   миграции — статусный экран `/instructors/rejected` (пара к пилотному
   pending) и простая форма `/review-form` («Отзыв об инструкторе»).
   Полный конвейер (СА-пакет → арх-ревью → dev → ревью → QA → regress).

## Критерии приема

- В кабинете ученика ровно один логотип (сайдбар); дублей `.brand` и
  крошек «Личный кабинет · Ученик» / «Кабинет ученика · Выбор
  инструктора» нет ни на одной странице контура.
- Плитки главной без тегов «В КАБИНЕТЕ».
- Полный регресс зеленый (web + api + unit); mockup-verbatim тесты
  зеленые против синхронизированных мокапов.
- e2e TC-UI-059/060 покрывают пункты 1–2.
