## Контекст

Прод-контур остается монолитом (app+nginx; разрезание сервисов — Релиз 1,
отложено). Партия — ЧИСТАЯ перекладка кода в доменные папки, без изменения
поведения, контрактов API и БД (паттерн 3 «модульность без фанатизма»,
директива 2026-10-16 «модульная структура»).

## Состав Спринта 13

1. **backend/**: плоские 22 модуля → доменные папки (auth / instructor /
   student / policy / core-инфраструктура). Точное дерево — СА по инвентарю
   импортов (tests/, scripts/, Dockerfile, compose, systemd-юнит).
2. **frontend/js/**: плоские ES-модули → папки по контурам (shared /
   student / instructor / admin). Мигрированные на Vue страницы уже
   структурированы (src/pages/<page>/) — не трогаются.

## Критические ограничения

- Поведение, контракты API, схема БД, single-worker — БЕЗ ИЗМЕНЕНИЙ.
- Точки входа: uvicorn `backend.app:app` (Dockerfile CMD, compose,
  systemd-юнит), create_app() — не переименовываются.
- Импорты во всех тестах (from backend...), строковые ссылки
  (backend.booking и т.п.), HTML src="/js/..." и conftest
  frontend_source()-обход — полная инвентаризация до переноса.
- Полный e2e + все наборы — зеленые; правки тестов — ТОЛЬКО пути импортов
  (механические), фиксируются отдельным списком.

## Критерии приема

- Новое дерево доменов; все наборы тестов зеленые без смысловых правок;
  сборка образа + полный e2e; openspec strict; regress-final PASS.
